/lang is a single-pass compiler kit for building languages on the Edge engine. A language declares its tokens and Pratt rules, and the kit supplies cursor, emitter, SSA and VM. So, every language owns its semantics, none inherit Python.

Async model

- The engine implements only the coroutine protocol of Python, await, send, throw, close, async generators and async with. It runs no scheduler, the host port that stays is blocking host calls, host events and fuel preemption of the module body.
- lang ships the opinionated async API as the module tasks, Python source compiled with the program, imported as `from tasks import run, sleep, gather, with_timeout, cancel, CancelledError`.
- run is the only entry from plain code, it drives every task it was given until they all end and returns what the first returned. sleep, gather and with_timeout are awaited inside a task, cancel raises a catchable CancelledError where the task waits.
- The loop keeps the ready tasks in a list read from a head cut back once half spent, so a step costs O(1), and the sleepers in a binary heap. Ten thousand tasks gather in about 40 ms natively, where the old engine scheduler took 72 seconds.
- The clock is virtual, a sleep takes no real time and every run prints the same. A host clock would be a native the language defines.
- Edge Python gets asyncio transpiled with the rest of the standard library, over the same protocol, instead of these names.
- Still open. A host call that waits inside a task, since a coroutine stepped by send cannot suspend to the host yet. What time.sleep does in Edge Python, CPython blocks the thread and a browser can only block a worker with Atomics.wait.

Foreign values

- A NaN-box tag FOREIGN marks a value whose owner is not the Edge heap, a raw pointer the engine never moves or collects.
- It is not tied to Python. The same tag carries a PyObject, a JS or DOM handle, or any host object a lang language brings.
- Names elsewhere are Lua light userdata for a bare pointer and userdata for a GC-managed block, wasm externref, and Truffle foreign objects.
- A mutable object that native code can write directly moves to one shared storage the first time it crosses and stays there. Never keep two copies synced at the boundary. Ironclad tried and failed, JyNI and GraalPy keep one copy.
- Inline numbers have no address. Native code gets an entry of a small-int table or a pooled box, never a pointer that encodes the value, since prebuilt code reads the memory behind it.

Kit shape

- The engine never imposes evaluation order. Each language picks it in its frontend. Python runs the value of an assignment first, JS runs the target first.
- The reusable part is the cursor. Mark, seek and rewind, skipping a target list without compiling it, compiling the value, then coming back to store into the targets.
- The lexer marks what the parser needs ahead of time, comp for a comprehension element and assigns for the `=` that end assignment targets. The kit should let each language add such marks.
- Swap and Rot3 cost nothing once lowered to registers, so a frontend can emit values in its own order and reorder right before a store.
- lang depends on the engine of this repo by path and uses only the embedding API, so it moves with every engine change.

From the 2026-10-12 research

- Decided, FOREIGN carries a handle and not a raw pointer, kind 16 bits and index 32 bits into a slot table the Edge GC sweeps. A forged NaN then fails a check instead of reaching arbitrary memory, and the browser and native builds share one format. V8 measured about 1% for the extra load.
- In the browser a JS object sits in an externref table and the handle is its slot, as wasm-bindgen does. WasmGC refs are opaque and Rust cannot hold externref, so engine objects stay NaN-boxed.
- Test FOREIGN only after the int, float and heap fast paths fail, so code without foreign values pays nothing.
- The lang API is register_kind(vtable) giving a kind, box(kind, handle) and unbox(value) giving (kind, handle). The vtable stays near the Lua metatable events, attr and item get set del, call, iter, len, bool, eq hash repr, one binary op hook, trace and drop, with a bitmask of the missing ones. Handle ownership follows WIT resources, own and borrow. Start small, Truffle interop grew to 138 messages.
- One backend for every language. Lowering the typed SSA to Cranelift IR gives each lang language the same native and wasm output.
- Deegen and LuaJIT Remake generate an interpreter and a baseline JIT from a semantics description for a register VM. It is the model for lang later, not now.
