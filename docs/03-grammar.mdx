# Grammar

This page covers the grammar a token table can bring in `shapes.grammar`. With a `Grammar` the parser reads a program as items (`let`, `fn`, `type` and imports) and adds three things the fixed core lacks.

| Piece | Is | Example |
|---|---|---|
| Form | A construct led by a word of yours, compiled to a call of a function with its parts as arguments | `fix k = 1 up to 10 { ... }` |
| Reading | An operator table an expression is read with, one of the `readings` a slot names by its index | `Expr(0)` reads with the first |
| Pattern | A word a `match` arm tests its subject with | `ok v` |

All of it compiles to the engine's bytecode, so a grammar costs nothing at run time.

## Example

This table has braces, `--` comments, one form, one pattern word and one lazy call.

```rust standalone_crate
use interpreter::{Limits, VM};
use interpreter::lang::{Cmp, Descriptor, Front, Language, Names, Native, Natives, Op, Overflow, Policy, Runtime};
use interpreter::value::foreign::BinOp;
use interpreter::lexer::grammar::{Emit, Form, Grammar, Pattern, Reading, Row, Slot, Test};
use interpreter::lexer::TokenType as T;
use interpreter::lexer::{Binding, Blocks, Comments, Cond, Continuation, Dot, Ends, Escapes, Keywords, Lambda, Numbers, Quote, Shapes, Spelling, Strings, Suffix, Syntax, TokenType, Unicode, Unknown, Zeros, index, operators};

interpreter::allocator!();

const WORDS: &[(&str, TokenType)] = &[
    ("true", T::True), ("false", T::False), ("or", T::Or), ("in", T::In), ("if", T::If), ("else", T::Else),
    ("match", T::Match), ("fn", T::Fn), ("let", T::Let), ("for", T::For), ("_", T::Underscore),
];
const SYMBOLS: &[(&str, TokenType)] = &[
    ("(", T::ParenOpen), (")", T::ParenClose), ("[", T::BracketOpen), ("]", T::BracketClose),
    ("{", T::BraceOpen), ("}", T::BraceClose), ("{", T::BlockOpen), ("}", T::BlockClose),
    ("=>", T::Arm), ("==", T::EqualEqual), ("<", T::Less), ("=", T::Equal), ("+", T::Plus), ("-", T::Minus), ("/", T::Slash), (",", T::Comma),
];
static OPERATORS: [[TokenType; 4]; 128] = operators(SYMBOLS);
static KEYWORDS: Keywords = index(WORDS);

// reading 0 with each operator and its powers and the operator it applies
const ROWS: &[Row] = &[
    Row::new(T::Or, 4, 5, Emit::Lazy(false)),
    Row::new(T::EqualEqual, 10, 11, Emit::Op(Op::Cmp(Cmp::Eq))),
    Row::new(T::Less, 10, 11, Emit::Op(Op::Cmp(Cmp::Lt))),
    Row::new(T::Plus, 14, 15, Emit::Op(Op::Bin(BinOp::Add))),
    Row::new(T::Minus, 14, 15, Emit::Op(Op::Bin(BinOp::Sub))),
    Row::new(T::Slash, 16, 17, Emit::Op(Op::Bin(BinOp::FloorDiv))),
];

static GRAMMAR: Grammar = Grammar::PLAIN
    .readings(&[Reading::new(ROWS, &[])])
    .forms(&[Form::new("fix", &[Slot::Bind, Slot::Word("="), Slot::Expr(0), Slot::Word("up"), Slot::Word("to"), Slot::Expr(0), Slot::Body(0)], "steps")])
    .patterns(&[Pattern::new("ok", Test::Item(0, true), Some(1))])
    .lazy(&["any"]);

struct Fixes;

impl Spelling for Fixes {
    const SYNTAX: Syntax = Syntax::PLAIN
        .name("fixes")
        .extension("fix")
        .words(WORDS)
        .symbols(SYMBOLS)
        .operators(&OPERATORS)
        .keywords(&KEYWORDS)
        .comments(Comments::PLAIN.line(&["--"]))
        .shapes(Shapes::PLAIN
        .cond(Cond::None)
        .lambda(Lambda::None)
        .splat(false)
        .slices(false)
        .dot(Dot::Key)
        .decorators(false)
        .named(false)
        .binding(Binding::Optional)
        .arms(true)
        .grammar(Some(&GRAMMAR)))
        .strings(Strings::PLAIN
        .quotes(&[Quote::PLAIN])
        .escapes(Escapes::PLAIN.unicode(Unicode::Fixed).unknown(Unknown::Refuse)))
        .numbers(Numbers::PLAIN.zeros(Zeros::Refused).suffix(Suffix::Refused));
    const NATIVES: &'static Natives = &NATIVES;
}

// print and the lazy any that the grammar names
const TABLE: &[Native] = &interpreter::lib::table![Fixes; "print" => interpreter::lib::io::print, "any" => interpreter::lib::iter::fold::some];
static NATIVES: Natives = interpreter::natives! { language: Fixes, fns: [TABLE], methods: [], types: &[] };

impl interpreter::lib::Lang for Fixes {}

impl Language for Fixes {
    const VERSION: u32 = 1;
    const POLICY: Policy = Policy::PLAIN.int_overflow(Overflow::Error);
    const NATIVES: &'static Natives = &NATIVES;
    const NAMES: &'static Names = &Names::PLAIN;
    const FRONT: Front = FRONT;
    const DESCRIPTOR: &'static Descriptor = &Descriptor::PLAIN;
    type Ops = ();

    interpreter::lib::hooks!(Fixes; show);
}

const FRONT: Front = Front::spelled::<Fixes>();
static RUNTIME: Runtime = Runtime::of::<Fixes>();

const PROGRAM: &str = r#"
fn steps(x, n, f) = if n == 0 or f(x) == x { x } else { steps(f(x), n - 1, f) }
fn answer(r) = match r { ok v => v  _ => "failed" }
let _ = print(fix k = 1 up to 10 { if k < 50 { k + k } else { k } })
let _ = print(answer([true, 5]), answer([false, 5]))
let _ = print(any([n == 0 or 1 / (n - n) == 1 for n in [0, 1]]))
"#;

fn main() {
    let chunk = FRONT.compile(PROGRAM).unwrap_or_else(|errors| panic!("{}", interpreter::Diagnostic::render_all(&errors, PROGRAM, None)));
    let mut vm = VM::with_runtime(&RUNTIME, &chunk, Limits::sandbox());
    vm.run().expect("the program runs");
    assert_eq!(vm.output_text(), "64\n5 failed\ntrue\n");
}
```

`fix` doubles `k` until it passes 50 or ten steps run, so it prints `64`. The last line would divide by zero for `n = 1` if `any` built the whole list first, and it stops at the first true item instead.

## Reference

| Type | Parts | Means |
|---|---|---|
| `Grammar` | `readings`, `forms`, `patterns`, `lazy` | The operator tables, the forms, the pattern words and the calls whose lone comprehension runs as a generator |
| | `modifiers` | Words before an item, each with the function whose call wraps the item or `None`. A chunk keeps the words in `notes().decls` |
| | `unmatched` | The function a `match` calls when no arm takes its value |
| | `inner`, `tail` | A byte a name may hold inside, and one it may end with, such as `-` and `?` |
| `Reading` | `rows`, `words` | The operators of one reading of an expression, and words it reads as plain texts. Reading 0 reads plain values |
| `Row` | `tok`, `left`, `right`, `emit` | An operator and its binding powers, a zero `left` marks a prefix. `emit` is `Emit::Op(op)` with a `lang::Op` such as `Op::Bin(BinOp::Add)` or `Op::Not`, `Emit::Lazy(and)` for a short-circuit, or `Emit::Call(name)`. A row whose `Op` applies no operator, such as `Op::Len`, is refused |
| `Form` | `head`, `slots`, `call` | The word that leads the form, its parts in order, and the function it calls with them |
| `Pattern` | `word`, `test`, `part` | A word an arm tests its subject with, and the item its own pattern then matches |

A `Slot` is one part of a form after its head.

| Slot | Reads |
|---|---|
| `Word(w)` | The word `w`, and nothing is passed |
| `Name` | A bare name or dotted path, passed as its text |
| `Expr(k)` | An expression in reading `k` |
| `Opt(w, k)` | `w` then an expression in reading `k`, or `nil` without the word |
| `Tagged(tags, default)` | A bracketed expression handed to the call its leading word names, or to `default` |
| `Limits(w, pairs)` | After `w`, a list of names with counts, each led by its words, passed as `[name, count]` pairs. Words after a `_` in a pair, as in `"time _ s"`, follow the count |
| `Bind` and `Body(k)` | Names split by commas, then an expression in reading `k` passed as a function of those names |
| `Items(k)` | Braced expressions in reading `k`, split by line ends or `;`, passed as a list. An item `for p in xs, q in ys { ... }` gives the list of its own items for each pass |
| `Each(k)` | Generators `p in xs` split by commas in parentheses, then braced items as in `Items(k)`, passed as the list of the items of each pass |
| `At` | The byte offset of the head word, for error reports |

A `Test` is `Nil`, `NotNil`, `Item(index, bool)` or `Field(name, int)`, checked before the arm matches its `part`. An arm also takes a literal such as `-1` or `"a"`, a tuple `(a, b)`, and a list `[a, b]` that only matches a value with as many items. `Grammar::PLAIN` fills every setter an example leaves out.
