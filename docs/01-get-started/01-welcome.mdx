# Welcome

Edge Python is sandboxed Python, compiled to bytecode and run by a register VM written in Rust. One WebAssembly engine of about 250 KB runs it in browsers, in JavaScript runtimes and in the `edge` CLI.

The defaults deny everything. A program reaches no files, no network and no environment unless its host grants them. Imports resolve at compile time from `edge.json`, and a running program never loads code you did not declare.

## Try it

This program asks the GitHub API about the Edge Python repository and prints three of its fields. It runs on the real engine in your browser. Edit it and run it again.

```edge-manifest
{ "imports": { "json": "0.1.0" }, "permissions": { "main": ["net:api.github.com"] } }
```

```edge-python
import json
import net

r = net.request("GET", "https://api.github.com/repos/dylan-sutton-chavez/edge-python", {}, None)
status, headers = net.response(r)
body = b""
chunk = net.read(r)
while chunk is not None:
    body += chunk
    chunk = net.read(r)

repo = json.loads(body.decode())
print(repo["full_name"])
print(repo["language"])
print(repo["default_branch"])
```

```output
dylan-sutton-chavez/edge-python
Rust
main
```

Its `edge.json` declares the `json` package and grants the network for `api.github.com` alone. Any other host raises `PermissionError`. Every runnable example in these docs runs the same way.

## Questions

> [!QUESTION] Is it full Python?
> A program that compiles behaves as it does in CPython, apart from the choices below. What Edge Python leaves out is missing for the sandbox, like the standard library and `open`, or for the design of the engine, like `locals` and metaclasses. It fails with an error instead, at compile time whenever the compiler can see it. [Limits and errors](/docs/edge-python/reference/limits-and-errors#compile-time-errors) lists those errors and [Design](/docs/edge-python/internals/design#memory-model) explains the memory model behind them.

> [!QUESTION] Where does it behave differently on purpose?
> In three places. [Ints](/docs/edge-python/reference/limits-and-errors#integer-width) stop at 2^127. Sets iterate in [insertion order](/docs/edge-python/language/data-types#behavioral-notes). Every NaN is [one value](/docs/edge-python/internals/design#memory-model).

> [!QUESTION] Is there a standard library?
> No bundled one. Every module is an external package that `edge.json` declares. [Modules](/docs/edge-python/reference/modules) explains how imports resolve.

> [!QUESTION] Can a program run code it builds at run time?
> Yes, through `eval`, `exec` and `compile`. The text runs in the same sandbox under the same budget and grants, and it imports only packages the program resolved, so the set of packages is still fixed when the program compiles. [Dynamic code](/docs/edge-python/reference/builtins#dynamic-code) has the details.

> [!QUESTION] Can a program reach the network or the disk?
> Only what the root `edge.json` grants. Each grant names a module and a scope, such as one host for `net` or one folder for `fs`. [System](/docs/edge-python/reference/system) lists every scope.

> [!QUESTION] Where does it run?
> The [JavaScript host](/docs/edge-python/platforms/javascript) runs it in browsers and in runtimes with the same Web APIs, such as Deno. The [edge CLI](/docs/edge-python/platforms/cli) runs the same engine on macOS, Linux and WSL. [Rust](/docs/edge-python/platforms/rust) shows how to drive `compiler.wasm` from Rust code.

> [!QUESTION] Is there a summary for machine learning models?
> Yes. A model can load [skill/SKILL.md](https://github.com/dylan-sutton-chavez/edge-python/blob/main/skill/SKILL.md) for a self-verifying summary of the language and the CLI.
