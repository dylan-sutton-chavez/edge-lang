# Mini, a scripting language

Mini is the reference runtime of Edge Lang. The engine's corpus of 5,302 programs in `tests/cases/vm` runs in it, `edge.wasm` is built from it and the `edge` CLI embeds it. It is about 1,500 lines of Rust in `examples/mini`, a token table, its rules, the natives it takes from lib under its own names and the words of its errors.

This page runs one real job in mini, five reports over an hour of public GitHub events, then shows each part of the runtime. [Tiny](./03-tiny.mdx) runs the same job as a YAML flow over the same hour, and [Your runtime and its CLI](./01-your-runtime.mdx) builds a runtime of your own.

## The job

GH Archive publishes every public GitHub event, one gzipped file of JSON lines per hour. The job reads the hour from 3 pm to 4 pm UTC on 1 October 2026, 85,569 events in 19.4 MB, and writes five reports with the events of bots left out.

| Report | Holds |
|---|---|
| `top_stars` | The ten repositories starred most in the hour |
| `busy_branches` | Each branch pushed to more than once |
| `activity.csv` | The events of each minute by type, as CSV |
| `issues_opened` | The issues opened in each repository |
| `time_to_close` | The hours an issue stayed open, averaged for each repository over the issues closed in the hour |

```edge file=examples/data/github-hour.mini
import net

// one hour of public GitHub events which GH Archive serves gzipped
HOUR = 'https://data.gharchive.org/2026-10-01-15.json.gz'

// the character each one letter escape of a JSON string stands for
ESCAPED = {'"': '"', '\\': '\\', '/': '/', 'b': '\b', 'f': '\f', 'n': '\n', 'r': '\r', 't': '\t'}

// the bytes that end a bare JSON value
BREAKS = '{}[],: \t\r\n'

// the body of a JSON string with each escape read
fn unescape(s):
    out = []
    i = 0
    while true:
        j = s.find('\\', i)
        if j < 0:
            out.append(s[i:])
            return ''.join(out)
        out.append(s[i:j])
        c = s[j + 1]
        if c != 'u':
            out.append(ESCAPED[c])
            i = j + 2
            continue
        code = int(s[j + 2:j + 6], 16)
        i = j + 6
        // a high surrogate takes the low one that must follow it
        if 0xD800 <= code && code < 0xDC00 && s[i:i + 2] == '\\u':
            low = int(s[i + 2:i + 6], 16)
            if 0xDC00 <= low && low < 0xE000:
                code = 0x10000 + ((code - 0xD800) << 10) + (low - 0xDC00)
                i += 6
        if 0xD800 <= code && code < 0xE000:
            raise ValueError(f'lone surrogate in {s!r}')
        out.append(chr(code))

// a bare JSON value as a mini value
fn literal(word):
    if word == 'true':
        return true
    if word == 'false':
        return false
    if word == 'null':
        return nil
    if '.' in word || 'e' in word || 'E' in word:
        return float(word)
    return int(word)

// one line of JSON read with its containers on a stack of their own
fn read_json(line):
    pieces = line.split('"')
    root = []
    top = root
    in_map = false
    want_key = false
    key = nil
    stack = []
    i = 0
    n = len(pieces)
    while i < n:
        text = pieces[i]
        i += 1
        if text == ':':
            want_key = false
        else if text == ',':
            want_key = in_map
        else:
            start = -1
            j = 0
            m = len(text)
            while j <= m:
                c = text[j] if j < m else ' '
                if c !in BREAKS:
                    if start < 0:
                        start = j
                    j += 1
                    continue
                if start >= 0:
                    v = literal(text[start:j])
                    start = -1
                    if in_map:
                        top[key] = v
                    else:
                        top.append(v)
                if c == '{' || c == '[':
                    child = {} if c == '{' else []
                    if in_map:
                        top[key] = child
                    else:
                        top.append(child)
                    stack.append((top, in_map, key))
                    top = child
                    in_map = c == '{'
                    want_key = in_map
                else if c == '}' || c == ']':
                    top, in_map, key = stack.pop()
                else if c == ',':
                    want_key = in_map
                else if c == ':':
                    want_key = false
                j += 1
        if i == n:
            break
        s = pieces[i]
        i += 1
        // a quote after an odd run of backslashes belongs to the string
        while s.endswith('\\') && (len(s) - len(s.rstrip('\\'))) % 2 == 1:
            s = s + '"' + pieces[i]
            i += 1
        if '\\' in s:
            s = unescape(s)
        if want_key:
            key = s
        else if in_map:
            top[key] = s
        else:
            top.append(s)
    if len(root) != 1 || len(stack) != 0:
        raise ValueError(f'a line holds no one JSON value {line[:60]!r}')
    return root[0]

stars = {}
busy = {}
activity = {}
opened = {}
closing = {}

// one event's part of every report with the bots left out
fn tally(e):
    if e['actor']['login'].endswith('[bot]'):
        return
    kind = e['type']
    minute = (e['created_at'][11:16], kind)
    activity[minute] = activity.get(minute, 0) + 1
    // only the reports that name a repository read it since some events carry none
    if kind == 'WatchEvent':
        repo = e['repo']['name']
        stars[repo] = stars.get(repo, 0) + 1
    else if kind == 'PushEvent':
        branch = (e['repo']['name'], e['payload']['ref'].removeprefix('refs/heads/'))
        busy[branch] = busy.get(branch, 0) + 1
    else if kind == 'IssuesEvent':
        action = e['payload']['action']
        if action == 'opened':
            repo = e['repo']['name']
            opened[repo] = opened.get(repo, 0) + 1
        else if action == 'closed':
            repo = e['repo']['name']
            issue = e['payload']['issue']
            hours = (time(issue['closed_at']) - time(issue['created_at'])).hours
            total, n = closing.get(repo, (0.0, 0))
            closing[repo] = (total + hours, n + 1)

r = net.request('GET', HOUR, nil, nil, 'gzip')
status, headers = net.response(r)
if status != 200:
    raise OSError(f'{HOUR} answered {status}, not 200')
// the bytes after the last line end wait for the next chunk
rest = b''
chunk = net.read(r)
while chunk is !nil:
    lines = (rest + chunk).split(b'\n')
    rest = lines.pop()
    for line in lines:
        if len(line):
            tally(read_json(line.decode()))
    chunk = net.read(r)
if len(rest):
    tally(read_json(rest.decode()))

print('top_stars')
for repo, n in sorted(stars.items(), key=lambda kv: kv[1], reverse=true)[:10]:
    print(f'{n:>6}  {repo}')
print('busy_branches')
for (repo, branch), n in busy.items():
    if n > 1:
        print(f'{n:>6}  {repo} {branch}')
print('activity.csv')
print('minute,type,count')
for (minute, kind), n in activity.items():
    print(f'{minute},{kind},{n}')
print('issues_opened')
for repo, n in opened.items():
    print(f'{n:>6}  {repo}')
print('time_to_close')
for repo, (total, n) in closing.items():
    print(f'{total / n:>8.2f}  {repo}')
```

The job reads the hour through the net plugin a chunk at a time and never holds it whole. It cuts each chunk into lines, keeps the bytes after the last line end for the next chunk and reads each line that holds bytes with `read_json`, a JSON reader the job writes in mini over `split`, `find` and slices. It asks a line for its length first, since an empty buffer reads as true under [the engine's own rules](../04-book/04-rules.mdx#the-engines-own-rules). The reports are maps keyed by tuples, `sorted` ranks the stars and `time` reads the two times of an issue, whose difference is a duration with its `hours`.

Only the reports that name a repository read it, since one event of the hour carries an empty `repo`. It is a ForkEvent 28 minutes into the hour, and reading every event's repository first would stop the run there with a `KeyError`.

## What it may reach

The grant names the one host the job reads. A project that grants another host stops the run at its request, before a byte leaves, with the host it asked for and the ones it holds.

```text
$ edge run --ops 100000000000 github-hour.mini
error: PermissionError: 'main' has no net:data.gharchive.org, edge.json grants it net:api.github.com
    --> github-hour.mini:156:1
    |
156 | r = net.request('GET', HOUR, nil, nil, 'gzip')
    | ^
```

A project whose `edge.json` grants nothing of `net` stops earlier, at `import net`, with `'main' imports net, which edge.json does not grant it`.

## Its surface

Mini's table spells the engine's one grammar. A header ends in a colon and its block is the indented lines after it. `fn` defines a function, `true`, `false` and `nil` are the three constants, `&&`, `||` and `!` are the logic, `else if` is the second branch of an `if` and `//` starts a comment, so integer division is `~/`. `is !` and `!in` negate `is` and `in`, as `while chunk is !nil` and `c !in BREAKS` do in the job.

## How it prints

Mini prints the three constants it reads as `true`, `false` and `nil` as `True`, `False` and `None`, and a text inside a container in single quotes. Ints grow without bound and a float prints the shortest digits that read back as it. A map keeps the order its keys first came in, which is the order the job prints `busy_branches`, `activity.csv` and the other reports of a map in.

```rust file=examples/mini/src/style.rs
use alloc::string::String;

use edge::lang::ErrKind;
use lib::fmt::render::{Escape, Floats, Style, hex};

use crate::{DESCRIPTOR, Mini, NAMES};

/* the ` at 0x` a text places an object by */
fn at(out: &mut String, a: u64) { out.push_str(" at "); hex(out, a); }

impl Style for Mini {
    const TRUE: &'static str = "True";
    const FALSE: &'static str = "False";
    const QUOTE: char = '\'';
    const SWITCH: Option<char> = Some('"');
    const ESCAPE: Escape = Escape::Fixed;
    const BYTES: &'static str = "b";
    const BUFFER: (&'static str, &'static str) = ("bytearray(", ")");
    const EMPTY_SET: &'static str = "set()";
    const ONE: &'static str = ",)";
    const FLOATS: Floats = Floats { nan: "nan", inf: "inf", neg_inf: "-inf", low: -3, high: 16, plus: true, width: 2, point: true };
    const AGAIN: &'static str = "...";
    const BOUND: (&'static str, &'static str, &'static str) = ("<bound method ", " of ", ">");
    const SLICE: (&'static str, &'static str, &'static str) = ("slice(", ", ", ")");
    const NUMBERED: (&'static str, &'static str, &'static str) = ("[Errno ", "] ", ": ");

    fn type_form(out: &mut String, name: &str) { out.push_str("<class '"); out.push_str(name); out.push_str("'>"); }

    fn native_form(out: &mut String, name: &str) { out.push_str("<built-in function "); out.push_str(name); out.push('>'); }

    fn method_form(out: &mut String, name: &str, kind: &str) {
        out.push_str("<method '");
        out.push_str(name);
        out.push_str("' of '");
        out.push_str(kind);
        out.push_str("' objects>");
    }

    fn bound_native_form(out: &mut String, name: &str, ty: &str, a: u64) {
        out.push_str("<built-in method ");
        out.push_str(name);
        out.push_str(" of ");
        out.push_str(ty);
        out.push_str(" object");
        at(out, a);
        out.push('>');
    }

    fn object_form(out: &mut String, ty: &str, a: u64) { out.push('<'); out.push_str(ty); out.push_str(" object"); at(out, a); out.push('>'); }

    fn module_form(out: &mut String, name: &str) { out.push_str("<module '"); out.push_str(name); out.push_str("'>"); }

    fn extern_form(out: &mut String, name: &str) { out.push_str("<extern function "); out.push_str(name); out.push('>'); }

    fn function_form(out: &mut String, name: &str, a: u64) { out.push_str("<function "); out.push_str(name); at(out, a); out.push('>'); }

    fn class_form(out: &mut String, name: &str) { out.push_str("<class '__main__."); out.push_str(name); out.push_str("'>"); }

    fn instance_form(out: &mut String, name: &str, a: u64) { out.push_str("<__main__."); out.push_str(name); out.push_str(" object"); at(out, a); out.push('>'); }

    fn coroutine_form(out: &mut String, ty: &str, name: &str, a: u64) {
        out.push('<');
        out.push_str(ty);
        out.push_str(" object ");
        out.push_str(name);
        at(out, a);
        out.push('>');
    }

    fn cell_form(out: &mut String, a: u64, held: Option<(&str, u64)>) {
        out.push_str("<cell");
        at(out, a);
        match held {
            None => out.push_str(": empty>"),
            Some((ty, h)) => { out.push_str(": "); out.push_str(ty); out.push_str(" object"); at(out, h); out.push('>'); }
        }
    }

    fn range_form(out: &mut String, start: &str, stop: &str, step: Option<&str>) {
        out.push_str("range(");
        if start == Self::AGAIN { return out.push_str("...)"); }
        out.push_str(start);
        out.push_str(", ");
        out.push_str(stop);
        if let Some(st) = step { out.push_str(", "); out.push_str(st); }
        out.push(')');
    }

    fn keyed(name: &str) -> bool { name == NAMES.error(ErrKind::Key) }

    // the class a failed host call raises and its children carry an error number
    fn numbered(name: &str) -> bool { crate::types::TREE.derives(name, DESCRIPTOR.failed_error) }
}
```

## Its natives

Each native is a kernel of lib under the name mini gives it, grouped by kind. `print` and `input` come from `io`, `len` and `sorted` from `seq`, `time` from `date`, and the methods of each kind come from the module that holds that kind.

## Its errors

Mini names 31 error classes, each beside its parent, and the engine and lib raise those names. An error prints its class and its words, the line it rose at and each call it passed through, as the budget error above does.

```rust file=examples/mini/src/types.rs
use lib::lang::Tree;

use crate::Mini;

// the builtin types besides the exceptions
const PLAIN: [&str; 14] = ["int", "float", "str", "bytes", "bytearray", "bool", "list", "tuple", "dict", "set", "range", "type", "NoneType", "object"];

// each builtin exception beside its parent with the root's parent empty
pub(crate) const CLASSES: [(&str, &str); 31] = [
    ("OSError", "Exception"),
    ("EOFError", "Exception"), ("KeyError", "LookupError"),
    ("Exception", "BaseException"), ("NameError", "Exception"), ("TypeError", "Exception"),
    ("IndexError", "LookupError"), ("SystemExit", "BaseException"), ("ValueError", "Exception"),
    ("ImportError", "Exception"), ("LookupError", "Exception"), ("MemoryError", "Exception"), ("SyntaxError", "Exception"),
    ("RuntimeError", "Exception"), ("TimeoutError", "OSError"), ("UnicodeError", "ValueError"),
    ("BaseException", ""), ("GeneratorExit", "BaseException"), ("OverflowError", "ArithmeticError"), ("StopIteration", "Exception"),
    ("AssertionError", "Exception"), ("AttributeError", "Exception"), ("RecursionError", "RuntimeError"),
    ("ArithmeticError", "Exception"), ("PermissionError", "OSError"),
    ("UnboundLocalError", "NameError"), ("ZeroDivisionError", "ArithmeticError"),
    ("UnicodeDecodeError", "UnicodeError"), ("UnicodeEncodeError", "UnicodeError"),
    ("ModuleNotFoundError", "ImportError"), ("NotImplementedError", "RuntimeError"),
];

// the classes the type tests walk as mini's names give them
pub static TREE: Tree = Tree::of::<Mini>();

// the names a load gives as type objects
pub const NAMES: &[&str] = &names::<{ PLAIN.len() + CLASSES.len() }>();

/* the plain types then every exception of the tree */
const fn names<const N: usize>() -> [&'static str; N] {
    let mut out = [""; N];
    let mut i = 0;
    while i < PLAIN.len() { out[i] = PLAIN[i]; i += 1; }
    let mut j = 0;
    while j < CLASSES.len() { out[i + j] = CLASSES[j].0; j += 1; }
    out
}
```

```rust file=examples/mini/src/words.rs
            let span = if len == 1 { joined(&["byte 0x", &hex2(first), " in position ", itoa::Buffer::new().format(i)]) } else { joined(&["bytes in position ", itoa::Buffer::new().format(i), "-", itoa::Buffer::new().format(i + len - 1)]) };
            raised::<Mini>(Class::Decode, &["'", Mini::codec_name(codec), "' codec can't decode ", &span, ": ", coding(codec, why)])
        }
        Fail::BadJson { at: i, why } => raised::<Mini>(Class::Value, &["invalid JSON at byte ", itoa::Buffer::new().format(i), ": ", why.words()]),
        Fail::NotJson { v, why } => VmErr::TypeMsg(joined(&[name, "(): '", ty(v), "' ", why.words()])),
        Fail::BadCsv { at: i, why } => raised::<Mini>(Class::Value, &["invalid CSV at byte ", itoa::Buffer::new().format(i), ": ", why.words()]),
        Fail::FieldOf { recv, want } => VmErr::TypeMsg(joined(&["'", name, "' applies to '", want, "' values, not '", ty(recv), "'"])),
        Fail::IntMissing => VmErr::TypeMsg(joined(&[name, "() is missing a positional argument"])),
        Fail::IntArg(v) => VmErr::TypeMsg(joined(&[name, "() argument must be a string, a bytes-like object or a real number, not '", ty(v), "'"])),
        Fail::IntBaseType | Fail::StartType => VmErr::TypeMsg(joined(&[name, "() ", at.param(1), " must be an integer"])),
        Fail::IntBase => raised::<Mini>(Class::Value, &[name, "() ", at.param(1), " must be >= 2 and <= 36, or 0"]),
        Fail::IntExplicitBase => VmErr::TypeMsg(joined(&[name, "() can't convert non-string with explicit ", at.param(1)])),
        Fail::FloatArg(v) => VmErr::TypeMsg(joined(&[name, "() argument must be a string or a real number, not '", ty(v), "'"])),
        Fail::FloatNan => VmErr::Value("cannot convert float NaN to integer"),
        Fail::FloatInf => raise::<Mini>(Class::Overflow, "cannot convert float infinity to integer"),
        Fail::RoundArg => VmErr::TypeMsg(joined(&[name, "() requires a number"])),
        Fail::RoundRange => raise::<Mini>(Class::Overflow, "rounded value too large to represent"),
        Fail::PowArgs => VmErr::TypeMsg(joined(&[name, "() requires numeric operands"])),
        Fail::PowThird => VmErr::TypeMsg(joined(&[name, "() 3rd argument not allowed unless all arguments are integers"])),
        Fail::PowZero => raised::<Mini>(Class::Value, &[name, "() 3rd argument cannot be 0"]),
        Fail::PowInverse => VmErr::Value("base is not invertible for the given modulus"),
        Fail::ExtremeEmpty => raised::<Mini>(Class::Value, &[name, "() iterable argument is empty"]),
        Fail::PairNotIterable => VmErr::Type("object is not iterable"),
        Fail::PairLength { at: i, len } => raised::<Mini>(Class::Value, &["dictionary update sequence element #", itoa::Buffer::new().format(i), " has length ", itoa::Buffer::new().format(len), "; 2 is required"]),
        Fail::RangeArgs => VmErr::TypeMsg(joined(&[name, "() takes 1 to 3 arguments"])),
        Fail::ZeroStep => raised::<Mini>(Class::Value, &[name, "() arg 3 must not be zero"]),
        Fail::IterCallable => VmErr::TypeMsg(joined(&[name, "(v, w): v must be callable"])),
        Fail::SortCount(n) => VmErr::TypeMsg(joined(&[name, "() takes at most 2 arguments (", itoa::Buffer::new().format(n), " given)"])),
        Fail::SortPositional => VmErr::TypeMsg(joined(&[name, "() takes no positional arguments"])),
        Fail::SortKeyword(k) => {
            let hint = edge::util::suggest::did_you_mean(&k, at.keywords.iter().copied());
            VmErr::TypeMsg(joined(&[name, "() got an unexpected keyword argument '", &k, "'", &hint]))
        }
        Fail::ByteOrder => VmErr::Value("byteorder must be 'little' or 'big'"),
        Fail::LengthNegative => VmErr::Value("length argument must be non-negative"),
        Fail::LengthType => VmErr::Type("length must be an integer"),
        Fail::TakeType => VmErr::TypeMsg(joined(&["n must be an integer or ", NIL])),
        Fail::BytesFirst => VmErr::TypeMsg(joined(&[name, "() first arg must be ", kind(KindId::Bytes)])),
        Fail::Spec(why) => spec(why),
        Fail::SpecInvalid { spec, v } => raised::<Mini>(Class::Value, &["Invalid format specifier '", &spec, "' for object of type '", ty(v), "'"]),
        Fail::SpecUnknown { code, v } => raised::<Mini>(Class::Value, &["Unknown format code '", &*(code).encode_utf8(&mut [0u8; 4]), "' for object of type '", ty(v), "'"]),
        Fail::SpecWidth => VmErr::Value("format width exceeds limit"),
        Fail::SpecPrecision => VmErr::Value("format precision exceeds limit"),
        Fail::EndOfInput => raise::<Mini>(Class::End, "EOF when reading a line"),
        Fail::ExitCode(v) => VmErr::TypeMsg(joined(&[name, "() expects an ", kind(KindId::Int), ", not ", ty(v)])),
        Fail::SendText(i) => VmErr::TypeMsg(joined(&[name, "() expects a ", kind(KindId::Str), " at argument ", itoa::Buffer::new().format(i)])),
        Fail::NoScheduler => raised::<Mini>(Class::Runtime, &[name, "() needs an actor scheduler, missing in this runtime"]),
        f => words_bare(f),
    }
}

/* mini's words for failures raised with no running call */
pub fn words_bare(f: Fail) -> VmErr {
    match f {
        Fail::Spec(Spec::CharWide) => raise::<Mini>(Class::Overflow, "Python int too large to convert to C long"),
        Fail::NegativeUnsigned => raise::<Mini>(Class::Overflow, "can't convert negative int to unsigned"),
        Fail::TooBig => raise::<Mini>(Class::Overflow, "int too big to convert"),
        Fail::WideToFloat => raise::<Mini>(Class::Overflow, "int too large to convert to float"),
        Fail::WideDivFloat => raise::<Mini>(Class::Overflow, "integer division result too large for a float"),
        Fail::NegativeShift => VmErr::Value("negative shift count"),
        Fail::ShiftDigits => raise::<Mini>(Class::Overflow, "too many digits in integer"),
        Fail::ZeroNegativePower => raise::<Mini>(Class::ZeroDiv, "zero to a negative power"),
        Fail::TimeRange => VmErr::Value("time out of range"),
        Fail::DurationRange => VmErr::Value("duration out of range"),
        Fail::HandlerArg => VmErr::Type("a handler must name a class or a tuple of classes"),
        Fail::Spec(why) => spec(why),
        Fail::Digits(count) => {
            let limit = Mini::DIGITS.unwrap_or(0);
            match count {
                Some(n) => raised::<Mini>(Class::Value, &["Exceeds the limit (", itoa::Buffer::new().format(limit), " digits) for integer string conversion: value has ", itoa::Buffer::new().format(n), " digits"]),
                None => raised::<Mini>(Class::Value, &["Exceeds the limit (", itoa::Buffer::new().format(limit), " digits) for integer string conversion"]),
            }
        }
        f => VmErr::TypeMsg(alloc::format!("{f:?}")),
    }
}

/* mini's words for why `codec` could not write or read a span */
fn coding(codec: Codec, why: Coding) -> &'static str {
    match why {
        Coding::Unmapped => match codec { Codec::Ascii => "ordinal not in range(128)", Codec::Latin1 => "ordinal not in range(256)", _ => "character maps to <undefined>" },
        Coding::End => "unexpected end of data",
        Coding::Start => "invalid start byte",
        Coding::Continuation => "invalid continuation byte",
        Coding::Truncated => "truncated data",
        Coding::Surrogate => "illegal UTF-16 surrogate",
        Coding::LowFirst => "illegal encoding",
        Coding::SurrogateRange => "code point in surrogate code point range(0xd800, 0xe000)",
        Coding::PastUnicode => "code point not in range(0x110000)",
    }
}

/* the words of a refused format spec */
fn spec(why: Spec) -> VmErr {
    let sep = |b: u8| char::from(b);
    match why {
        Spec::ZeroInText => VmErr::Value("Negative zero coercion (z) not allowed in string format specifier"),
        Spec::ZeroInInt => VmErr::Value("Negative zero coercion (z) not allowed in integer format specifier"),
        Spec::AltWithChar => VmErr::Value("Alternate form (#) not allowed with integer format specifier 'c'"),
        Spec::SignWithChar => VmErr::Value("Sign not allowed with integer format specifier 'c'"),
        Spec::AltInText => VmErr::Value("Alternate form (#) not allowed in string format specifier"),
        Spec::SpaceInText => VmErr::Value("Space not allowed in string format specifier"),
        Spec::SignInText => VmErr::Value("Sign not allowed in string format specifier"),
        Spec::EqInText => VmErr::Value("'=' alignment not allowed in string format specifier"),
        Spec::PrecisionInInt => VmErr::Value("Precision not allowed in integer format specifier"),
        Spec::SepWith(s, t) => raised::<Mini>(Class::Value, &["Cannot specify '", &*(sep(s)).encode_utf8(&mut [0u8; 4]), "' with '", &*(sep(t)).encode_utf8(&mut [0u8; 4]), "'."]),
        Spec::SepTwice(s) => raised::<Mini>(Class::Value, &["Cannot specify '", &*(sep(s)).encode_utf8(&mut [0u8; 4]), "' with '", &*(sep(s)).encode_utf8(&mut [0u8; 4]), "'."]),
        Spec::SepBoth => VmErr::Value("Cannot specify both ',' and '_'."),
        Spec::BadWidth => VmErr::Value("invalid width in format spec"),
        Spec::BadPrecision => VmErr::Value("invalid precision in format spec"),
        Spec::MissingPrecision => VmErr::Value("missing precision in format spec"),
        Spec::BadType => VmErr::Value("invalid type in format spec"),
        Spec::NeedsInt => VmErr::Value("format spec requires an integer"),
        Spec::NeedsNumber => VmErr::Value("format spec requires a number"),
        Spec::CharNeedsInt => VmErr::Value("'c' format spec requires an integer"),
        Spec::CharRange => raise::<Mini>(Class::Overflow, "%c arg not in range(0x110000)"),
        Spec::CharWide => raise::<Mini>(Class::Overflow, "int too large for a character"),
        Spec::CharInvalid => VmErr::Value("'c' format spec arg not a valid char"),
    }
}

/* the repr of `v` as mini renders it */
fn repr(cx: &mut Cx<'_, '_>, v: Val) -> Result<String, VmErr> { Mini::show(cx, v, Mode::Repr) }

/* a byte as two lowercase hex digits */
fn hex2(b: u8) -> String {
    let digits = b"0123456789abcdef";
    let mut out = String::with_capacity(2);
    out.push(char::from(digits[(b >> 4) as usize]));
    out.push(char::from(digits[(b & 15) as usize]));
    out
}

/* a character a codec failure quotes as its shortest hex escape */
fn escaped(c: char) -> String {
    let n = c as u32;
    if n < 0x100 { alloc::format!("'\\x{n:02x}'") } else if n < 0x10000 { alloc::format!("'\\u{n:04x}'") } else { alloc::format!("'\\U{n:08x}'") }
}

// methods whose count errors word the parameters past their positional ones
const TAKES: &[&str] = &["replace", "hex", "sort"];

/* the words of a call that misses a native's signature */
pub fn arity(n: &Native, owner: Option<&str>, m: Misfit<'_>) -> VmErr {
    VmErr::TypeMsg(match owner {
        Some(ty) => method_words(n, ty, m),
        None => function_words(n, m),
    })
}

fn function_words(n: &Native, m: Misfit<'_>) -> String {
    let name = n.name;
    let (lo, hi) = (n.sig.min as i64, if n.sig.max == VAR { i64::MAX } else { n.sig.max as i64 });
    match m {
        Misfit::Count(got) => {
            let got = got as i64;
            if lo == hi && lo == 0 { return s!(str name, "() takes no arguments (", int got, " given)"); }
            if lo == hi && lo == 1 { return s!(str name, "() takes exactly one argument (", int got, " given)"); }
            if lo == hi { return s!(str name, " expected ", int lo, " arguments, got ", int got); }
            let (word, bound) = if got < lo { ("least", lo) } else { ("most", hi) };
            s!(str name, " expected at ", str word, " ", int bound, " argument", str if bound == 1 { "" } else { "s" }, ", got ", int got)
        }
        Misfit::Unexpected(_) if !n.sig.keywords() => s!(str name, "() takes no keyword arguments"),
        Misfit::Unexpected(k) if !n.sig.kw.is_empty() => s!(str name, "() got an unexpected keyword argument '", str k, "'"),
        Misfit::Unexpected(k) => s!("'", str k, "' is an invalid keyword argument for ", str name, "()"),
        Misfit::Twice(k) => s!(str name, "() got multiple values for argument '", str k, "'"),
        Misfit::Missing(_) => s!(str name, "() is missing a positional argument"),
    }
}

fn method_words(n: &Native, ty: &str, m: Misfit<'_>) -> String {
    let name = n.name;
    let named = n.sig.names.iter().any(|p| !p.is_empty()) || !n.sig.kw.is_empty();
    match m {
        Misfit::Count(got) => {
            let (min, max, got) = (n.sig.min as i64, n.sig.max as i64, got as i64);
            let args = |k: i64| if k == 1 { "argument" } else { "arguments" };
            if min == max && min <= 1 {
                return s!(str ty, ".", str name, str if min == 0 { "() takes no arguments (" } else { "() takes exactly one argument (" }, int got, " given)");
            }
            if TAKES.contains(&name) || named {
                return match n.sig.names.get(got as usize).filter(|p| !p.is_empty() && got < min) {
                    Some(p) => s!(str name, "() missing required argument '", str p, "' (pos ", int got + 1, ")"),
                    None if got < min => s!(str name, "() takes at least ", int min, " positional ", str args(min), " (", int got, " given)"),
                    None => s!(str name, "() takes at most ", int max, " ", str args(max), " (", int got, " given)"),
                };
            }
            let (word, k) = if min == max { ("", min) } else if got < min { ("at least ", min) } else { ("at most ", max) };
            s!(str name, " expected ", str word, int k, " ", str args(k), ", got ", int got)
        }
        Misfit::Unexpected(_) if !n.sig.keywords() => s!(str ty, ".", str name, "() takes no keyword arguments"),
        Misfit::Unexpected(k) => {
            let hint = edge::util::suggest::did_you_mean(k, n.sig.names.iter().chain(n.sig.kw).copied().filter(|p| !p.is_empty()));
            s!(str name, "() got an unexpected keyword argument '", str k, "'", str &hint)
        }
        Misfit::Twice(k) => s!("argument for ", str ty, ".", str name, "() given by name ('", str k, "') and position"),
        Misfit::Missing(i) => match n.sig.names.get(i).filter(|p| !p.is_empty()) {
            Some(p) => s!(str name, "() missing required argument '", str p, "' (pos ", int i as i64 + 1, ")"),
            None => s!(str name, "() is missing a positional argument"),
        },
    }
}
```

So are the words of the engine's own errors, in its `Language` beside the rules its corpus runs on, as [Errors](../04-book/05-errors.mdx#how-a-runtime-words-them) covers. `map_fields` stays off for now, since reading a missing field off a map's keys puts a call on every attribute miss, as [What a rule costs](../04-book/04-rules.mdx#what-a-rule-costs) measures.

```rust file=examples/mini/src/language.rs
/* every engine error in the words the corpus reads */
fn message(cx: &mut Cx<'_, '_>, e: &EngineError) -> String {
    use EngineError as E;
    match e {
        &E::Unsupported { op, a, b } => unsupported(cx, op, a, b),
        &E::Cannot { act, recv } => cannot(cx, act, recv),
        &E::BadIndex { recv, index } => match cx.kind(recv) {
            KindId::Str => s!("string indices must be integers, not '", str cx.type_name(index), "'"),
            // bytes name their index as one byte as the corpus reads them
            KindId::Bytes => s!("byte indices must be integers or slices, not ", str cx.type_name(index)),
            _ => s!(str cx.type_name(recv), " indices must be integers or slices, not ", str cx.type_name(index)),
        },
        E::BadSlice { step: true, .. } => String::from("slice step must be an integer"),
        E::BadSlice { .. } => s!("slice indices must be integers or ", str NAMES.nil, " or have an ", str NAMES.index_method, " method"),
        &E::OutOfRange { recv, store } => String::from(match (cx.kind(recv), store) {
            (KindId::List, true) => "list assignment index out of range",
            (KindId::List, false) => "list index out of range",
            (KindId::Tuple, _) => "tuple index out of range",
            (KindId::Str, _) => "string index out of range",
            (KindId::Range, _) => "range object index out of range",
            (KindId::ByteArray, _) => "bytearray index out of range",
            _ => "index out of range",
        }),
        E::TooWide(_) => s!("cannot fit '", str NAMES.kind(KindId::Int), "' into an index-sized integer"),
        &E::MissingKey(k) => cx.render(k, Mode::Repr).unwrap_or_default(),
        E::Changed(KindId::Set) => String::from("Set changed size during iteration"),
        E::Changed(_) => String::from("dictionary changed size during iteration"),
        E::ZeroStep { range: true } => s!(str NAMES.kind(KindId::Range), "() arg 3 must not be zero"),
        E::ZeroStep { range: false } => String::from("slice step cannot be zero"),
        E::Arity { callee, fit } => arity(cx, callee, fit),
        E::Call(f) => call_fault(cx, f),
        E::Undefined(n) => s!("name '", str n, "' is not defined"),
        E::Unbound { name: Some(n), free: false } => s!("cannot access local variable '", str n, "' where it is not associated with a value"),
        E::Unbound { name: Some(n), free: true } => s!("cannot access free variable '", str n, "' where it is not associated with a value in enclosing scope"),
        E::Unbound { name: None, .. } => String::from("cannot access a local variable that is not associated with a value"),
        E::NoAttribute { recv, name, store: true } => s!("'", str cx.type_name(*recv), "' object has no attribute '", str name, "' and no __dict__ for setting new attributes"),
        E::NoAttribute { recv, name, .. } => match cx.heap().try_get(*recv) {
            Some(HeapObj::Module(module, _)) => s!("module '", str module, "' has no attribute '", str name, "'"),
            _ if cx.heap().is_class(*recv) => s!("type object '", str cx.heap().class_name(*recv).unwrap_or(""), "' has no attribute '", str name, "'"),
            _ => s!("'", str cx.type_name(*recv), "' object has no attribute '", str name, "'"),
        },
        E::ReadOnly { recv, name, lock } => match lock {
            Lock::Type => match cx.heap().type_object_name(*recv) {
                Some(t) => s!("cannot set '", str name, "' attribute of immutable type '", str t, "'"),
                None => s!("cannot set '", str name, "' attribute of immutable type '", str cx.type_name(*recv), "'"),
            },
            Lock::Native => s!("'", str cx.type_name(*recv), "' object attribute '", str name, "' is read-only"),
            Lock::Fixed => String::from("readonly attribute"),
            Lock::Plain => s!("attribute '", str name, "' of '", str cx.type_name(*recv), "' objects is not writable"),
        },
        E::ZeroDiv => String::from("division by zero"),
        E::ZeroPow => String::from("zero to a negative power"),
        E::Overflow => String::from(NAMES.overflow),
        E::FloatRange => String::from("(34, 'Numerical result out of range')"),
        E::NegativeShift => String::from("negative shift count"),
        E::ByteRange => String::from("byte must be in range(0, 256)"),
        &E::Unpack { want, got, more: false, rest } => s!("not enough values to unpack (expected ", str if rest { "at least " } else { "" }, int want as i64, ", got ", int got.unwrap_or(0) as i64, ")"),
        &E::Unpack { want, got: Some(g), .. } => s!("too many values to unpack (expected ", int want as i64, ", got ", int g as i64, ")"),
        &E::Unpack { want, got: None, .. } => s!("too many values to unpack (expected ", int want as i64, ")"),
        &E::SliceSize { size, span } => s!("attempt to assign sequence of size ", int size as i64, " to extended slice of size ", int span as i64),
        &E::Uneven { arg, longer } => {
            let before = if arg == 1 { String::from("argument 1") } else { s!("arguments 1-", int i64::from(arg)) };
            s!(str cx.names().iters[edge::lang::iters::ZIP], "() argument ", int i64::from(arg) + 1, str if longer { " is longer than " } else { " is shorter than " }, str &before)
        }
        E::Generator(g) => generator(g),
        E::Pattern(p) => match p {
            &Pattern::OnePositional(subject) => s!(str cx.type_name(subject), "() accepts 1 positional sub-pattern"),
            Pattern::NoFields => s!("class pattern accepts no positional sub-patterns without ", str NAMES.fields.match_args),
            Pattern::TooMany => s!("class pattern got more positional sub-patterns than ", str NAMES.fields.match_args),
        },
        &E::Stop(v) | &E::Exit(v) | &E::Assert(v) => if v.is_undef() || v.is_none() { String::new() } else { cx.render(v, Mode::Str).unwrap_or_default() },
        E::Close => String::new(),
        E::Recursion => String::from("maximum recursion depth exceeded"),
        e => edge::lang::plain(cx, e),
    }
}

/* an operator's refusal in the corpus' forms with the operator as mini spells it */
fn unsupported(cx: &Cx<'_, '_>, op: Op, a: Val, b: Option<Val>) -> String {
    if matches!(op, Op::Bin(BinOp::Pow) | Op::InPlace(BinOp::Pow)) { return s!(str spelled(cx, Op::Bin(BinOp::Pow)), " requires numeric operands"); }
    let (sym, ta) = (spelled(cx, op), cx.type_name(a));
    let Some(b) = b else { return s!("bad operand type for unary ", str sym, ": '", str ta, "'") };
    let tb = cx.type_name(b);
    let seq = |k: KindId| matches!(k, KindId::Str | KindId::List | KindId::Tuple);
    let buffer = |k: KindId| matches!(k, KindId::Bytes | KindId::ByteArray);
    let (ka, kb) = (cx.kind(a), cx.kind(b));
    match op {
        Op::Bin(BinOp::Add) | Op::InPlace(BinOp::Add) if seq(ka) => s!("can only concatenate ", str ta, " (not \"", str tb, "\") to ", str ta),
        Op::Bin(BinOp::Add) | Op::InPlace(BinOp::Add) if buffer(ka) => s!("can't concat ", str tb, " to ", str ta),
        Op::Bin(BinOp::Mul) | Op::InPlace(BinOp::Mul) if seq(ka) || buffer(ka) => s!("can't multiply sequence by non-int of type '", str tb, "'"),
        Op::Bin(BinOp::Mul) | Op::InPlace(BinOp::Mul) if seq(kb) || buffer(kb) => s!("can't multiply sequence by non-int of type '", str ta, "'"),
        Op::Cmp(_) => s!("'", str sym, "' not supported between instances of '", str ta, "' and '", str tb, "'"),
        // a text holds only texts which names the item it was asked for
        Op::In => s!("'in <string>' requires string as left operand, not ", str ta),
        _ => s!("unsupported operand type(s) for ", str sym, ": '", str ta, "' and '", str tb, "'"),
    }
}

/* what a value cannot do in the corpus' forms */
fn cannot(cx: &Cx<'_, '_>, act: Act, recv: Option<Val>) -> String {
    let t = recv.map_or("", |v| cx.type_name(v));
    match act {
        Act::Iterate => s!("'", str t, "' object is not iterable"),
        Act::Next => s!("'", str t, "' object is not an iterator"),
        Act::Call => s!("'", str t, "' object is not callable"),
        Act::Subscript => s!("'", str t, "' object is not subscriptable"),
        Act::AssignItem if recv.is_none() => String::from("object does not support item assignment"),
        Act::AssignItem => s!("'", str t, "' object does not support item assignment"),
        Act::DeleteItem if recv.is_none() => String::from("object does not support item deletion"),
        Act::DeleteItem => s!("'", str t, "' object does not support item deletion"),
        Act::AssignSlice => s!("'", str t, "' object does not support slice assignment"),
        Act::Slice => String::from("object is not sliceable"),
        Act::Sequence => String::from("slice requires a sequence"),
        Act::Size => {
            // the length native as the running runtime names it
            let size = cx.natives().intrinsic(Intrinsic::Len).map_or("size", |n| n.name);
            s!("object of type '", str t, "' has no ", str size, "()")
        }
        Act::Hash { at, inner } => {
            let inner = NAMES.kind(inner);
            match at {
                Use::Plain => s!("unhashable type: '", str inner, "'"),
                Use::Key => s!("cannot use '", str t, "' as a dict key (unhashable type: '", str inner, "')"),
                Use::Element => s!("cannot use '", str t, "' as a set element (unhashable type: '", str inner, "')"),
            }
        }
        Act::Await => s!("'", str t, "' object can't be awaited"),
        Act::Map { spread: false } => s!("'", str t, "' object is not a mapping"),
        Act::Map { spread: true } => s!("Value after ** must be a mapping, not ", str t),
        Act::Contain => s!("argument of type '", str t, "' is not a container or iterable"),
        Act::Index => s!("'", str t, "' object cannot be interpreted as an integer"),
        Act::Raise { throw: false } => s!("exceptions must derive from ", str NAMES.error(ErrKind::Base)),
        Act::Raise { throw: true } => s!("exceptions must be classes or instances deriving from ", str NAMES.error(ErrKind::Base), ", not ", str t),
        Act::Bytes => String::from("a bytes-like object is required"),
        Act::Spec => String::from("format spec must be a string"),
        Act::Keyword => String::from("keywords must be strings"),
        Act::DeleteAttr => String::from("an attribute is deleted only off an instance or a class"),
        Act::DropArgs => s!(str NAMES.fields.args, " may not be deleted"),
        Act::Resume(Body::Generator) => String::from("not a generator"),
        Act::Resume(Body::Coroutine) => String::from("not a coroutine"),
        Act::Complex => String::from("complex numbers are not supported"),
    }
}

/* a call that misses its callee's signature in the corpus' forms */
fn arity(cx: &Cx<'_, '_>, callee: &Callee, fit: &Fit) -> String {
    let &Callee::Function { ref name, normal, defaults } = callee else { return native_arity(cx, callee, fit) };
    match fit {
        &Fit::Count(given) => {
            let noun = if normal == 1 && defaults == 0 { " positional argument but " } else { " positional arguments but " };
            let verb = if given == 1 { " was given" } else { " were given" };
            if defaults == 0 { s!(str name, "() takes ", int normal as i64, str noun, int given as i64, str verb) }
            else { s!(str name, "() takes from ", int (normal - defaults) as i64, " to ", int normal as i64, str noun, int given as i64, str verb) }
        }
        Fit::Missing { names, keyword, .. } => {
            let quoted: Vec<String> = names.iter().map(|n| s!("'", str n, "'")).collect();
            let list = match quoted.split_last() {
                Some((last, [])) => last.clone(),
                Some((last, rest)) => s!(str &rest.join(", "), str if rest.len() > 1 { ", and " } else { " and " }, str last),
                None => String::new(),
            };
            let kind = if *keyword { " required keyword-only argument" } else { " required positional argument" };
            s!(str name, "() missing ", int names.len() as i64, str kind, str if names.len() == 1 { ": " } else { "s: " }, str &list)
        }
        Fit::Unexpected { key, near: Some(n) } => s!(str name, "() got an unexpected keyword argument '", str key, "'. Did you mean '", str n, "'?"),
        Fit::Unexpected { key, near: None } => s!(str name, "() got an unexpected keyword argument '", str key, "'"),
        Fit::Twice(key) => s!(str name, "() got multiple values for argument '", str key, "'"),
        Fit::ByKeyword(key) => s!(str name, "() got some positional-only arguments passed as keyword arguments: '", str key, "'"),
    }
}

/* a native's misfit through the words mini's arity hook writes today */
fn native_arity(cx: &Cx<'_, '_>, callee: &Callee, fit: &Fit) -> String {
    let &Callee::Native { id, owner } = callee else { return String::new() };
    let Some(n) = cx.natives().get(id) else { return String::new() };
    let m = match fit {
        &Fit::Count(got) => Misfit::Count(got as usize),
        Fit::Unexpected { key, .. } | Fit::ByKeyword(key) => Misfit::Unexpected(key),
        Fit::Twice(key) => Misfit::Twice(key),
        &Fit::Missing { at, .. } => Misfit::Missing(at as usize),
    };
    match crate::words::arity(n, owner.map(|k| NAMES.kind(k)), m) {
        VmErr::TypeMsg(text) => text,
        e => e.message(&NAMES),
    }
}

/* a call its callee refuses in the corpus' forms */
fn call_fault(cx: &mut Cx<'_, '_>, f: &CallFault) -> String {
    match f {
        CallFault::NoArgs { name, keywords: true, .. } => s!(str name, "() takes no keyword arguments"),
        CallFault::NoArgs { name, called: true, .. } => s!(str name, "() takes no arguments"),
        CallFault::NoArgs { name, .. } => s!(str name, " takes no arguments"),
        CallFault::InitArgs => s!(str NAMES.kind(KindId::Instance), ".", str NAMES.constructor, "() takes exactly one argument (the instance to initialize)"),
        CallFault::ExcKeywords => String::from("exception class takes no keyword arguments"),
        CallFault::CtorArgs => String::from("class constructor takes no arguments"),
        &CallFault::NoReceiver { kind, name } => s!("unbound method ", str NAMES.kind(kind), ".", str name, "() needs an argument"),
        &CallFault::WrongReceiver { kind, name, got } => s!("descriptor '", str name, "' for '", str NAMES.kind(kind), "' objects doesn't apply to a '", str cx.type_name(got), "' object"),
        CallFault::TooMany { name, got } => s!("call '", str name, "': too many arguments (max 255, got ", int *got as i64, ")"),
        CallFault::Instantiate(name) => s!("cannot create '", str name, "' instances"),
        CallFault::Base(Some(name)) => s!("type '", str name, "' is not an acceptable base type"),
        CallFault::Base(None) => String::from("base class must be a class object"),
    }
}

/* the generator protocol in the corpus' forms */
fn generator(g: &Gen) -> String {
    let noun = |b: &Body| match b { Body::Generator => NAMES.kind(KindId::Coro), Body::Coroutine => NAMES.coroutine };
    match g {
        Gen::Running(b) => s!(str noun(b), " already executing"),
        Gen::FreshSend(b) => s!("can't send non-", str NAMES.nil, " value to a just-started ", str noun(b)),
        Gen::Reused => String::from("cannot reuse already awaited coroutine"),
        Gen::IgnoredClose(b) => s!(str noun(b), " ignored ", str NAMES.error(ErrKind::Close)),
        Gen::Wait { inside } => s!("receive() and host calls cannot wait inside", str inside),
        Gen::ClassSuspend => String::from("a class body cannot suspend, await outside it"),
        Gen::Sent => s!("'", str NAMES.kind(KindId::Iter), "' object has no attribute '", str NAMES.send, "'"),
    }
}

/* implements `Language` for `$lang` as mini's own over the natives `$natives` and the names `$names` */
#[doc(hidden)]

macro_rules! over {

            const BUILT: ::edge::value::foreign::Built = <$crate::Mini as ::edge::lang::Language>::BUILT;
            type Ops = ();

            }
```

## How it is built

The crate links the engine, lib and `itoa`. `lib.rs` gathers the tables of natives under its language, reads every source through the table with `Front::spelled` and names the runtime for the CLI in its `DESCRIPTOR`.

```toml file=examples/mini/Cargo.toml
[package]
name = "mini"
version.workspace = true
edition.workspace = true
license.workspace = true
repository.workspace = true
description = "The reference runtime of Edge Lang, which edge.wasm is built from, naming the lib kernels its corpus calls."
publish = false

[lib]
name = "mini"
doctest = false

[features]
default = ["std"]
std = ["edge/std"]
# builds edge.wasm with the engine's exports over these natives and the grant logic
web = ["edge/runtime", "edge/perms"]

[dependencies]
edge = { path = "../..", default-features = false }
lib = { path = "../../lib" }
itoa = { workspace = true }
```
