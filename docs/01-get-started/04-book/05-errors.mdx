# Errors

The engine finds most of a program's errors itself, an operator given a kind it does not take, a key a map lacks, a call with one argument too many. It knows what went wrong and the values it went wrong with, and nothing of how the language says so. A runtime brings that part, a class for each kind of error and the words of each one. This chapter covers what the engine raises, what a runtime chooses for it, how a report and its traceback read and what an error costs.

## Why the engine asks

The same mistake reads three ways. Each program below subtracts two times read as texts, without reading them as times first.

Tiny's flow takes the hours an issue stayed open over the GH Archive hour of [the first chapter](./02-tokens.mdx#one-job-both-ways), subtracting its two times as the texts the record holds.

```tiny
from: https://data.gharchive.org/2026-10-01-15.json.gz

time_to_close:
  where: type == "IssuesEvent" and payload.action == "closed"
  average: payload.issue.closed_at - payload.issue.created_at
  by: repo.name
```

```text
$ tiny run close.flow.yaml
report time_to_close, average at line 5: WrongType, cannot subtract text and text
```

Mini's job in `examples/data/github-hour.mini` reads the same two fields. With line 152 subtracting the two texts in place of the times `time` reads from them, it stops at the first closed issue.

```text
$ edge run --ops 100000000000 github-hour.mini
error: TypeError: unsupported operand type(s) for -: 'str' and 'str'
    --> github-hour.mini:152:13
    |
152 |             hours = (issue['closed_at'] - issue['created_at']).hours
    |             ^

note: called from tally()
    --> github-hour.mini:168:18
    |
168 |             tally(read_json(line.decode()))
    |                  ^
```

Uptime's check takes the age of GitHub's status page, the clock's milliseconds less the time the page was last updated. This ran on 25 October 2026 in a copy of `examples/uptime/checks`.

```text
$ uptime run -c 'use clock
use .http
let body = http.get("https://www.githubstatus.com/api/v2/status.json").body
print(clock.now() - body.page.updated_at)'
error: WrongType: - does not apply to int and text
  --> <eval>:4:1
  |
4 | print(clock.now() - body.page.updated_at)
  | ^
```

The engine refused one thing three times, `-` given a text. Mini calls that a `TypeError`, names the text kind `str` and words it as its corpus reads. Uptime calls it `WrongType`, names the kind `text` and takes the engine's plain words. Tiny names the report and the key it rose in and words the error its own way. The engine chose none of those names or words, as [How a runtime words them](#how-a-runtime-words-them) explains.

## Kinds and classes

The engine sorts each error it raises itself into one of 20 kinds, an `ErrKind`, and a runtime's `NAMES` gives each kind a class. The class is what a report prints and what a handler names.

| Kind | Raised for | Mini | Uptime | Tiny |
|---|---|---|---|---|
| `Base` | The root of every class a program raises | `BaseException` | `Error` | `Error` |
| `Error` | A raise whose value names no class of its own | `Exception` | `Error` | `Error` |
| `Type` | A value of a kind an operation does not take | `TypeError` | `WrongType` | `WrongType` |
| `Value` | A value of the right kind that is still wrong | `ValueError` | `BadData` | `BadData` |
| `Name` | A name no scope binds | `NameError` | `Missing` | `MissingField` |
| `Unbound` | A local read before anything binds it | `UnboundLocalError` | `Missing` | `MissingField` |
| `Attribute` | An attribute the value lacks | `AttributeError` | `Missing` | `MissingField` |
| `Key` | A key the map lacks | `KeyError` | `Missing` | `MissingField` |
| `Index` | An index past the end | `IndexError` | `Missing` | `MissingField` |
| `ZeroDiv` | A division by zero | `ZeroDivisionError` | `BadData` | `BadData` |
| `Overflow` | An int too wide for the size it must fit, an int result past the inline range where no wide kind grows it, or a float past the float range | `OverflowError` | `BadData` | `BadData` |
| `Recursion` | Calls nested past the recursion limit | `RecursionError` | `OutOfBudget` | `OutOfBudget` |
| `Memory` | The memory limit reached | `MemoryError` | `OutOfBudget` | `OutOfBudget` |
| `Runtime` | A failure no other kind names | `RuntimeError` | `Error` | `Error` |
| `Stop` | The end of an iteration, which ends the loop stepping it | `StopIteration` | `Stop` | `Stop` |
| `Close` | The signal a close throws into a generator | `GeneratorExit` | `Close` | `Close` |
| `Exit` | A program asking its host to end with a code | `SystemExit` | `Exit` | `Exit` |
| `Assert` | A failed assertion | `AssertionError` | `CheckFailed` | `Error` |
| `Syntax` | Code compiled while the program runs that does not parse | `SyntaxError` | `BadData` | `BadData` |
| `Permission` | A host call or an import the grants refuse | `PermissionError` | `Denied` | `Denied` |

Mini gives every kind a class of its own, as its corpus reads them. Uptime folds the 20 kinds into 10 classes a check catches by what went wrong for it, so a missing key, attribute and index are all `Missing`, and tiny folds them into 9.

A class sits in a tree, the pairs of class and parent `NAMES.tree` holds, and a handler that names a class catches every class below it. Mini's tree holds 31 classes, the 20 above and 11 more such as `LookupError` over `KeyError` and `IndexError`. Uptime keeps `Exit`, `Stop` and `Close` apart from `Error`, so a `catch Error` in a check never stops an exit, and its descriptor's `Unreachable` and `Denied` sit under `Error` for the host calls that fail or are refused. Tiny puts every class under `Error`, since a flow catches nothing.

## The facts of an error

`EngineError` is an error as the engine knows it, one variant for each thing that can go wrong, holding the values it went wrong with and no words.

- `Unsupported { op, a, b }` is an operator that refused its operands, the subtraction above.
- `MissingKey(k)` is a key a map lacks, tiny's `no field "name"` in [the last chapter](./04-rules.mdx#three-ways-to-read-a-field).
- `NoAttribute { recv, name, store }` is an attribute a value lacks, mini's `AttributeError` and uptime's `Missing` of the same section.
- `Arity { callee, fit }` is a call that misses what its callee takes, with `Fit` saying how, a count, a keyword no parameter takes, a parameter given twice, one left out, or a positional one given by keyword.
- `Cannot { act, recv }` is a value that cannot do what a site asked, with `Act` naming it, be iterated, be called, report a size, stand as a key and the rest.
- `Of(kind, words)` is an error a native or a host already worded, under a kind.
- `Raised(v)` is a value the program raised itself.
- `Budget`, `HostYield`, `HostCallDeferred` and `Redo` are signals that end or pause a run, and no program catches them.

`e.kind()` is the kind whose class the runtime names, and none for a raised value or a signal. [Language](../../02-sdk/04-language.mdx#engineerror) lists every variant with its kind.

## How a runtime words them

The trait holds the words in `message(cx, e)`, which a runtime writes from the facts of `e`. The default is `edge::lang::plain`, the engine's plain words, which name an operator as the runtime's table spells it. Mini writes its own, every variant in the form its corpus reads, in its `language.rs` beside its rules.

```rust file=examples/mini/src/language.rs
use alloc::string::String;
use alloc::vec::Vec;

use edge::lang::{
    Act, Body, CallFault, Callee, Cx, Descriptor, EngineError, ErrKind, Falsy, Fit, Front, Gen, IntDiv, IntMod, Intrinsic, KindId, Language,
    Lock, MapIter, Misfit, Mode, Names, Native, Natives, NegPow, NumEq, Op, Overflow, Pattern, Policy, StrIter, Use, ZeroDiv, spelled,
};
use edge::value::foreign::{BinOp, Built, Kind};
use edge::value::{HeapObj, HeapPool, Val, VmErr};

use edge::s;

use crate::{Mini, NAMES};

impl Language for Mini {
    const VERSION: u32 = 1;
    // the corpus' rules as mini's own choices
    const POLICY: Policy = Policy {
        int_overflow: Overflow::Promote,
        int_div: IntDiv::ToFloat,
        int_mod: IntMod::Truncated,
        zero_div: ZeroDiv::Error,
        neg_pow: NegPow::ToFloat,
        numeric_eq: NumEq::Unified,
        bool_is_int: true,
        falsy: Falsy::NIL.or(Falsy::FALSE).or(Falsy::ZERO).or(Falsy::NAN).or(Falsy::EMPTY_TEXT),
        identity_first: true,
        neg_index: true,
        str_iter: StrIter::CodePoints,
        map_iter: MapIter::Keys,
        // off for now since reading keys puts a call on every attribute miss
        map_fields: false,
        builtins_scope: true,
        receiver_slot: true,
        // kept so the limit cases keep their numbers
        recursion_limit: 1000,
        max_int_digits: Some(4300),
    };
    const NATIVES: &'static Natives = &crate::NATIVES;
    const NAMES: &'static Names = &NAMES;
    const FRONT: Front = crate::FRONT;
    const DESCRIPTOR: &'static Descriptor = &crate::DESCRIPTOR;
    const WIDE: Option<&'static Kind> = Some(&crate::lang::WIDE);
    const KINDS: &'static [&'static Kind] = &[&crate::lang::TIME, &crate::lang::DURATION];
    const BUILT: Built = Built { ellipsis: Some(&crate::lang::DOTS), slice: Some(&crate::lang::SLICE) };
    type Ops = ();

    fn show(cx: &mut Cx<'_, '_>, v: Val, mode: Mode) -> Result<String, VmErr> { lib::fmt::render::hook::<Mini>(cx, v, mode) }

    fn format(cx: &mut Cx<'_, '_>, v: Val, spec: &str) -> Result<String, VmErr> { lib::fmt::spec::hook::<Mini>(cx, v, spec) }

    fn handles(heap: &HeapPool, exc: Val, class: Val) -> Result<bool, VmErr> { lib::types::match_exc::<Mini>(heap, exc, class) }

    fn misfit(n: &Native, owner: Option<&str>, m: Misfit<'_>) -> VmErr { crate::words::arity(n, owner, m) }

    fn message(cx: &mut Cx<'_, '_>, e: &EngineError) -> String { message(cx, e) }
}

/* every engine error in the words the corpus reads */
fn message(cx: &mut Cx<'_, '_>, e: &EngineError) -> String {
    use EngineError as E;
    match e {
        &E::Unsupported { op, a, b } => unsupported(cx, op, a, b),
        &E::Cannot { act, recv } => cannot(cx, act, recv),
        &E::BadIndex { recv, index } => match cx.kind(recv) {
            KindId::Str => s!("string indices must be integers, not '", str cx.type_name(index), "'"),
            // bytes name their index as one byte as the corpus reads them
            KindId::Bytes => s!("byte indices must be integers or slices, not ", str cx.type_name(index)),
            _ => s!(str cx.type_name(recv), " indices must be integers or slices, not ", str cx.type_name(index)),
        },
        E::BadSlice { step: true, .. } => String::from("slice step must be an integer"),
        E::BadSlice { .. } => s!("slice indices must be integers or ", str NAMES.nil, " or have an ", str NAMES.index_method, " method"),
        &E::OutOfRange { recv, store } => String::from(match (cx.kind(recv), store) {
            (KindId::List, true) => "list assignment index out of range",
            (KindId::List, false) => "list index out of range",
            (KindId::Tuple, _) => "tuple index out of range",
            (KindId::Str, _) => "string index out of range",
            (KindId::Range, _) => "range object index out of range",
            (KindId::ByteArray, _) => "bytearray index out of range",
            _ => "index out of range",
        }),
        E::TooWide(_) => s!("cannot fit '", str NAMES.kind(KindId::Int), "' into an index-sized integer"),
        &E::MissingKey(k) => cx.render(k, Mode::Repr).unwrap_or_default(),
        E::Changed(KindId::Set) => String::from("Set changed size during iteration"),
        E::Changed(_) => String::from("dictionary changed size during iteration"),
        E::ZeroStep { range: true } => s!(str NAMES.kind(KindId::Range), "() arg 3 must not be zero"),
        E::ZeroStep { range: false } => String::from("slice step cannot be zero"),
        E::Arity { callee, fit } => arity(cx, callee, fit),
        E::Call(f) => call_fault(cx, f),
        E::Undefined(n) => s!("name '", str n, "' is not defined"),
        E::Unbound { name: Some(n), free: false } => s!("cannot access local variable '", str n, "' where it is not associated with a value"),
        E::Unbound { name: Some(n), free: true } => s!("cannot access free variable '", str n, "' where it is not associated with a value in enclosing scope"),
        E::Unbound { name: None, .. } => String::from("cannot access a local variable that is not associated with a value"),
        E::NoAttribute { recv, name, store: true } => s!("'", str cx.type_name(*recv), "' object has no attribute '", str name, "' and no __dict__ for setting new attributes"),
        E::NoAttribute { recv, name, .. } => match cx.heap().try_get(*recv) {
            Some(HeapObj::Module(module, _)) => s!("module '", str module, "' has no attribute '", str name, "'"),
            _ if cx.heap().is_class(*recv) => s!("type object '", str cx.heap().class_name(*recv).unwrap_or(""), "' has no attribute '", str name, "'"),
            _ => s!("'", str cx.type_name(*recv), "' object has no attribute '", str name, "'"),
        },
        E::ReadOnly { recv, name, lock } => match lock {
            Lock::Type => match cx.heap().type_object_name(*recv) {
                Some(t) => s!("cannot set '", str name, "' attribute of immutable type '", str t, "'"),
                None => s!("cannot set '", str name, "' attribute of immutable type '", str cx.type_name(*recv), "'"),
            },
            Lock::Native => s!("'", str cx.type_name(*recv), "' object attribute '", str name, "' is read-only"),
            Lock::Fixed => String::from("readonly attribute"),
            Lock::Plain => s!("attribute '", str name, "' of '", str cx.type_name(*recv), "' objects is not writable"),
        },
        E::ZeroDiv => String::from("division by zero"),
        E::ZeroPow => String::from("zero to a negative power"),
        E::Overflow => String::from(NAMES.overflow),
        E::FloatRange => String::from("(34, 'Numerical result out of range')"),
        E::NegativeShift => String::from("negative shift count"),
        E::ByteRange => String::from("byte must be in range(0, 256)"),
        &E::Unpack { want, got, more: false, rest } => s!("not enough values to unpack (expected ", str if rest { "at least " } else { "" }, int want as i64, ", got ", int got.unwrap_or(0) as i64, ")"),
        &E::Unpack { want, got: Some(g), .. } => s!("too many values to unpack (expected ", int want as i64, ", got ", int g as i64, ")"),
        &E::Unpack { want, got: None, .. } => s!("too many values to unpack (expected ", int want as i64, ")"),
        &E::SliceSize { size, span } => s!("attempt to assign sequence of size ", int size as i64, " to extended slice of size ", int span as i64),
        &E::Uneven { arg, longer } => {
            let before = if arg == 1 { String::from("argument 1") } else { s!("arguments 1-", int i64::from(arg)) };
            s!(str cx.names().iters[edge::lang::iters::ZIP], "() argument ", int i64::from(arg) + 1, str if longer { " is longer than " } else { " is shorter than " }, str &before)
        }
        E::Generator(g) => generator(g),
        E::Pattern(p) => match p {
            &Pattern::OnePositional(subject) => s!(str cx.type_name(subject), "() accepts 1 positional sub-pattern"),
            Pattern::NoFields => s!("class pattern accepts no positional sub-patterns without ", str NAMES.fields.match_args),
            Pattern::TooMany => s!("class pattern got more positional sub-patterns than ", str NAMES.fields.match_args),
        },
        &E::Stop(v) | &E::Exit(v) | &E::Assert(v) => if v.is_undef() || v.is_none() { String::new() } else { cx.render(v, Mode::Str).unwrap_or_default() },
        E::Close => String::new(),
        E::Recursion => String::from("maximum recursion depth exceeded"),
        e => edge::lang::plain(cx, e),
    }
}

/* an operator's refusal in the corpus' forms with the operator as mini spells it */
fn unsupported(cx: &Cx<'_, '_>, op: Op, a: Val, b: Option<Val>) -> String {
    if matches!(op, Op::Bin(BinOp::Pow) | Op::InPlace(BinOp::Pow)) { return s!(str spelled(cx, Op::Bin(BinOp::Pow)), " requires numeric operands"); }
    let (sym, ta) = (spelled(cx, op), cx.type_name(a));
    let Some(b) = b else { return s!("bad operand type for unary ", str sym, ": '", str ta, "'") };
    let tb = cx.type_name(b);
    let seq = |k: KindId| matches!(k, KindId::Str | KindId::List | KindId::Tuple);
    let buffer = |k: KindId| matches!(k, KindId::Bytes | KindId::ByteArray);
    let (ka, kb) = (cx.kind(a), cx.kind(b));
    match op {
        Op::Bin(BinOp::Add) | Op::InPlace(BinOp::Add) if seq(ka) => s!("can only concatenate ", str ta, " (not \"", str tb, "\") to ", str ta),
        Op::Bin(BinOp::Add) | Op::InPlace(BinOp::Add) if buffer(ka) => s!("can't concat ", str tb, " to ", str ta),
        Op::Bin(BinOp::Mul) | Op::InPlace(BinOp::Mul) if seq(ka) || buffer(ka) => s!("can't multiply sequence by non-int of type '", str tb, "'"),
        Op::Bin(BinOp::Mul) | Op::InPlace(BinOp::Mul) if seq(kb) || buffer(kb) => s!("can't multiply sequence by non-int of type '", str ta, "'"),
        Op::Cmp(_) => s!("'", str sym, "' not supported between instances of '", str ta, "' and '", str tb, "'"),
        // a text holds only texts which names the item it was asked for
        Op::In => s!("'in <string>' requires string as left operand, not ", str ta),
        _ => s!("unsupported operand type(s) for ", str sym, ": '", str ta, "' and '", str tb, "'"),
    }
}

/* what a value cannot do in the corpus' forms */
fn cannot(cx: &Cx<'_, '_>, act: Act, recv: Option<Val>) -> String {
    let t = recv.map_or("", |v| cx.type_name(v));
    match act {
        Act::Iterate => s!("'", str t, "' object is not iterable"),
        Act::Next => s!("'", str t, "' object is not an iterator"),
        Act::Call => s!("'", str t, "' object is not callable"),
        Act::Subscript => s!("'", str t, "' object is not subscriptable"),
        Act::AssignItem if recv.is_none() => String::from("object does not support item assignment"),
        Act::AssignItem => s!("'", str t, "' object does not support item assignment"),
        Act::DeleteItem if recv.is_none() => String::from("object does not support item deletion"),
        Act::DeleteItem => s!("'", str t, "' object does not support item deletion"),
        Act::AssignSlice => s!("'", str t, "' object does not support slice assignment"),
        Act::Slice => String::from("object is not sliceable"),
        Act::Sequence => String::from("slice requires a sequence"),
        Act::Size => {
            // the length native as the running runtime names it
            let size = cx.natives().intrinsic(Intrinsic::Len).map_or("size", |n| n.name);
            s!("object of type '", str t, "' has no ", str size, "()")
        }
        Act::Hash { at, inner } => {
            let inner = NAMES.kind(inner);
            match at {
                Use::Plain => s!("unhashable type: '", str inner, "'"),
                Use::Key => s!("cannot use '", str t, "' as a dict key (unhashable type: '", str inner, "')"),
                Use::Element => s!("cannot use '", str t, "' as a set element (unhashable type: '", str inner, "')"),
            }
        }
        Act::Await => s!("'", str t, "' object can't be awaited"),
        Act::Map { spread: false } => s!("'", str t, "' object is not a mapping"),
        Act::Map { spread: true } => s!("Value after ** must be a mapping, not ", str t),
        Act::Contain => s!("argument of type '", str t, "' is not a container or iterable"),
        Act::Index => s!("'", str t, "' object cannot be interpreted as an integer"),
        Act::Raise { throw: false } => s!("exceptions must derive from ", str NAMES.error(ErrKind::Base)),
        Act::Raise { throw: true } => s!("exceptions must be classes or instances deriving from ", str NAMES.error(ErrKind::Base), ", not ", str t),
        Act::Bytes => String::from("a bytes-like object is required"),
        Act::Spec => String::from("format spec must be a string"),
        Act::Keyword => String::from("keywords must be strings"),
        Act::DeleteAttr => String::from("an attribute is deleted only off an instance or a class"),
        Act::DropArgs => s!(str NAMES.fields.args, " may not be deleted"),
        Act::Resume(Body::Generator) => String::from("not a generator"),
        Act::Resume(Body::Coroutine) => String::from("not a coroutine"),
        Act::Complex => String::from("complex numbers are not supported"),
    }
}

/* a call that misses its callee's signature in the corpus' forms */
fn arity(cx: &Cx<'_, '_>, callee: &Callee, fit: &Fit) -> String {
    let &Callee::Function { ref name, normal, defaults } = callee else { return native_arity(cx, callee, fit) };
    match fit {
        &Fit::Count(given) => {
            let noun = if normal == 1 && defaults == 0 { " positional argument but " } else { " positional arguments but " };
            let verb = if given == 1 { " was given" } else { " were given" };
            if defaults == 0 { s!(str name, "() takes ", int normal as i64, str noun, int given as i64, str verb) }
            else { s!(str name, "() takes from ", int (normal - defaults) as i64, " to ", int normal as i64, str noun, int given as i64, str verb) }
        }
        Fit::Missing { names, keyword, .. } => {
            let quoted: Vec<String> = names.iter().map(|n| s!("'", str n, "'")).collect();
            let list = match quoted.split_last() {
                Some((last, [])) => last.clone(),
                Some((last, rest)) => s!(str &rest.join(", "), str if rest.len() > 1 { ", and " } else { " and " }, str last),
                None => String::new(),
            };
            let kind = if *keyword { " required keyword-only argument" } else { " required positional argument" };
            s!(str name, "() missing ", int names.len() as i64, str kind, str if names.len() == 1 { ": " } else { "s: " }, str &list)
        }
        Fit::Unexpected { key, near: Some(n) } => s!(str name, "() got an unexpected keyword argument '", str key, "'. Did you mean '", str n, "'?"),
        Fit::Unexpected { key, near: None } => s!(str name, "() got an unexpected keyword argument '", str key, "'"),
        Fit::Twice(key) => s!(str name, "() got multiple values for argument '", str key, "'"),
        Fit::ByKeyword(key) => s!(str name, "() got some positional-only arguments passed as keyword arguments: '", str key, "'"),
    }
}

/* a native's misfit through the words mini's arity hook writes today */
fn native_arity(cx: &Cx<'_, '_>, callee: &Callee, fit: &Fit) -> String {
    let &Callee::Native { id, owner } = callee else { return String::new() };
    let Some(n) = cx.natives().get(id) else { return String::new() };
    let m = match fit {
        &Fit::Count(got) => Misfit::Count(got as usize),
        Fit::Unexpected { key, .. } | Fit::ByKeyword(key) => Misfit::Unexpected(key),
        Fit::Twice(key) => Misfit::Twice(key),
        &Fit::Missing { at, .. } => Misfit::Missing(at as usize),
    };
    match crate::words::arity(n, owner.map(|k| NAMES.kind(k)), m) {
        VmErr::TypeMsg(text) => text,
        e => e.message(&NAMES),
    }
}

/* a call its callee refuses in the corpus' forms */
fn call_fault(cx: &mut Cx<'_, '_>, f: &CallFault) -> String {
    match f {
        CallFault::NoArgs { name, keywords: true, .. } => s!(str name, "() takes no keyword arguments"),
        CallFault::NoArgs { name, called: true, .. } => s!(str name, "() takes no arguments"),
        CallFault::NoArgs { name, .. } => s!(str name, " takes no arguments"),
        CallFault::InitArgs => s!(str NAMES.kind(KindId::Instance), ".", str NAMES.constructor, "() takes exactly one argument (the instance to initialize)"),
        CallFault::ExcKeywords => String::from("exception class takes no keyword arguments"),
        CallFault::CtorArgs => String::from("class constructor takes no arguments"),
        &CallFault::NoReceiver { kind, name } => s!("unbound method ", str NAMES.kind(kind), ".", str name, "() needs an argument"),
        &CallFault::WrongReceiver { kind, name, got } => s!("descriptor '", str name, "' for '", str NAMES.kind(kind), "' objects doesn't apply to a '", str cx.type_name(got), "' object"),
        CallFault::TooMany { name, got } => s!("call '", str name, "': too many arguments (max 255, got ", int *got as i64, ")"),
        CallFault::Instantiate(name) => s!("cannot create '", str name, "' instances"),
        CallFault::Base(Some(name)) => s!("type '", str name, "' is not an acceptable base type"),
        CallFault::Base(None) => String::from("base class must be a class object"),
    }
}

/* the generator protocol in the corpus' forms */
fn generator(g: &Gen) -> String {
    let noun = |b: &Body| match b { Body::Generator => NAMES.kind(KindId::Coro), Body::Coroutine => NAMES.coroutine };
    match g {
        Gen::Running(b) => s!(str noun(b), " already executing"),
        Gen::FreshSend(b) => s!("can't send non-", str NAMES.nil, " value to a just-started ", str noun(b)),
        Gen::Reused => String::from("cannot reuse already awaited coroutine"),
        Gen::IgnoredClose(b) => s!(str noun(b), " ignored ", str NAMES.error(ErrKind::Close)),
        Gen::Wait { inside } => s!("receive() and host calls cannot wait inside", str inside),
        Gen::ClassSuspend => String::from("a class body cannot suspend, await outside it"),
        Gen::Sent => s!("'", str NAMES.kind(KindId::Iter), "' object has no attribute '", str NAMES.send, "'"),
    }
}

/* implements `Language` for `$lang` as mini's own over the natives `$natives` and the names `$names` */
#[doc(hidden)]
#[macro_export]
macro_rules! over {
    ($lang:ident, $natives:expr) => { $crate::over!($lang, $natives, &$crate::NAMES); };
    ($lang:ident, $natives:expr, $names:expr) => {
        impl ::edge::lang::Language for $lang {
            const VERSION: u32 = 1;
            const POLICY: ::edge::lang::Policy = <$crate::Mini as ::edge::lang::Language>::POLICY;
            const NATIVES: &'static ::edge::lang::Natives = $natives;
            const NAMES: &'static ::edge::lang::Names = $names;
            const FRONT: ::edge::lang::Front = $crate::FRONT;
            const DESCRIPTOR: &'static ::edge::lang::Descriptor = &$crate::DESCRIPTOR;
            const WIDE: Option<&'static ::edge::value::foreign::Kind> = <$crate::Mini as ::edge::lang::Language>::WIDE;
            const KINDS: &'static [&'static ::edge::value::foreign::Kind] = <$crate::Mini as ::edge::lang::Language>::KINDS;
            const BUILT: ::edge::value::foreign::Built = <$crate::Mini as ::edge::lang::Language>::BUILT;
            type Ops = ();

            fn show(cx: &mut ::edge::lang::Cx<'_, '_>, v: ::edge::value::Val, mode: ::edge::lang::Mode) -> Result<$crate::__String, ::edge::value::VmErr> {
                <$crate::Mini as ::edge::lang::Language>::show(cx, v, mode)
            }

            fn format(cx: &mut ::edge::lang::Cx<'_, '_>, v: ::edge::value::Val, spec: &str) -> Result<$crate::__String, ::edge::value::VmErr> {
                <$crate::Mini as ::edge::lang::Language>::format(cx, v, spec)
            }

            fn handles(heap: &::edge::value::HeapPool, exc: ::edge::value::Val, class: ::edge::value::Val) -> Result<bool, ::edge::value::VmErr> {
                <$crate::Mini as ::edge::lang::Language>::handles(heap, exc, class)
            }

            fn misfit(n: &::edge::lang::Native, owner: Option<&str>, m: ::edge::lang::Misfit<'_>) -> ::edge::value::VmErr {
                <$crate::Mini as ::edge::lang::Language>::misfit(n, owner, m)
            }

            fn message(cx: &mut ::edge::lang::Cx<'_, '_>, e: &::edge::lang::EngineError) -> $crate::__String {
                <$crate::Mini as ::edge::lang::Language>::message(cx, e)
            }
        }
    };
}
```

`raise(cx, e)` makes the value a handler binds, an exception of the class `NAMES` gives the error's kind holding `message`'s words. A missing key keeps the key itself as its one argument, and an exit, a stop or an assertion keeps its value.

The loop raises an `EngineError`, and the engine words it through the runtime's `message` where a handler catches it and where it leaves the machine, so a program reads every error of the engine in its runtime's words. Uptime writes no `message`, so its subtraction above reads in the engine's plain words with uptime's names for the two kinds. `examples/mini/tests/language.rs` runs 37 programs that fail, each beside a native that builds the same `EngineError` and words it through mini's `message`, and holds the two to one text. The handler binds what the runtime's `raise` makes of the kind and those words, and the default builds an exception of the class `NAMES` gives the kind.

Two more parts word errors.

- **`misfit`** words a call that misses a native's signature. Tiny's says how many arguments a native takes, as a flow that hands `hours_between` one time shows.
- **`REPORT`** words the whole report of an error no handler caught. Tiny's names the report and the key the error rose in, with the line of that key. Its `message` already worded the error in tiny's terms, so the report only reads a missing key's text as the field it names.

```rust file=examples/tiny/src/words.rs
use alloc::format;
use alloc::string::{String, ToString};
use core::ops::Range;

use edge::lang::{Act, Cx, EngineError, Intrinsic, KindId, Misfit, Mode, Native, Op, VAR};
use edge::value::foreign::{BinOp, UnOp};
use edge::value::{Val, VmErr};
use lib::fail::{At, Fail, english};

use crate::Tiny;
use crate::natives::wrong;

/* tiny's words for the failures of its kernels with lib's neutral words for the rest */
pub fn words(cx: &mut Cx<'_, '_>, at: At, f: Fail) -> VmErr {
    match f {
        Fail::IntLiteral { base: 10, v } | Fail::FloatLiteral(v) => match cx.render(v, Mode::Repr) {
            Ok(r) => VmErr::Raised(format!("BadData: {r} spells no number")),
            Err(e) => e,
        },
        Fail::BadOperand(v) => wrong(cx, at.name, "a number", v),
        // a fraction is a number too so the words name what it lacks
        Fail::NotIndex(v) if cx.kind(v) == KindId::Float => VmErr::Raised(format!("WrongType: {} takes a whole number, not a fraction", at.name)),
        Fail::NotIndex(v) => wrong(cx, at.name, "a whole number", v),
        Fail::ExtremeEmpty => VmErr::Raised(format!("BadData: {} takes at least one value", at.name)),
        f => english::<Tiny>(cx, at, f),
    }
}

/* the words of a call that misses a native's signature */
pub fn arity(n: &Native, owner: Option<&str>, m: Misfit<'_>) -> VmErr {
    let name = match owner { Some(_) => format!(".{}", n.name), None => n.name.to_string() };
    let (lo, hi) = (n.sig.min as usize, n.sig.max);
    let want = match (lo, hi) {
        (l, h) if h != VAR && l == h as usize => format!("{l}"),
        (l, VAR) => format!("at least {l}"),
        (l, h) => format!("{l} to {h}"),
    };
    // one argument however many more are allowed takes no plural
    let plural = if lo == 1 && (hi == 1 || hi == VAR) { "" } else { "s" };
    VmErr::Raised(match m {
        Misfit::Count(got) => format!("WrongType: {name} takes {want} argument{plural}, not {got}"),
        Misfit::Unexpected(k) | Misfit::Twice(k) => format!("WrongType: {name} takes its arguments in order, not as {k}"),
        Misfit::Missing(i) => format!("WrongType: {name} misses argument {}", i + 1),
    })
}

/* the place in a flow a run's error rose at and the line it reads */
pub fn report(src: &str, err: &str, pos: Option<usize>) -> String {
    let (class, msg) = err.split_once(": ").unwrap_or((err, ""));
    let (class, msg) = named(class, msg);
    // a run out of steps or memory fails as a whole and names no report
    let Some(pos) = pos.filter(|_| class != "OutOfBudget") else { return format!("{class}, {msg}") };
    let line = src.as_bytes()[..pos.min(src.len())].iter().filter(|&&c| c == b'\n').count() + 1;
    let place = place(src, pos);
    format!("{place} at line {line}: {class}, {msg}")
}

/* tiny's class and words for an error the engine or a kernel raised */
fn named(class: &str, msg: &str) -> (String, String) {
    // a run out of steps fails as a runtime error whose words tell it apart
    if msg == "budget exceeded" { return ("OutOfBudget".into(), "the run spent its budget of steps".into()); }
    if class == "OutOfBudget" && msg == "memory limit" { return (class.into(), "the run passed its memory limit".into()); }
    (class.to_string(), keyed(msg))
}

/* a missing key's text as the field it names */
fn keyed(msg: &str) -> String {
    if msg.len() > 1 && msg.starts_with('"') && msg.ends_with('"') { return format!("no field {msg}"); }
    // a record's key that is no text reads as the value it was
    if msg.parse::<f64>().is_ok() { return format!("no field {msg}"); }
    if msg.starts_with('(') && msg.ends_with(')') && msg.matches("; ").count() == 2 { return "a record is read by field, not by a slice".into(); }
    msg.to_string()
}

/* every engine error in tiny's words with the engine's plain words for the rest */
pub fn message(cx: &mut Cx<'_, '_>, e: &EngineError) -> String {
    use EngineError as E;
    let ty = |cx: &Cx<'_, '_>, v: Val| String::from(cx.type_name(v));
    match e {
        &E::Unsupported { op, a, b: Some(b) } => operands(cx, op, a, b).unwrap_or_else(|| edge::lang::plain(cx, e)),
        &E::Unsupported { op: Op::Unary(UnOp::Neg), a, b: None } => format!("cannot negate {}", ty(cx, a)),
        &E::Unsupported { op: Op::Unary(UnOp::Pos), a, b: None } => format!("cannot apply + to {}", ty(cx, a)),
        &E::Cannot { act, recv: Some(v) } => match act {
            Act::Subscript => format!("{} holds no items", ty(cx, v)),
            Act::Iterate => format!("{} holds no values", ty(cx, v)),
            Act::Contain => format!("cannot look for a value in {}", ty(cx, v)),
            Act::Hash { .. } => format!("a {} cannot be a key", ty(cx, v)),
            // the length native as tiny names it
            Act::Size => format!("{} takes text, a list or a record, not {}", cx.natives().intrinsic(Intrinsic::Len).map_or("len", |n| n.name), ty(cx, v)),
            _ => edge::lang::plain(cx, e),
        },
        &E::BadIndex { recv, index } if cx.kind(index) == KindId::Float => format!("the {} takes a whole number as its index, not a fraction", ty(cx, recv)),
        &E::BadIndex { recv, index } => format!("the {} takes a number as its index, not {}", ty(cx, recv), ty(cx, index)),
        &E::OutOfRange { recv, .. } => format!("the {} holds no item at that index", ty(cx, recv)),
        E::NoAttribute { recv, name, store: false } if cx.kind(*recv) == KindId::Dict => format!("no field \"{name}\""),
        E::NoAttribute { recv, name, store: false } => format!("{} has no field or method {name}", ty(cx, *recv)),
        E::Undefined(name) => format!("no field or function \"{name}\""),
        E::FloatRange => "the result is too large for a number".into(),
        E::IntRange => "the result is too large for a whole number".into(),
        e => edge::lang::plain(cx, e),
    }
}

/* a binary operator's refusal of `a` and `b` in tiny's words */
fn operands(cx: &mut Cx<'_, '_>, op: Op, a: Val, b: Val) -> Option<String> {
    let (ta, tb) = (String::from(cx.type_name(a)), String::from(cx.type_name(b)));
    let repeats = |k: KindId| matches!(k, KindId::Str | KindId::List | KindId::Tuple | KindId::Bytes | KindId::ByteArray);
    let bin = match op {
        Op::Cmp(_) => return Some(format!("cannot compare {ta} and {tb}")),
        // only text holds text which the left side must then be
        Op::In => return Some(format!("in looks for text in text, not {ta}")),
        Op::Bin(b) | Op::InPlace(b) => b,
        _ => return None,
    };
    let verb = match bin {
        BinOp::Pow => return Some("** takes a number on each side".into()),
        BinOp::Mul if repeats(cx.kind(a)) || repeats(cx.kind(b)) => {
            let count = if repeats(cx.kind(a)) { b } else { a };
            let kind = if cx.kind(count) == KindId::Float { "a fraction" } else { cx.type_name(count) };
            return Some(format!("text or a list repeats a whole number of times, not {kind}"));
        }
        BinOp::Add => "add",
        BinOp::Sub => "subtract",
        BinOp::Mul => "multiply",
        BinOp::TrueDiv | BinOp::FloorDiv => "divide",
        BinOp::Mod => "take the remainder of",
        _ => return None,
    };
    Some(format!("cannot {verb} {ta} and {tb}"))
}

/* the report and key whose bytes hold `pos` as an error names them */
fn place(src: &str, pos: usize) -> String {
    let Ok(docs) = crate::yaml::documents(src) else { return "the flow".into() };
    let Ok(prog) = crate::flow::check(src, &docs) else { return "the flow".into() };
    let mut best: Option<(Range<usize>, String)> = None;
    let mut keep = |span: &Range<usize>, what: String| {
        let holds = span.start <= pos && pos < span.end.max(span.start + 1);
        if holds && best.as_ref().is_none_or(|(b, _)| span.len() <= b.len()) { best = Some((span.clone(), what)); }
    };
    keep(&prog.from.span, "from".into());
    if let Some(w) = &prog.filter { keep(&w.span, "where".into()); }
    for r in &prog.reports {
        let here = format!("report {}", r.name);
        keep(&r.span, here.clone());
        for (span, key) in r.entries() { keep(&span, format!("{here}, {key}")); }
    }
    best.map_or_else(|| "the flow".into(), |(_, w)| w)
}
```

## A traceback

An error no handler catches ends the run, and the CLI prints its report to stderr and exits with 1. Mini's job above shows every part of one.

- The head is `error:` with the class and the words, then `-->` with the path, the line and the column it rose at, and that line with a caret under the statement it rose in.
- Each frame the error unwound through adds a `note: called from` with the function's name, the line of its call and a caret under the call's opening parenthesis, the innermost first. The subtraction rose in `tally()`, which line 168 called.
- A call that repeats, as a recursion's does, shows once and then `note: the same call N more times`.
- A function with no name of its own reads as `NAMES.anonymous`, `<lambda>` in mini, and code compiled while the program runs as `NAMES.compiled`, `<string>` in mini.

A runtime with a `REPORT` replaces all of it, so tiny's report is the one line above, with no source and no frames, since a flow has no calls of its own. The diagnostics the kit reports before a program runs are another report, spelled through the runtime's table, as [Diagnostics](../../04-reference/05-diagnostics.mdx) lists.

## What an error costs

An error costs nothing until it is raised. The paths that raise one are cold, built apart from the loop's hot code, and the engine finds the frames of a traceback only as the error unwinds through them, so a call pays nothing for a traceback it might print.

A raise pays for its facts and the words come later, where a handler catches the error or where it leaves the machine. A loop that raises and catches the same error on every pass pays for its words on every pass, and a native that tests for an error and drops it, as `getattr` with a default does, pays for none. A missing key and the end of an iteration still build their exception as they rise, since it holds the key or the value. A handler's test walks the runtime's tree, which `Tree::of` lays out as the runtime builds, so the test reads a table and then the parents above the class.

`REPORT` runs once, on the error that ended the run, so tiny's report costs a flow nothing while it reads its records. The words are code in the runtime's `.wasm`. Uptime takes the engine's plain words, mini words every variant and tiny words the variants its flows meet.

## Choosing

| | Mini | Tiny | Uptime |
|---|---|---|---|
| Classes | One for each kind and 11 more, as its corpus reads | 9, under one root | 10, a check catches by what went wrong |
| Signals | `SystemExit` and `GeneratorExit` apart from `Exception`, `StopIteration` under it | Under `Error`, since a flow catches nothing | Apart from `Error`, so `catch Error` never stops an exit |
| Words for the engine's errors | Its own for every variant, through `message` | Its own, through `message`, with the report its `REPORT` writes | The engine's plain words |
| A call that misses a native | Its own, through `misfit` | Its own, through `misfit` | The engine's |

A language whose errors must read exactly as its programs expect words every variant, as mini does for its corpus. A language whose programs are data words the report, as tiny does, so an error names the part of the data the user wrote. A small language takes the engine's plain words and names only its classes, as uptime does, and its errors read in the engine's terms.
