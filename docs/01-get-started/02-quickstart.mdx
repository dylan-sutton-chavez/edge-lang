# Quickstart

## Build a runtime of your own

Edge Lang is an engine for language runtimes. A runtime on it is a crate with a token table, its rules, the natives it takes from lib and a descriptor, and its CLI is the kit composed over it. The repo holds one, `uptime`, a language for checking the services a project depends on. Build it and its CLI from a clone.

```bash
git clone https://github.com/dylan-sutton-chavez/edge-lang
cd edge-lang
make uptime
export PATH="$PWD/cli/target/release:$PATH"
```

`make uptime` needs Rust only, and `rust-toolchain.toml` pins the toolchain with its wasm target. Then run the checks.

```bash
cd examples/uptime/checks
uptime run status.up
```

```text
github      200   559 ms  All Systems Operational
npm         200   568 ms  All Systems Operational
cloudflare  200   802 ms  Partial System Outage
```

The board read three status pages through the net plugin, under the grants of the `edge.json` beside it. The runtime is the 241 lines of Rust in the five files of `examples/uptime/src`, and the CLI is the kit composed over it, whole below.

```rust file=examples/uptime/cli/src/lib.rs
```

`Kit::new` takes the runtime, made of its wasm and its descriptor. `run` and `test` are two of the kit's commands, `perms` holds each check to what `edge.json` grants, and `net` and `clock` are the host modules a check may import.

> [!BANNER] Build it file by file
> [Your runtime and its CLI](./03-use-cases/01-your-runtime.mdx)

## Install the CLI

The `edge` CLI runs programs on mini, the reference runtime the repo holds beside uptime. Build it in the same clone.

```bash
make wasm-cli js lucide
cargo install --path cli
```

> [!NOTE]
> The CLI runs on macOS, Linux and WSL. `make js` and `make lucide` need Deno too.

Check the install. It prints the version of the CLI.

> [!COPY] edge --version

Prebuilt binaries and every detail are in [Install](../03-platforms/01-cli.mdx#install) in the CLI reference.

## Run a first program

A program reaches nothing outside its sandbox until its `edge.json` grants it, so a first program that reads GitHub's status page asks for that one host. It requests the page, reads its body a chunk at a time and prints the state the page describes.

```edge-manifest
{ "permissions": { "main": ["net:www.githubstatus.com"] } }
```

```edge
import net

r = net.request("GET", "https://www.githubstatus.com/api/v2/status.json")
code, headers = net.response(r)
body = b""
chunk = net.read(r)
while chunk is !nil:
    body += chunk
    chunk = net.read(r)
page = body.decode()
at = page.find('"description":"') + 15
print("GitHub", code, page[at:page.find('"', at)])
```

```output
GitHub 200 All Systems Operational
```

It printed that on 25 October 2026. Save it as `status.mini` beside an `edge.json` holding the grant above, and run it from your terminal.

> [!COPY] edge run status.mini

There is no build step. The CLI compiles the file and runs it, and without the grant the import of `net` fails before anything runs.
