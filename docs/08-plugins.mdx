# Plugins

This page covers writing a plugin, a `.wasm` module a program imports like any other module. It runs in an instance of its own, beside the runtime, and reaches the program's values only through handles the host lends it. `interpreter::plugin` is the kit you write one with, and every runtime built on `interpreter` loads it the same way, in the CLI and in a web page.

## The crate

A plugin is a `cdylib` that takes the crate with only the `plugin` feature.

```toml
[lib]
crate-type = ["cdylib"]

[dependencies]
interpreter = { version = "1", default-features = false, features = ["plugin"] }
```

It builds for `wasm32-unknown-unknown`, where the crate is `no_std` and `plugin_module!()` brings the allocator and the panic handler.

```bash
cargo build --release --target wasm32-unknown-unknown
```

## Exports

Each macro takes the items it exports and writes them as they are, beside the symbols the host calls.

```rust standalone_crate
#![cfg_attr(target_arch = "wasm32", no_std, no_main)]

extern crate alloc;

use alloc::string::String;
use interpreter::plugin::*;

// the allocator and panic handler every wasm32 plugin needs
plugin_module!();

plugin_fn! {
    // a module constant the program reads once at import
    #[constant]
    fn version() -> i64 { 1 }

    // every argument after `sep` joined as the runtime writes it
    fn join(sep: String, parts: Args) -> Result<String> {
        let mut out = String::new();
        for (i, h) in parts.iter().enumerate() {
            if i > 0 { out.push_str(&sep); }
            out.push_str(&h.text()?);
        }
        Ok(out)
    }
}

plugin_class! {
    pub struct Counter { n: i64 }

    impl Counter {
        #[ctor]
        pub fn new() -> Self { Self { n: 0 } }

        pub fn add(&mut self, by: i64) -> i64 {
            self.n += by;
            self.n
        }
    }
}

#[cfg(not(target_arch = "wasm32"))]
fn main() {}
```

| Macro | Exports | As |
|---|---|---|
| `plugin_module!` | The allocator and the panic handler a wasm32 plugin needs | |
| `plugin_fn!` | Functions a program calls, and with `#[constant]` a zero-param function read once as a module constant | `__fn_<name>`, `__const_<name>` |
| `plugin_class!` | A struct whose instances live in the plugin under the id their object keeps, with its `impl` of methods and the `#[ctor]` one as the constructor | `__class_<Name>_<method>`, `__class_<Name>_init` |
| `plugin_resume!` | The function a waiting system call settles into | `__interpreter_resume` |

A param is any type with `FromValue`, which are `i64`, `i128`, `f64`, `bool`, `String`, `Bytes`, `Vec<f64>`, `interpreter::abi::WireValue`, `Vec<WireValue>`, `Option<T>` and a borrowed `Handle`. `Args` takes every positional past the fixed params and reads them with `iter`, `get` and `len`, and `Kwargs`, last, takes the keywords. A function returns any type with `IntoValue`, or a `Result` of one. A `WireValue` turns into a handle with `into_handle`. An `Error` raises in the program as the class its kind names, and `Error::kind` gives that kind as an `abi::ErrorKind`. `Error::custom(text)` raises the class its text names. A misplaced `Args` or `Kwargs` fails the build.

## Importing it

A program imports the plugin by the name its `interpreter.json` gives the file.

```json
{ "imports": { "tools": "./tools.wasm" } }
```

```lox main.lox
var tools = import("tools");
print tools.join("-", "a", "b", 3);
var c = tools.Counter();
c.add(2);
print c.add(3);
```

A host loads a plugin whose `__interpreter_abi_version` is from v1 to its own `abi::PLUGIN_ABI`, and refuses a newer one with an error that names both. A plugin built for v1 loads in every later host, as [Stability](./09-stability.mdx#formats-and-the-abi) sets out.

## Handles and system calls

A `Handle` is a value of the program the plugin holds, and its methods run the program's own operations on it, which are `get_attr`, `set_attr`, `get_item`, `set_item`, `len`, `iter` and `iter_next`, `call`, `text` and `type_of`. `Handle::new_list`, `new_dict`, `new_tuple`, `new_set` and `new_frozenset` build new ones. An argument is borrowed for its call, and a handle an operation returns is released when it drops.

`Handle::sys("module.name", args)` calls a host module the plugin's package was granted, such as `net`. A call that answers later returns `Error::Waiting`, the program waits with it, and the host calls the function `plugin_resume!` exports with the call's id and its answer once it settles. `call_id()` names the running call, so a plugin keeps what it needs under it in a `PluginCell`.
