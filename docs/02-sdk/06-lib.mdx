# Lib

`lib` holds the natives a runtime would otherwise write itself, as kernels with no name and no words of their own. A runtime picks the modules it needs by Cargo feature, gives each kernel its name in a table with `lib::table!`, and makes every choice a kernel leaves open through its [`Language`](./04-language.mdx) and lib's `Lang` trait. Mini names every kernel of lib but the `data` readers and writers, `seq::top` and `date::part`, under the names its corpus calls. Tiny names a few, mostly under the names mini gives them.

Uptime's table is the smallest use of lib in the repo, four entries in the 23 lines of `examples/uptime/src/natives.rs`, each giving one kernel the name a check calls. Its first argument is the runtime whose choices the four kernels follow.

```rust file=examples/uptime/src/natives.rs
use edge::lang::{Native, Natives};
use edge::value::foreign::Kind;
use lib::{data, io, seq};

use crate::Uptime;

// the four natives a check calls each a lib kernel under its own name
const TABLE: &[Native] = &lib::table![Uptime;
    "print" => io::print,
    "exit" => io::exit,
    "json" => data::json::read,
    "size" => seq::len,
];

pub static NATIVES: Natives = edge::natives! {
    language: Uptime,
    fns: [TABLE],
    methods: [],
    types: &crate::names::TYPES,
};

// the kind that boxes an int too wide for an inline value
pub static WIDE: Kind = lib::num::big::kind::<Uptime>("int");
```

The crate is `no_std` and forbids `unsafe` code. Mini names its natives a line each in one file of 291 lines. Tiny names 22 kernels of lib, three of them for its lowering alone, and writes three natives of its own for programs beside 16 that only its lowering calls.

## Modules

Each module but `fmt` sits behind a feature of its own name, and a feature pulls in the modules whose helpers it calls. The default feature `all` takes every module, as mini and tiny do.

| Module | Pulls in | Kernels |
|---|---|---|
| `io` | | `print`, `read_line`, `receive`, `send`, `exit` |
| `iter` | | `range`, `iter`, `next`, `numbered`, `zipped`, `mapped`, `filtered`, `backward`, `range_index`, `range_count`, the generator steps `send`, `throw` and `close`, and in `iter::fold` the folds `every`, `some`, `least`, `most` and `sum` |
| `seq` | `iter`, `num` | `len`, `list`, `tuple`, `index`, `count`, `push`, `pop`, `insert`, `remove`, `extend`, `reverse`, `copy`, `clear`, `sort::sorted`, `sort::sort` and `top::top`, with `top::greatest`, which picks the greatest keys without sorting them all |
| `map` | `iter` | `new`, `get`, `keys`, `values`, `items`, `pop`, `pop_last`, `set_default`, `update`, `copy`, `clear`, `from_keys` |
| `set` | `iter` | `new`, `add`, `remove`, `discard`, `pop`, `clear`, `copy`, `union`, `intersection`, `difference`, `symmetric`, `subset`, `superset`, `disjoint`, and the forms that update in place |
| `num` | `iter` | `abs`, `div::divmod`, `pow::pow`, `round::round`, `hash::hash`, the `int` and `float` kernels, and wide ints in `num::big` |
| `text` | `bytes`, `iter`, `num` | `text`, `char_of`, `code_of`, and the modules `case`, `class`, `cut`, `edit`, `find` and `pad` |
| `bytes` | `iter`, `num` | `new`, `codec::encode`, `codec::decode`, the `hex` kernels and the buffer methods of `bytes::methods` |
| `data` | `iter`, `map` | `lines::lines`, `json::read`, `json::write`, `csv::read` and `csv::write`, with the helpers a runtime's own natives call, such as `lines::Lines`, `json::parse` and `csv::fields` |
| `date` | | `parse` and `part`, with `time_kind` and `duration_kind`, which make the kinds a runtime boxes its times and durations in |
| `types` | | `is_a`, `is_sub`, `type_of`, `callable`, `truth`, and the `match_exc` hook |
| `reflect` | | `get`, `has`, `set`, `delete` |
| `fmt` | `num` for `spec` | `render::repr_of` and `render::ascii_of`, the `render` hook in `fmt::render`, and the `format` hook in `fmt::spec` behind the `spec` feature |

`fail`, `kernel`, `lang` and `uni` are always in. They hold the failures, the kernel type, the runtime's choices and the Unicode tables the others share.

## A kernel

A kernel is a `const fn` generic over a `Site` that returns a `Kernel`, a native's body with its signature, fast paths and flags and no name yet. A choice the kernel leaves open is one more type parameter after the site. `text::case` holds six kernels and one such choice, `Case`, which decides whether a character whose other case is several characters maps to them or stays as it is.

```rust file=lib/src/text/case.rs
use alloc::string::String;
use alloc::vec::Vec;

use edge::lang::{Args, Cx, Ret, Sig};

use super::{new_str, push_lower, push_upper, recv_str};
use crate::{Kernel, Site, uni};

/* the text in uppercase as `C` maps each character */
pub const fn upper<S: Site, C: Case>() -> Kernel { Kernel::new(Sig::exact(0), upper_run::<C>) }

/* the text in lowercase as `C` maps each character */
pub const fn lower<S: Site, C: Case>() -> Kernel { Kernel::new(Sig::exact(0), lower_run::<C>) }

/* the first character in titlecase and the rest lowercased */
pub const fn capitalize<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), capitalize_run) }

/* each run of cased characters titlecased first and lowercased after */
pub const fn title<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), title_run) }

/* each cased character turned to the other case */
pub const fn swap<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), swap_run) }

/* the text folded so texts that differ only by case compare equal */
pub const fn fold<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), fold_run) }

/* how a case map treats a character whose other case is several characters */
pub trait Case: 'static {
    fn upper(s: &str) -> String;
    fn lower(s: &str) -> String;
}

/* one character maps to one and a longer mapping leaves it as it is */
pub struct Simple;

/* unicode's full mappings where one character may become several */
pub struct Full;

impl Case for Simple {
    fn upper(s: &str) -> String { s.chars().map(|c| one(c, c.to_uppercase())).collect() }
    fn lower(s: &str) -> String { s.chars().map(|c| one(c, c.to_lowercase())).collect() }
}

impl Case for Full {
    fn upper(s: &str) -> String { s.to_uppercase() }
    fn lower(s: &str) -> String { s.to_lowercase() }
}

/* the one character a mapping gives or `c` when it gives several */
fn one(c: char, mut mapped: impl Iterator<Item = char>) -> char {
    match (mapped.next(), mapped.next()) { (Some(m), None) => m, _ => c }
}

fn upper_run<C: Case>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { let out = C::upper(recv_str(cx, a.recv)?); new_str(cx, out) }

fn lower_run<C: Case>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { let out = C::lower(recv_str(cx, a.recv)?); new_str(cx, out) }

fn capitalize_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let out = {
        let s = recv_str(cx, a.recv)?;
        let mut cs = s.chars();
        let mut out = String::with_capacity(s.len());
        if let Some(c) = cs.next() {
            uni::push_title(&mut out, c);
            let rest = cs.as_str();
            // a capital sigma lowers by its place in the whole text first character included
            if rest.bytes().any(|b| b == SIGMA_END) { out.push_str(s.to_lowercase().get(lowered_len(c)..).unwrap_or("")); } else { out.push_str(&rest.to_lowercase()); }
        }
        out
    };
    new_str(cx, out)
}

/* the bytes first character `c` takes once its text is lowercased */
fn lowered_len(c: char) -> usize { if c == SIGMA { 'σ'.len_utf8() } else { c.to_lowercase().map(char::len_utf8).sum() } }

fn title_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let ascii = cx.is_ascii(a.recv);
    let out = {
        let s = recv_str(cx, a.recv)?;
        // ascii text maps byte by byte with no case tables
        if ascii { let out = ascii_title(s); return new_str(cx, out); }
        let mut finals = None;
        let (mut out, mut cased, mut cs) = (String::with_capacity(s.len()), false, s.chars());
        while let Some(c) = cs.next() {
            if !uni::is_cased(c) { out.push(c); cased = false; continue; }
            if !cased { uni::push_title(&mut out, c); } else if c == SIGMA { out.push(sigma(finals.get_or_insert_with(|| ends(s)), s.len() - cs.as_str().len() - c.len_utf8())); } else { push_lower(&mut out, c); }
            cased = true;
        }
        out
    };
    new_str(cx, out)
}

// the capital sigma whose lowercase takes its final form at the end of a word
const SIGMA: char = 'Σ';
// the last byte of a capital sigma which a scan finds with no decoding
const SIGMA_END: u8 = 0xA3;

/* an ascii text with each run of letters started uppercase and continued lowercase */
#[inline(never)]
fn ascii_title(s: &str) -> String {
    let mut cased = false;
    let out: Vec<u8> = s.bytes().map(|b| {
        let c = if !b.is_ascii_alphabetic() { b } else if cased { b.to_ascii_lowercase() } else { b.to_ascii_uppercase() };
        cased = b.is_ascii_alphabetic();
        c
    }).collect();
    String::from_utf8(out).unwrap_or_default()
}

/* an ascii text with each letter turned to the other case */
#[inline(never)]
fn ascii_swap(s: &str) -> String {
    let out: Vec<u8> = s.bytes().map(|b| if b.is_ascii_uppercase() { b.to_ascii_lowercase() } else { b.to_ascii_uppercase() }).collect();
    String::from_utf8(out).unwrap_or_default()
}

/* where capital sigmas of `s` take the final form as its whole lowercase tells */
fn ends(s: &str) -> Vec<usize> {
    let lowered = s.to_lowercase();
    let mut low = lowered.chars();
    let mut out = Vec::new();
    for (i, c) in s.char_indices() {
        // every other character lowers on its own so the two texts walk together
        if c != SIGMA { low.by_ref().take(c.to_lowercase().count()).for_each(drop); continue; }
        if low.next() == Some('ς') { out.push(i); }
    }
    out
}

/* the lowercase of the capital sigma at byte `at` given where the final forms fall */
fn sigma(finals: &[usize], at: usize) -> char { if finals.binary_search(&at).is_ok() { 'ς' } else { 'σ' } }

fn fold_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let out = {
        let s = recv_str(cx, a.recv)?;
        let mut out = String::with_capacity(s.len());
        s.chars().for_each(|c| uni::push_fold(&mut out, c));
        out
    };
    new_str(cx, out)
}

fn swap_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let ascii = cx.is_ascii(a.recv);
    let out = {
        let s = recv_str(cx, a.recv)?;
        // ascii text maps byte by byte with no case tables
        if ascii { let out = ascii_swap(s); return new_str(cx, out); }
        let mut finals = None;
        let (mut out, mut cs) = (String::with_capacity(s.len()), s.chars());
        while let Some(c) = cs.next() {
            if c == SIGMA { out.push(sigma(finals.get_or_insert_with(|| ends(s)), s.len() - cs.as_str().len() - c.len_utf8())); }
            else if c.is_uppercase() { push_lower(&mut out, c); } else if c.is_lowercase() { push_upper(&mut out, c); } else { out.push(c); }
        }
        out
    };
    new_str(cx, out)
}
```

A variant is a type, so a kernel compiles once for each variant a runtime picks and asks nothing at run time.

| Variant trait | Variants | What it decides | Mini | Tiny |
|---|---|---|---|---|
| `num::round::Round` | `HalfEven`, `HalfAway` | Which way a tie rounds | `HalfEven` | `HalfAway` |
| `text::case::Case` | `Simple`, `Full` | Whether one character may map to several | `Full` | `Full` |
| `uni::Digits` | `Ascii`, `Decimal`, `Digit`, `Numeric` | Which characters read as digits | `Decimal` to read numbers, and `Digit`, `Decimal` and `Numeric` in its digit tests | `Decimal` |
| `num::int::Radix` | `Bin`, `Oct`, `Hex` | The base and the prefix of an int's text | All three | None |
| `bytes::Buf` | `Fixed`, `Mutable` | Whether a buffer kernel makes fixed or mutable bytes | Both | None |
| `iter::fold::Refuse` | `Adds`, `Joins` | Whether a total refuses a text or bytes start, which a join builds instead | `Joins` | None |
| `text::cut::Breaks` | `Newline`, `Unicode` | Which characters end a line | Its own `Lines`, Unicode's breaks and three information separators | None |
| `num::hash::Scheme` | None in lib | The modulus and the constants a hash mixes numbers and tuples with | Its own `Modular` | None |
| `date::Part` | `Days`, `Hours`, `Minutes`, `Seconds`, `Year`, `Month`, `Day`, `Hour`, `Minute`, `Second` | The field a `part` kernel reads as a method | None | None |

Tiny registers no `part` kernel. Its own natives `hours_between`, `minutes_between` and `days_between` take `Hours`, `Minutes` and `Days` as a type parameter and count the span between two times in that unit.

## A table

`lib::table!` turns a list of entries into the natives a runtime registers. Its first argument is the runtime whose choices every kernel of the table follows.

| Part of an entry | Gives the kernel | From mini |
|---|---|---|
| `"name" => path` | The name a program calls and the name its failures give | `"len" => seq::len` |
| `[Variant]` | The type parameters after the site, in order | `"lower" => text::case::lower[Full]` |
| `("a", "b")` | Names for the positionals a keyword may fill, where an empty name stays positional | `"sum" => iter::fold::sum[Joins]("", "start")` |
| `{"k"}` | Names for the keyword-only slots the kernel reads, in order, where names past its slots are taken and ignored | `"print" => io::print{"sep", "end", "file", "flush"}` |

The macro writes a `Site` for each entry, the runtime and the name and parameter names that entry gives. The kernel reads them at compile time. A table that names more positionals than its kernel takes fails to compile, and so does one that names some of the kernel's keyword slots and not all of them.

The tables go to `edge::natives!`, as functions under `fns` and as the methods of a kind under `methods`. Both runtimes do it in their `lib.rs`, shown on [Front ends](./14-front-ends.mdx), and the lookups are built at compile time, so a table costs nothing at boot. Mini's tables and tiny's follow side by side.

pub fn kind_name<'a>(cx: &'a Cx<'_, '_>, v: Val) -> &'a str { cx.type_name(v) }

/* the error a native raises when its receiver or argument is of another kind */
pub fn wrong(cx: &Cx<'_, '_>, what: &str, want: &str, v: Val) -> VmErr {
    VmErr::Raised(alloc::format!("WrongType: {what} takes {want}, not {}", kind_name(cx, v)))
}

/* the span from the first time to the second counted in the unit `P` names */
fn between<P: Part>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let what = match P::FIELD { Field::Days => "days_between", Field::Minutes => "minutes_between", _ => "hours_between" };
    let (start, end) = (instant(cx, a.pos[0], what)?, instant(cx, a.pos[1], what)?);
    Ok(Val::float(P::FIELD.of_duration(&Duration { nanos: end.nanos - start.nanos })).into())
}

/* the time a value holds or its RFC 3339 text spells */
fn instant(cx: &mut Cx<'_, '_>, v: Val, what: &str) -> Result<Time, VmErr> {
    if let Some(s) = cx.str_of(v) {
        if let Some(t) = Time::parse(s) { return Ok(t); }
        let shown = cx.render(v, Mode::Repr)?;
        return Err(VmErr::Raised(alloc::format!("BadData: invalid RFC 3339 time: {shown}")));
    }
    let heap = cx.heap();
    if let Some(t) = Cx::kind_token(heap, &crate::lang::TIME).and_then(|token| heap.foreign_payload::<Time>(token, v)) { return Ok(*t); }
    Err(wrong(cx, what, "times or RFC 3339 texts", v))
}

A call of a native compiles to one `CallNative` bound to its kernel, whatever name the table gave it. A runtime that names `seq::len` `size` keeps that call, and `tests/names.rs` holds a runtime that does. Four kernels also stand for an operation of the engine, `seq::len`, `iter::range`, `iter::next` and `types::is_a`, and a table that names two kernels for one of them fails to compile.

When lib holds no kernel for a native, the runtime writes it as a `Native::new(name, sig, run)` of its own and lists it beside its tables. Tiny writes `hours_between`, `minutes_between` and `days_between`, the spans between two times that lib holds no kernel for.

## Lang

`Lang` holds the choices a runtime makes for the kernels its tables name past what its `edge::lang::Language` says. It builds on `Language`, so each name and each rule a kernel reads has one home.

| Item | Decides |
|---|---|
| `TREE` | The classes the type tests walk, which `Tree::of` builds from the classes of the runtime's `Names` |
| `class(c)` | The class a failure of each `Class` raises, by default the class `Names` gives the error kind it matches |
| `words(cx, at, f)` | The error a failure raises, lib's neutral words by default |
| `words_bare(f)` | The error a failure raises where no native call runs |
| `show_into` | How a value renders onto a text, lib's `render` by default |
| `codec`, `handler`, `codec_name` | The codecs and error handlers a program may name, none by default |
| `endian` | The byte orders a program may name for an int's bytes, none by default |
| `CENTRE` | Where a centred text puts the unit an odd pad leaves over, after the text by default |
| `NUMERALS` | The separator the digits of number text may hold, whether it may follow a prefix or run twice, whether base 0 takes a leading zero and whether a base the call names reads its own prefix, with no separator by default |
| `SEPARATORS` | Whether the four information separators count as white space in text, no by default |
| `MACHINE` | The machine ints a tab size and a buffer count must fit, none by default, so memory alone bounds them |
| `SPECS` | Which of `z`, grouping, `%`, `n` and `=` a format spec takes past its plain parts, none by default |
| `THROW_VALUE`, `SENTINEL` | Whether a generator's throw takes a value after its class and whether `iter` takes a sentinel after a function, neither by default |

Each default is the plainest rule, and a runtime states the rules its programs read. Mini states its corpus' rules in `examples/mini/src/lang.rs` below, tiny states only `SENTINEL`, which its lowering calls, and uptime states none.

Lib reads the rest off the runtime's `Language` through `Derived`, which every runtime gets and none writes. The iterators the kernels make take their names from `Names.iters`, a wide int boxes in the language's `WIDE` kind, made by `num::big::kind`, the decimal text of an int stops at the policy's `max_int_digits`, and a value renders through the language's `show`.

`Lang` also builds on `Style`, the rendering choices, each with a default. They cover the words for true and false, the quotes and escapes of text, the forms of floats, and how functions, types, modules and exceptions show. Nil, the ellipsis, a nameless function and a module body show as `Names` calls them. Tiny sets only the words for true and false, as `True` and `False` the way its expressions spell them, and takes every other default. Mini sets its own in `examples/mini/src/style.rs`.

## Failures and their words

A kernel never writes the text of an error. It fails with a `Fail`, a neutral value naming what went wrong and holding the values it went wrong with, such as `Fail::NotIterable(v)` or `Fail::BadJson { at, why }`. A reason is a field too, as `why` is a `fail::Json` or a `fail::ToJson` for JSON, a `fail::Csv` or a `fail::Coding` for a codec, and each shows as lib's words, so a runtime prints one as it stands or words it itself. `fail::<S>(cx, f)` raises a failure through `Lang::words` with the `At` of its site, the name, positionals and keywords its table entry gave it, so the words name the native as the program called it.

`english::<L>` holds lib's neutral words for every failure, and every runtime starts from it. Tiny words a literal that spells no number, a bad operand and an empty `min` or `max` itself and hands the rest to `english::<Tiny>`. Mini words its failures the way its corpus expects in `examples/mini/src/words.rs`, the reasons of a codec among them. A runtime whose errors read in another language words every failure itself.

Past the type errors the engine names itself, `Class` sorts a failure into `Value`, `Overflow`, `Index`, `Key`, `Lookup`, `Decode`, `Encode`, `End`, `Exit`, `Runtime` or `ZeroDiv`, and `Lang::class` names the class each one raises. Tiny raises `MissingField` for a key, an index or a lookup, `HostFailed` for a runtime failure, and `BadData` for the rest.

## What lib answers

The engine asks a runtime a few questions past its natives through its `Language`, and lib answers them by the runtime's choices. A runtime writes lib's answers as the parts of its language, as [The trait](./04-language.mdx#the-trait) lists with what the engine reads of each.

| Item | Lib's answer | Mini | Tiny |
|---|---|---|---|
| `show` | `fmt::render::hook::<L>`, a value as text under the runtime's `Style` | Yes | Yes |
| `format` | `fmt::spec::hook::<L>`, a value under a format spec | Yes | No |
| `handles` | `types::match_exc::<L>`, whether a raised value matches the classes a handler names through `TREE` | Yes | No |
| `WIDE` | A kind made by `num::big::kind::<L>` | Yes | Yes |
| `KINDS` | The runtime's time and duration kinds, which a restore names before any value | Yes | Yes |
| `BUILT` | The slice kind `seq::slice::<L>` and the ellipsis kind `types::dots::<L>` the engine builds | Yes | Yes |
