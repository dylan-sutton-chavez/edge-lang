# Natives

A native is a Rust function a runtime registers, and every call past the bytecode reaches one. [Natives](../01-get-started/04-book/03-natives.mdx) in the book covers why the engine asks for them and where a runtime gets them, and [Lib](./06-lib.mdx) covers the kernels and the tables that name them. This page is the reference of the engine's side, the types of `edge::lang` a native is written against and what the engine does around each call.

## Native

A `Native` is a constant of the runtime's crate. Its builders are `const fn`, so a table of natives is laid out while the runtime compiles and costs nothing at boot.

| Field | Holds |
|---|---|
| `name` | The name a program calls it by and its errors give, which `named` replaces |
| `sig` | The `Sig` a call is checked against before the body runs |
| `run` | The body, a `NativeFn` that takes a `Cx` and the `Args` and returns a `Ret` |
| `fast1`, `fast2` | A path that answers one or two plain arguments straight from the heap, or declines with `None` |
| `fast_out` | The line a call of plain positionals writes with no call, for a native that prints |
| `flags` | The flags below |
| `intrinsic` | The operation of the engine the native stands for, `Intrinsic::None` for most |

`Native::new(name, sig, run)` makes one, and `fast`, `fast2`, `fast_out`, `flags` and `intrinsic` each give it back with one more part. Lib's `Kernel` wraps a `Native` with no name yet and the same builders, and a table entry names it with `named`.

| Flag | Means | In lib |
|---|---|---|
| `STEPS` | The body may answer with a step, so a call of it counts as one that runs program code | `seq::list`, `iter::fold::sum`, `io::receive` |
| `TYPE` | Its name reads as a type object, and calling that type runs the native | `seq::list`, `map::new`, `set::new` |
| `PUSH` | A method of lists whose call on a local lowers to the push the loop makes in place | `seq::push` |
| `CLASS` | Read off its type, it takes the type itself as its receiver | `map::from_keys` |

The four intrinsics are operations the engine reaches for on its own. `Len`, `Range`, `Next` and `IsA` are carried by lib's `seq::len`, `iter::range`, `iter::next` and `types::is_a`, a table names at most one native for each, and the lowering keeps the form of a call that names one, as [Lib](./06-lib.mdx#a-table) describes.

`lib/src/seq/mod.rs` shows every part in one module. `len` has a fast path and stands for `Len`, `list` and `tuple` are types that may step, `push` lowers in place, `extend` drains what it cannot copy at once, and the bodies spend for the items they move.

```rust file=lib/src/seq/mod.rs
use alloc::rc::Rc;
use alloc::vec::Vec;
use core::cell::RefCell;

use edge::lang::{Acc, Args, Cx, Flow, Fold, Intrinsic, Item, PUSH, Ret, STEPS, Sig, Step, TYPE};
use edge::value::foreign::{Kind, Snapshot};
use edge::value::{HeapObj, HeapPool, Val, VmErr};

use crate::fail::{Fail, fail, receiver};
use crate::iter::items::{drained, gather, generator, plain_items, taken};
use crate::{Kernel, Site};

pub mod sort;
mod timsort;
pub mod top;

/* the kind of the slice a key of bounds makes under the type name `type_name` */
pub const fn slice<L: crate::Lang>(type_name: &'static str) -> Kind {
    Kind {
        name: "bounds",
        type_name,
        family: "bounds",
        // two slices of equal bounds are equal and hash each bound as a table does
        hash: |heap, p| p.downcast_ref::<[Val; 3]>().map_or(0, |b| b.iter().fold(0x5_11CE, |h: u64, &v| (h ^ edge::value::hash_val_with_heap(v, heap)).wrapping_mul(0x100_0000_01B3))),
        eq: |heap, p, other| p.downcast_ref::<[Val; 3]>().zip(heap.slice_of(other)).is_some_and(|(a, b)| a.iter().zip(b).all(|(&x, y)| edge::value::eq_vals_with_heap(x, y, heap))),
        get: Some(bound::<L>),
        snapshot: Snapshot::Store,
        ..Kind::PLAIN
    }
}

/* the start stop or step of a slice under the runtime's field names */
fn bound<L: crate::Lang>(heap: &mut HeapPool, v: Val, name: &str) -> Result<Option<Val>, VmErr> {
    Ok(heap.slice_of(v).zip(L::NAMES.fields.bound(name)).map(|(b, i)| b[i]))
}

/* how many items a container holds */
pub const fn len<S: Site>() -> Kernel { Kernel::new(Sig::exact(1), len_run).fast(len_of).intrinsic(Intrinsic::Len) }

/* a new list of every item of an iterable */
pub const fn list<S: Site>() -> Kernel { Kernel::new(Sig::range(0, 1), list_run).fast(list_fast).flags(TYPE | STEPS) }

/* a new tuple of every item of an iterable where a tuple is itself */
pub const fn tuple<S: Site>() -> Kernel { Kernel::new(Sig::range(0, 1), tuple_run).fast(tuple_fast).flags(TYPE | STEPS) }

/* where an item first sits between a start and a stop */
pub const fn index<S: Site>() -> Kernel { Kernel::new(Sig::range(1, 3), index_run::<S>) }

/* how many items equal a value */
pub const fn count<S: Site>() -> Kernel { Kernel::new(Sig::exact(1), count_run::<S>) }

/* removes the first item equal to a value */
pub const fn remove<S: Site>() -> Kernel { Kernel::new(Sig::exact(1), remove_run::<S>) }

/* a new list of the same items */
pub const fn copy<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), copy_run) }

/* adds an item at the end which a call on a local lowers in place */
pub const fn push<S: Site>() -> Kernel { Kernel::new(Sig::exact(1), push_run).flags(PUSH) }

/* removes every item */
pub const fn clear<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), clear_run) }

/* turns the items around in place */
pub const fn reverse<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), reverse_run) }

/* adds every item of an iterable at the end */
pub const fn extend<S: Site>() -> Kernel { Kernel::new(Sig::exact(1), extend_run).flags(STEPS) }

/* puts an item before an index */
pub const fn insert<S: Site>() -> Kernel { Kernel::new(Sig::exact(2), insert_run::<S>) }

/* removes and gives the item at an index or the last */
pub const fn pop<S: Site>() -> Kernel { Kernel::new(Sig::range(0, 1), pop_run::<S>) }

fn len_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let n = cx.len(a.pos[0])?;
    Ok(cx.new_int(n)?.into())
}

/* the length the loop takes with no call and none where the full call answers */
fn len_of(heap: &mut HeapPool, v: Val) -> Option<Val> {
    let n = match heap.try_get(v)? {
        HeapObj::List(l) => l.borrow().len(),
        HeapObj::Tuple(t) => t.len(),
        HeapObj::Dict(d) => d.borrow().len(),
        HeapObj::Set(s) => s.borrow().len(),
        HeapObj::Bytes(b) | HeapObj::ByteArray(b) => b.len(),
        HeapObj::Str(_) => heap.text_len(v)?,
        &HeapObj::Range(s, e, st) => return word(crate::iter::span(s, e, st)?),
        _ => return None,
    };
    i64::try_from(n).ok().and_then(Val::int_checked)
}

/* a count as an inline int and none past what one holds */
fn word(n: i128) -> Option<Val> { i64::try_from(n).ok().and_then(Val::int_checked) }

fn list_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let Some(src) = a.get(0) else { return Ok(cx.new_list(Vec::new())?.into()) };
    if generator(cx, src) { return if cx.spent(src) { Ok(cx.new_list(Vec::new())?.into()) } else { Ok(drained(src, list_end, Acc::new())) }; }
    if let Some(v) = list_fast(cx.heap_mut(), src) { return Ok(v.into()); }
    match cx.items(src)? {
        Some(items) => Ok(cx.new_list(items)?.into()),
        None => Ok(drained(src, list_end, Acc::new())),
    }
}

/* the end of a list drain making the list of every item it gathered */
fn list_end(acc: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    let Item::End(_) = item else { return taken(acc, cx, item) };
    Ok(Flow::Stop(cx.new_list(core::mem::take(&mut acc.items))?))
}

/* a list of a list tuple or range copied with no call */
#[inline]
fn list_fast(heap: &mut HeapPool, x: Val) -> Option<Val> {
    if !copies(heap, x) { return None; }
    let items = plain_items(heap, x)?;
    heap.alloc(HeapObj::List(Rc::new(RefCell::new(items)))).ok()
}

fn tuple_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let Some(src) = a.get(0) else { return Ok(cx.new_tuple(Vec::new())?.into()) };
    if generator(cx, src) { return if cx.spent(src) { Ok(cx.new_tuple(Vec::new())?.into()) } else { Ok(drained(src, tuple_end, Acc::new())) }; }
    if let Some(v) = tuple_fast(cx.heap_mut(), src) { return Ok(v.into()); }
    match cx.items(src)? {
        Some(items) => Ok(cx.new_tuple(items)?.into()),
        None => Ok(drained(src, tuple_end, Acc::new())),
    }
}

/* the end of a tuple drain making the tuple of every item it gathered */
fn tuple_end(acc: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    let Item::End(_) = item else { return taken(acc, cx, item) };
    Ok(Flow::Stop(cx.new_tuple(core::mem::take(&mut acc.items))?))
}

/* a tuple of a tuple as itself and of a list or range copied */
#[inline]
fn tuple_fast(heap: &mut HeapPool, x: Val) -> Option<Val> {
    if let Some(HeapObj::Tuple(_)) = heap.try_get(x) { return Some(x); }
    if !copies(heap, x) { return None; }
    let items = plain_items(heap, x)?;
    heap.alloc(HeapObj::Tuple(items)).ok()
}

/* whether the items of `x` copy with no call */
#[inline(always)]
fn copies(heap: &HeapPool, x: Val) -> bool { matches!(heap.try_get(x), Some(HeapObj::List(_) | HeapObj::Tuple(_) | HeapObj::Range(..))) }


fn index_run<S: Site>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { search::<S>(cx, a.recv, Search::Index, a.pos) }

fn count_run<S: Site>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { search::<S>(cx, a.recv, Search::Count, a.pos) }

fn remove_run<S: Site>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { search::<S>(cx, a.recv, Search::Remove, a.pos) }

#[derive(Clone, Copy, PartialEq)]
enum Search { Index, Count, Remove }

/* index count or remove of `pos[0]` over the items which no comparison can change */
fn search<S: Site>(cx: &mut Cx<'_, '_>, recv: Val, what: Search, pos: &[Val]) -> Ret {
    let len = match cx.heap().try_get(recv) {
        Some(HeapObj::List(rc)) => rc.borrow().len(),
        Some(HeapObj::Tuple(t)) => t.len(),
        _ => return Err(receiver()),
    };
    cx.spend(len);
    // an index search clamps its bounds as every window does
    let (start, stop) = if what == Search::Index {
        crate::num::seq_bounds(cx, pos.get(1).copied(), pos.get(2).copied(), len).map_err(|e| e.raise::<S>(cx))?.unwrap_or((len, len))
    } else { (0, len) };
    let (x, count) = (pos[0], what == Search::Count);
    // two inline ints compare by value with no lookup
    let scan = |items: &[Val]| -> Result<(Option<usize>, i64), VmErr> {
        let mut hits = 0;
        for (i, &v) in items.iter().enumerate() {
            let same = if v.is_int() && x.is_int() { v.as_int() == x.as_int() } else { cx.eq(v, x)? };
            if !same { continue; }
            if !count { return Ok((Some(start + i), 0)); }
            hits += 1;
        }
        Ok((None, hits))
    };
    let (at, hits) = match cx.heap().try_get(recv) {
        Some(HeapObj::List(rc)) => { let items = rc.borrow(); scan(items.get(start..stop).unwrap_or(&[]))? }
        Some(HeapObj::Tuple(t)) => scan(t.get(start..stop).unwrap_or(&[]))?,
        _ => (None, 0),
    };
    match (what, at) {
        (Search::Count, _) => Ok(Val::int(hits).into()),
        (Search::Index, Some(i)) => Ok(Val::int(i as i64).into()),
        (Search::Remove, Some(i)) => {
            if let Some(HeapObj::List(rc)) = cx.heap().try_get(recv) && i < rc.borrow().len() { rc.borrow_mut().remove(i); }
            Ok(Val::none().into())
        }
        (_, None) => Err(fail::<S>(cx, Fail::NotFound(recv))),
    }
}

/* the list `recv` holds through `f` where any other receiver fails */
fn with_list<R>(cx: &mut Cx<'_, '_>, recv: Val, f: impl FnOnce(&mut Vec<Val>) -> R) -> Result<R, VmErr> {
    match cx.heap().try_get(recv) {
        Some(HeapObj::List(rc)) => Ok(f(&mut rc.borrow_mut())),
        _ => Err(receiver()),
    }
}

fn copy_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let items = with_list(cx, a.recv, |l| l.clone())?;
    cx.spend(items.len());
    Ok(cx.new_list(items)?.into())
}

fn push_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    with_list(cx, a.recv, |l| l.push(a.pos[0]))?;
    Ok(Val::none().into())
}

fn clear_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    with_list(cx, a.recv, Vec::clear)?;
    Ok(Val::none().into())
}

fn reverse_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let moved = with_list(cx, a.recv, |l| { l.reverse(); l.len() })?;
    cx.spend(moved);
    Ok(Val::none().into())
}

/* takes a container at once and user steps after a drain gathers them */
fn extend_run(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let Some(items) = cx.items(a.pos[0])? else {
        let mut acc = Acc::new();
        acc.v[0] = a.recv;
        return Ok(Step::Drain { it: a.pos[0], fold: Fold::collect(extend_fold, acc) }.into());
    };
    with_list(cx, a.recv, |l| l.extend_from_slice(&items))?;
    Ok(Val::none().into())
}

/* the drain of `extend` whose end adds every item at once */
fn extend_fold(acc: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    match item {
        Item::Next(v) => gather(acc, cx, v),
        Item::End(_) => {
            let items = core::mem::take(&mut acc.items);
            with_list(cx, acc.v[0], |l| l.extend_from_slice(&items))?;
            Ok(Flow::Stop(Val::none()))
        }
        Item::Called(_) => Ok(Flow::More),
    }
}

fn insert_run<S: Site>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let (at, v) = (a.pos[0], a.pos[1]);
    // a bool is its int and any int a word holds clamps to the list
    let i = match crate::num::word(cx, at) {
        Some(r) => r?,
        None => return Err(fail::<S>(cx, Fail::IndexType(a.recv))),
    };
    let moved = with_list(cx, a.recv, |l| {
        // an index past what a pointer holds lies past the end on any target
        let ui = if i < 0 { (l.len() as i64).saturating_add(i).max(0) as usize } else { usize::try_from(i).map_or(l.len(), |u| u.min(l.len())) };
        l.insert(ui, v);
        l.len() - ui
    })?;
    // the items past the slot shift as native work
    cx.spend(moved);
    Ok(Val::none().into())
}

fn pop_run<S: Site>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    // the index is read before the list and only one past a word overflows
    let at = match a.get(0).map(|v| crate::num::word(cx, v)) {
        None => None,
        Some(Some(r)) => Some(r?),
        Some(None) => return Err(fail::<S>(cx, Fail::IndexType(a.recv))),
    };
    let popped = with_list(cx, a.recv, |l| {
        let Some(i) = at else { return l.pop().map(|v| (v, 0)).ok_or_else(|| Fail::EmptyPop(Val::undef())) };
        if l.is_empty() { return Err(Fail::EmptyPop(Val::undef())); }
        let ui = if i < 0 {
            let adj = (l.len() as i64).saturating_add(i);
            if adj < 0 { return Err(Fail::PopRange); }
            adj as usize
        } else { usize::try_from(i).map_err(|_| Fail::PopRange)? };
        if ui >= l.len() { return Err(Fail::PopRange); }
        Ok((l.remove(ui), l.len() - ui))
    })?;
    let (popped, moved) = match popped {
        Ok(p) => p,
        // the receiver names the kind once the borrow of its items is over
        Err(Fail::EmptyPop(_)) => return Err(fail::<S>(cx, Fail::EmptyPop(a.recv))),
        Err(Fail::IndexType(_)) => return Err(fail::<S>(cx, Fail::IndexType(a.recv))),
        Err(f) => return Err(fail::<S>(cx, f)),
    };
    cx.spend(moved);
    Ok(popped.into())
}
```

## Sig

A `Sig` is what a call must fit, and the engine checks it before the body runs, so a body never counts its arguments.

| Part | Means | Built with |
|---|---|---|
| `min`, `max` | How many positionals a call passes, with `max` at `VAR` for no upper bound | `Sig::exact(n)`, `Sig::range(min, max)`, `Sig::var(min)` |
| `names` | A name for each positional a keyword may fill, where an empty name keeps it positional | `named(&[..])` |
| `kw` | The keyword-only parameters, read back by their index | `kw(&[..])` |
| `extra` | Whether keywords the signature does not name pass on as name and value pairs | `extra()` |

The positionals take their places first. A keyword that `names` holds fills its place, one that `kw` lists fills its slot, and with `extra` the rest pass on whole. A call that does not fit raises the runtime's type error and never reaches the body. The runtime's `misfit` words the error from a `Misfit`, which is `Count`, `Unexpected`, `Twice` or `Missing`, and a runtime that writes no `misfit` gets the engine's own words.

Uptime writes no `misfit`, so a check that hands `size` a second argument reads in the engine's words. This ran on 24 October 2026 in a copy of `examples/uptime/checks`, beside its `http.up` helper and its grants.

```text
$ uptime run -c 'use .http
let ping = http.get("https://registry.npmjs.org/-/ping")
print(ping.status, size(ping.body, "bytes"))'
error: WrongType: size() takes 1 argument, not 2
  --> <eval>:3:1
  |
3 | print(ping.status, size(ping.body, "bytes"))
  | ^
```

Mini's hook words the same misfit its own way, so `len(line, 'bytes')` in mini fails with `TypeError: len() takes exactly one argument (2 given)`. The class is the one each runtime names for a type error.

## Args

| Field | Holds |
|---|---|
| `recv` | A method's receiver, and `Val::undef()` for a function |
| `pos` | The positionals in the order of the signature, a keyword that filled one in its place and one left out as `Val::undef()` |
| `kw` | The keyword-only values in the order `kw` lists them, `Val::undef()` where none came |
| `named` | The keywords the signature does not name, as name and value pairs, when it takes them |

`get(i)` and `kw(i)` read one and answer `None` for one left out, and `len` counts the positionals. A body reads `pos` below `min` by index with no check, since the signature was checked, as tiny's `between` reads `a.pos[0]` and `a.pos[1]` in [A native of its own](../01-get-started/04-book/03-natives.mdx#a-native-of-its-own).

## Cx

`Cx` is what a body gets of the engine. None of its operations runs program code. One that would have to, such as stepping a generator a program wrote, answers `None` instead, and the native answers with a step.

| Group | Operations |
|---|---|
| Reading values | `kind`, `type_name`, `truthy`, `int`, `float`, `text`, `str_of`, `bytes_of`, `is_ascii`, `kw_name`, `fn_name`, `names` |
| Computing | `eq`, `lt`, `add`, `floor_div`, `modulo`, `pow`, `len`, `get_item`, `slice`, `contains`, `callable` |
| Checking keys | `require_key`, `require_element`, `require_hashable` |
| Making values | `new_int`, `new_str`, `new_list`, `new_tuple`, `new_dict`, `new_set`, `new_bytes`, `new_iter`, `type_object` |
| Iterating | `items`, `iter_of`, `next_plain`, `call_each`, `dict_walk`, `spent`, `resumable`, `is_generator`, `is_coroutine`, `range_index`, `range_reversed` |
| Raising | `raised`, `stop_iteration`, `exc_base` |
| Fields | `get_attr`, `set_attr`, `del_attr` |
| Paying | `spend`, `charge`, `reserve`, `room` |
| The host | `write`, `line`, `write_line`, `read_line`, `take_event`, `send`, `sent` |
| Rendering | `render` |
| The heap | `heap`, `heap_mut`, `Cx::kind_token` |

- `items(v)` answers every item of a container at once, and `None` where stepping `v` would run program code. `next_plain` and `call_each` answer `None` the same way.
- `eq` compares as a container compares its members, identity first, and raises past the comparison depth. `lt` orders numbers, texts, bytes, lists, tuples and FOREIGN values whose kind orders them, and raises the runtime's type error for any other pair.
- `new_int` makes the narrowest int, inline when it fits 48 bits and boxed in the runtime's wide kind past them, as [Values](./02-values.mdx#val) describes.
- `str_of` reads a text and spends for its length, where `text` reads it for free.
- `raised(class, args, text)` makes the exception a handler catches, and a failure of a kernel goes through lib's `fail`, which words it through the runtime's `Lang`.

## Out and Step

A body returns a `Ret`, which is `Result<Out, VmErr>`. `Out::Val` is a value, `Out::Step` a step the engine runs, and `Out::Next(g)` asks the engine to run generator `g` to its next item. `.into()` makes an `Out` of a `Val` or a `Step`.

| Step | The engine | The native's value |
|---|---|---|
| `Call { f, args, n, then }` | Calls `f` on up to three arguments | What `then` makes of the call's value |
| `Drain { it, fold }` | Walks `it` item by item through `fold` | What the fold stops with |
| `Resume { g, sent }` | Sends a value into generator `g`, throws into it or closes it, as `Sent` says | What the generator gives |
| `Wait` | Parks the run until the host pushes an event | The event, as [Host waits](./10-host-waits.mdx#a-native-that-waits) shows |

`Step::call(f, args)` gives the call's value as the native's. `Step::call_then(f, args, then)` hands it to `then`, which is `Then::Fn` for a plain function, or `Then::Cont` for a value of a type implementing `Cont`, whose `resume` goes on from the value and whose `trace` names the values it keeps.

A `Fold` holds its function, an `Acc` and an inline kind. The function takes the `Acc` and an `Item`, `Next` for each item, `Called` for the value of a call it asked for and `End` once the iterable ends. It answers with a `Flow`, `More` to go on, `Call(f, x)` to call `f` on `x` first, `Stop(v)` to end with `v`, or `Drain(it)` to walk `it` through the same fold. An `Acc` keeps four values in `v`, a count in `n`, two floats in `f` and a list in `items`, and the collector reaches every value it holds.

An inline kind lets the engine take items itself, so the function sees only the end or the items the engine cannot take.

| Inline | The engine | Built with | In lib |
|---|---|---|---|
| `None` | Hands every item to the function | `Fold::new`, `Fold::with` | `map::from_keys` |
| `Truth(any)` | Stops at the first item of that truth | `Fold::truth` | `iter::fold::every`, `iter::fold::some` |
| `Collect` | Gathers every item into `acc.items` | `Fold::collect` | `seq::list`, `seq::extend` |
| `Words` | Adds ints that fit a word into `acc.n` | `Fold::words` | `iter::fold::sum` |
| `Extreme(min)` | Keeps the least or the greatest of plain numbers in `acc.v[0]` | `Fold::extreme` | `iter::fold::least`, `iter::fold::most` |
| `Keys` | Calls the key in `acc.v[0]` on each item and gathers what it gives | `Fold::keys` | `seq::sort::sorted` with a key the program wrote |
| `Best(min)` | Calls the key in `acc.v[3]` on each item and keeps the best | `Fold::best` | `iter::fold::least` and `iter::fold::most` with a key |
| `First` | Stops at the first item, or gives the default in `acc.v[0]` at the end | `Fold::first` | `iter::next` with a default |

`taking(take)` adds a function that takes an item with no engine op, or declines it to the fold's function. `lib/tests/steps.rs` holds a native for each kind of step, run on mini's tables.

```rust file=lib/tests/steps.rs
use edge::embed::{Limits, VM};
use edge::lang::{Acc, Args, Cont, Cx, Flow, Fold, Item, Native, Natives, Ret, Runtime, STEPS, Sent, Sig, Step, Then};
use edge::value::{SchedulerStatus, Val, VmErr};
use mini::Mini;
use mini::natives::{ARRAY, ATTR, BUFFER, BYTES, CONVERT, DICT, FLOAT, FOLDS, GEN, INT, IO, ITER, LIST, LIST_SORT, NEXT, NUM, RANGE, SET, SET_MANY, SORT, STR, TUPLE, TYPES};

// every run meters what it allocates as edge.wasm does
edge::allocator!();

const STEPPED: &[Native] = &[
    Native::new("apply", Sig::exact(2), apply).flags(STEPS),
    Native::new("apply_inc", Sig::exact(2), apply_inc).flags(STEPS),
    Native::new("twice", Sig::exact(2), twice).flags(STEPS),
    Native::new("total", Sig::exact(1), total).flags(STEPS),
    Native::new("first", Sig::exact(1), first).flags(STEPS),
    Native::new("keys", Sig::exact(2), keys).flags(STEPS),
    Native::new("resume", Sig::exact(2), resume).flags(STEPS),
    Native::new("shut", Sig::exact(1), shut).flags(STEPS),
    Native::new("wait", Sig::exact(0), wait),
    Native::new("sums", Sig::range(1, 4), sums).flags(STEPS),
    Native::new("lists", Sig::range(1, 3), lists).flags(STEPS),
    Native::new("joins", Sig::range(1, 4), joins).flags(STEPS),
    Native::new("chained", Sig::range(2, 4), chained).flags(STEPS),
    Native::new("every", Sig::exact(1), every).flags(STEPS),
    Native::new("words", Sig::exact(1), words).flags(STEPS),
    Native::new("most", Sig::exact(1), most).flags(STEPS),
];

static NATIVES: Natives = edge::natives! {
    language: Over,
    fns: [IO, ITER, NEXT, NUM, FOLDS, CONVERT, BYTES, SORT, ATTR, TYPES, STEPPED],
    methods: [
        Str => [STR],
        Bytes => [BUFFER],
        ByteArray => [ARRAY],
        List => [LIST, LIST_SORT],
        Tuple => [TUPLE],
        Dict => [DICT],
        Set => [SET, SET_MANY],
        Int => [INT],
        Float => [FLOAT],
        Range => [RANGE],
        Coro => [GEN],
    ],
    types: mini::types::NAMES,
};

static RUNTIME: Runtime = Runtime::of::<Over>();

// mini's language over these natives
struct Over;
mini::over!(Over, &NATIVES);

fn apply(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::call(a.pos[0], &a.pos[1..2]).into()) }

fn apply_inc(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::call_then(a.pos[0], &a.pos[1..2], Then::Fn(|cx, v| Ok(cx.add(v, Val::int(1))?.into()))).into()) }

// calls its function on its own value as the second call
struct Again(Val);

impl Cont for Again {
    fn resume(self: Box<Self>, _: &mut Cx<'_, '_>, got: Val) -> Ret { Ok(Step::call(self.0, &[got]).into()) }
    fn trace(&self, mark: &mut dyn FnMut(Val)) { mark(self.0); }
}

fn twice(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::call_then(a.pos[0], &a.pos[1..2], Then::Cont(Box::new(Again(a.pos[0])))).into()) }

fn total(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::Drain { it: a.pos[0], fold: Fold::new(sum_fold) }.into()) }

fn sum_fold(acc: &mut Acc, _: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    match item {
        Item::Next(v) if v.is_int() => { acc.n += v.as_int(); Ok(Flow::More) }
        Item::Next(_) => Err(VmErr::Type("total takes ints")),
        Item::End(_) => Ok(Flow::Stop(Val::int(acc.n))),
        Item::Called(_) => Ok(Flow::More),
    }
}

fn first(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::Drain { it: a.pos[0], fold: Fold::new(first_fold) }.into()) }

fn first_fold(_: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    match item {
        Item::Next(v) => Ok(Flow::Stop(v)),
        Item::End(ret) => Err(cx.stop_iteration(ret)),
        Item::Called(_) => Ok(Flow::More),
    }
}

fn keys(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let mut acc = Acc::new();
    acc.v[0] = a.pos[1];
    Ok(Step::Drain { it: a.pos[0], fold: Fold::with(keys_fold, acc) }.into())
}

fn keys_fold(acc: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    match item {
        Item::Next(v) => Ok(Flow::Call(acc.v[0], v)),
        Item::Called(k) => { acc.items.push(k); Ok(Flow::More) }
        Item::End(_) => Ok(Flow::Stop(cx.new_list(core::mem::take(&mut acc.items))?)),
    }
}

// the iterables a chained fold walks after the first kept last first in `v`
fn pending(a: &Args<'_>) -> Acc {
    let mut acc = Acc::new();
    for (k, &it) in a.pos[1..].iter().rev().enumerate() { acc.v[k] = it; }
    acc.n = (a.pos.len() - 1) as i64;
    acc
}

// the next iterable a chained fold walks or None once all went
fn next_of(acc: &mut Acc) -> Option<Val> {
    if acc.n == 0 { return None; }
    acc.n -= 1;
    Some(core::mem::replace(&mut acc.v[acc.n as usize], Val::undef()))
}

fn sums(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let mut acc = pending(&a);
    acc.f = (0.0, 0.0);
    Ok(Step::Drain { it: a.pos[0], fold: Fold::with(sums_fold, acc) }.into())
}

fn sums_fold(acc: &mut Acc, _: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    match item {
        Item::Next(v) if v.is_int() => { acc.f.0 += v.as_int() as f64; Ok(Flow::More) }
        Item::Next(_) => Err(VmErr::Type("sums takes ints")),
        Item::End(_) => Ok(match next_of(acc) { Some(it) => Flow::Drain(it), None => Flow::Stop(Val::int(acc.f.0 as i64)) }),
        Item::Called(_) => Ok(Flow::More),
    }
}

fn lists(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let mut acc = pending(&a);
    acc.v[3] = cx.new_list(Vec::new())?;
    Ok(Step::Drain { it: a.pos[0], fold: Fold::collect(lists_end, acc) }.into())
}

fn lists_end(acc: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    let Item::End(_) = item else { return Ok(Flow::More) };
    let part = cx.new_list(core::mem::take(&mut acc.items))?;
    if let Some(edge::value::HeapObj::List(rc)) = cx.heap().try_get(acc.v[3]) { rc.borrow_mut().push(part); }
    Ok(match next_of(acc) { Some(it) => Flow::Drain(it), None => Flow::Stop(acc.v[3]) })
}

fn joins(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::Drain { it: a.pos[0], fold: Fold::collect(joins_end, pending(&a)) }.into()) }

// the items stay gathered across the chain and form one list at its end
fn joins_end(acc: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    let Item::End(_) = item else { return Ok(Flow::More) };
    Ok(match next_of(acc) { Some(it) => Flow::Drain(it), None => Flow::Stop(cx.new_list(core::mem::take(&mut acc.items))?) })
}

// calls its first argument on each item of the iterables after it
fn chained(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let mut acc = Acc::new();
    for (k, &it) in a.pos[2..].iter().rev().enumerate() { acc.v[k] = it; }
    (acc.n, acc.v[3]) = ((a.pos.len() - 2) as i64, a.pos[0]);
    Ok(Step::Drain { it: a.pos[1], fold: Fold::with(chained_fold, acc) }.into())
}

fn chained_fold(acc: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    match item {
        Item::Next(v) => Ok(Flow::Call(acc.v[3], v)),
        Item::Called(k) => { acc.items.push(k); Ok(Flow::More) }
        Item::End(_) => Ok(match next_of(acc) { Some(it) => Flow::Drain(it), None => Flow::Stop(cx.new_list(core::mem::take(&mut acc.items))?) }),
    }
}

fn every(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::Drain { it: a.pos[0], fold: Fold::truth(false) }.into()) }

fn words(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::Drain { it: a.pos[0], fold: Fold::words(words_fold, Acc::new()) }.into()) }

// ints the engine added come in `n` and other numbers go to the float total
fn words_fold(acc: &mut Acc, _: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    match item {
        Item::Next(v) if v.is_float() => { acc.f.0 += v.as_float(); Ok(Flow::More) }
        Item::Next(v) if v.is_int() => { acc.f.0 += v.as_int() as f64; Ok(Flow::More) }
        Item::Next(_) => Err(VmErr::Type("words takes numbers")),
        Item::End(_) => Ok(Flow::Stop(if acc.f.0 == 0.0 { Val::int(acc.n) } else { Val::float(acc.f.0 + acc.n as f64) })),
        Item::Called(_) => Ok(Flow::More),
    }
}

fn most(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::Drain { it: a.pos[0], fold: Fold::extreme(false, most_fold, Acc::new()) }.into()) }

// the pairs the engine left to compare go through the slow path of `<`
fn most_fold(acc: &mut Acc, cx: &mut Cx<'_, '_>, item: Item) -> Result<Flow, VmErr> {
    match item {
        Item::Next(v) => { if acc.v[0].is_undef() || cx.lt(acc.v[0], v)? { acc.v[0] = v; } Ok(Flow::More) }
        Item::End(_) if acc.v[0].is_undef() => Err(VmErr::Value("most of nothing")),
        Item::End(_) => Ok(Flow::Stop(acc.v[0])),
        Item::Called(_) => Ok(Flow::More),
    }
}

fn resume(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::Resume { g: a.pos[0], sent: Sent::Value(a.pos[1]) }.into()) }

fn shut(_: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { Ok(Step::Resume { g: a.pos[0], sent: Sent::Close }.into()) }

fn wait(cx: &mut Cx<'_, '_>, _: Args<'_>) -> Ret {
    match cx.take_event() { Some(v) => Ok(v.into()), None => Ok(Step::Wait.into()) }
}

/* what `src` printed or its error with one event pushed at each wait */
fn run(src: &str, events: &[&str]) -> Result<String, String> {
    let (chunk, errors) = edge::code::compile_as::<Mini>(src);
    assert!(errors.is_empty(), "{src}: {:?}", errors.iter().map(|e| &e.msg).collect::<Vec<_>>());
    let mut vm = VM::with_runtime(&RUNTIME, &chunk, Limits::sandbox());
    let mut events = events.iter();
    loop {
        match vm.run() {
            Ok(_) => return Ok(vm.output_text()),
            Err(VmErr::HostYield(SchedulerStatus::PendingEvent)) => match events.next() {
                Some(e) => { vm.push_event(e).map_err(|e| e.to_string())?; }
                None => return Err("waited past its events".into()),
            },
            Err(e) => return Err(e.to_string()),
        }
    }
}

fn prints(src: &str, want: &str) {
    match run(src, &[]) {
        Ok(out) => assert_eq!(out, want, "{src}"),
        Err(e) => panic!("{src}: {e}"),
    }
}
```

The engine runs a step's calls as frames of the loop that called the native, never in a loop of their own, as [Calling program code from Rust](../05-internals/01-design.mdx#calling-program-code-from-rust) explains. So a callback is metered and limited as any other code is, and an error it raises leaves through the native's call with a note for its frame. The type count of [Tokens or a front end](../01-get-started/04-book/02-tokens.mdx#one-job-both-ways) with its key reading `kv[2]` in place of `kv[1]` stops inside the key, after reading the whole hour.

## The registry

`edge::natives!` builds a runtime's `Natives` at compile time from four parts and a fifth that a runtime with FOREIGN kinds of its own may add.

| Part | Holds |
|---|---|
| `fns` | Tables of functions, each a slice of `Native` such as a `lib::table!` gives |
| `methods` | For each kind, the tables of its methods, written `Str => [STR]` |
| `foreign` | For each FOREIGN kind, the tables of its methods, written `POINT => [POINT_METHODS]` after the static `Kind` it registers, as [A kind's methods](./02-values.mdx#a-kinds-methods) shows |
| `types` | The names a load gives as type objects |
| `language` | The runtime's [`Language`](./04-language.mdx), whose names and policy the tables take, with the parts lib answers listed in [What lib answers](./06-lib.mdx#what-lib-answers) |

The language names the tables as its `NATIVES`, and `Runtime::of` hands them to the engine with the rest of the language. Mini's `lib.rs` registers functions from eleven tables and methods on eleven kinds.

```rust file=examples/mini/src/lib.rs
#![no_std]
#![forbid(unsafe_code)]

extern crate alloc;

use edge::lang::{Descriptor, ErrKind, Front, Natives, Runtime};

mod codecs;
pub mod lang;
mod language;
mod names;
pub mod natives;
mod style;
pub mod types;
pub mod words;

pub use names::NAMES;
// the text type `over!` names in the crate it expands in
#[doc(hidden)]
pub use alloc::string::String as __String;
use natives::*;

pub static NATIVES: Natives = edge::natives! {
    language: Mini,
    fns: [IO, ITER, NEXT, NUM, FOLDS, CONVERT, BYTES, SORT, ATTR, TYPES, DATE],
    methods: [
        Str => [STR],
        Bytes => [BUFFER],
        ByteArray => [ARRAY],
        List => [LIST, LIST_SORT],
        Tuple => [TUPLE],
        Dict => [DICT],
        Set => [SET, SET_MANY],
        Int => [INT],
        Float => [FLOAT],
        Range => [RANGE],
        Coro => [GEN],
    ],
    types: types::NAMES,
};

pub static RUNTIME: Runtime = Runtime::of::<Mini>();

// mini reads every source through its own token table
pub const FRONT: Front = Front::spelled::<Mini>();

mod syntax;
pub use syntax::{Mini, MINI, INTERP, LADDER, NUMBERS, STRINGS};

// the names the CLI gives this runtime's files and errors
pub const DESCRIPTOR: Descriptor = Descriptor {
    language: "mini",
    extension: MINI.extension,
    entries: &["main.mini", "app.mini", "index.mini"],
    test_suffix: "_test.mini",
    scaffold: "print(\"hello from edge\")\n",
    example_fence: "edge",
    manifest_fence: "edge-manifest",
    type_error: names::ERRORS[ErrKind::Type as usize],
    value_error: names::ERRORS[ErrKind::Value as usize],
    runtime_error: names::ERRORS[ErrKind::Runtime as usize],
    denied_error: names::ERRORS[ErrKind::Permission as usize],
    failed_error: "OSError",

#[cfg(all(target_arch = "wasm32", feature = "web"))]
edge::web_exports!(RUNTIME);
```

The functions come first in the table, each kind's methods after them and each FOREIGN kind's last, and a native's place is the `NativeId` its calls compile to. The table writes each entry's place into its `id`, so a value, a site or a snapshot that holds a native compares it by that place and never by where the entry lies in memory. The lookups are built with the table. Functions are found by name through tables of hashes, and each kind keeps its methods sorted by the hash of their names behind a mask of name shapes, so most misses read no name at all. `find`, `function`, `method`, `get`, `intrinsic` and `kind_methods` read them. `digest` is a hash of every name in table order with each method's kind, which the identity a snapshot keeps holds, as [Snapshots](./11-snapshots.mdx) describes.

### Methods per kind

A method is a native registered on a `KindId`, the 22 kinds [Values](./02-values.mdx#kinds) lists. `x.name(..)` looks `name` up among the methods of the kind `x` has, once for the call site, which keeps what it found. The body reads its receiver in `recv`. Read off the type, a method is unbound and takes its receiver as its first argument, refused unless the receiver is of its kind, and with `CLASS` it takes the type itself. A method read off a value and kept, as `push = xs.append` keeps one, is a value of its own, the same one each time for one receiver.

Uptime registers no methods, so a name after a dot reads a key of a map under its `map_fields`. Tiny registers ten methods on texts and nothing on any other kind. The init every class ends in is no entry of the table, so its place is `NativeId::INIT`.

## Guardrails

The engine holds every native to the same rules, so a native cannot run program code on the side, outrun the budget or slip past the memory limit.

| When | What holds |
|---|---|
| The runtime compiles | `edge::natives!` refuses two functions of one name, a kind or a FOREIGN kind listed twice, two methods of one kind whose names hash alike and two natives for one intrinsic. A table holds at most 255 functions and 255 type names |
| The program compiles | A call of a native's name binds to its place in the table, and a name the program binds itself wins over the native |
| The call starts | The arguments bind to the `Sig`, and a call that does not fit raises before the body runs |
| The body runs | It reaches the engine only through `Cx`, which runs no program code, and no collection runs, so the values it makes stay alive until it returns |
| A step runs | Program code runs as frames of the running loop and is metered as any other code. Only what an `Acc` or a `Cont` holds stays alive across the step, and a wait inside a callback is refused, as [Host waits](./10-host-waits.mdx#where-a-run-may-wait) lists |
| The body returns | The work it spent is paid before the next instruction runs |

The digest of the registry is part of the identity that ties a saved run to the runtime it was saved under, so a restore under other natives is refused before the source parses.

## The budget

A run spends its op budget on its calls, the turns of its loops and the work its natives report, and [Limits](./12-limits.mdx#sandboxed-execution) covers what a run is held to. A native pays for its own work in four ways.

| Operation | Does | Fails |
|---|---|---|
| `cx.spend(n)` | Counts `n` units of work, paid when the native returns or at the run's next step | At that payment, once the budget is spent |
| `cx.charge(n)` | Pays `n` units at once | At once, when fewer than `n` are left |
| `cx.heap().afford(n)` | Refuses work of `n` units before it starts | At once, when the budget left at the last payment is short of it |
| `cx.reserve(bytes)` | Refuses a result of that many bytes before it is built | At once, with the runtime's memory error, when it would pass what `cx.room()` leaves |

`cx.room()` is what a result may still take, the memory limit or what is left under twice the limit with garbage counted, whichever is less, and no more than the instance has left. A kernel that grows its result an item at a time reads it as it goes, as lib's drains do.

Lib's kernels pay in proportion to the work they do, past a small floor of work most of them leave free.

- **Scans and copies.** Text and bytes methods pay for the length of their receiver, a slice for the items it copies, and the length of a long text past ASCII by its bytes. `str_of` spends for the text it reads.
- **Sorts.** A sort pays for its comparisons, and refuses before it starts a sort the budget left cannot pay for.
- **Wide ints and formats.** A wide int pays by the limbs it works on, and a format spec by the width or the precision it fills.
- **Hashes and equality.** A walk over nested containers pays for the items it reads, and past 1,048,576 of them it walks again remembering each part it already read, so a value built from shared parts costs what its distinct parts hold.
- **Results.** A kernel that builds a result reserves its size first, so `split`, `expandtabs`, the bytes kernels and the others refuse a result past the limit before a byte of it is built.

That is why the book's type count pays for every byte of the hour each `find` and each split reads, as [What a native pays](../01-get-started/04-book/03-natives.mdx#what-a-native-pays) measures.

`spend` costs one addition, so a kernel spends as it scans and the engine charges the total once the native returns. A drain pays one op for each item it takes, with the work its fold spent on the item before.
