# Opcodes

Every opcode of the engine is declared once, as a row of the table in `src/code/table.rs`. A row names the op and states its facts in columns, what it pops and pushes, what its operand names, where control goes past it and which register form the lowering writes for it. `edge::ops!` turns the table into the `OpCode` enum and into everything the compiler asks of an op, so each fact has one home and every reader takes it from there.

The table has three parts, and an op's byte is its place in them.

| Part | Rows | Holds |
|---|---:|---|
| `stack` | 112 | The ops the parser emits, in bytecode order, with the two the lowering fuses method calls into |
| `register` | 66 | The register forms only the lowering writes, each reading and writing frame slots |
| `internal` | 24 | The forms sections and calls lay |

`OpCode::ALL` holds the 178 ops of the first two parts, so `ALL[b]` is the op of byte `b`, and `OpCode::EVERY` holds all 202. Two of the stack ops, `And` and `Or`, are never in compiled code, since the parser writes both as jumps.

A stack instruction is a 4-byte record of an op and a 16-bit operand, as [Bytecode model](../05-internals/02-compiler.mdx#bytecode-model) shows. A register instruction holds an op, a flag byte `x` and three 16-bit operands `a`, `b` and `c`, as [Dispatch shape](../05-internals/01-design.mdx#dispatch-shape) describes. `OpR`, `UnaryR`, `BuildR` and `RowsR` carry a stack op in `x`, so one register form serves every stack op it runs over registers. `RuntimeOp` and its register form `RuntimeR` carry an op of the runtime's own table the same way, in the low byte of the operand and in `x`, as [A runtime's own opcodes](#a-runtimes-own-opcodes) shows.

## Columns

A stack row has eleven columns past its name, and a dash is the column's default.

| Column | Type | Says |
|---|---|---|
| `pops`, `pushes` | `Count` | The values it takes from the stack and leaves on it, a number or a count its operand or its chunk gives, `items`, `pairs`, `rest`, `spec`, `args`, `packed`, `site`, `gives`, `defaults`, `bases`, `iter`, `raised` or `high` for the high byte of the operand, and `?` where only the run knows |
| `operand` | `Operand` | What its operand names, such as a constant, a slot, a name, an attribute, a jump target, a count, a function, a class, a native site or an op of the runtime's own table |
| `arm` | `Arm` | The block of the register loop whose arm runs it over rows, `values`, `containers`, `calls`, `natives` or `flow` |
| `flow` | `Flow` | Where control goes past it, the next op by default, or `goto`, `fork`, `guard`, `leave` or `unwind` |
| `edge` | `Edge` | What the way to its jump target does to the stack, `keep`, `pop` or `catch` |
| `spill` | `Spill` | What the lowering spills at it so a run parked there resumes in any code, `under` or `every` |
| `operator` | `Operator` | The operator it applies, `binary`, `augmented` or `unary` |
| `fold` | `bool` | Whether its constant operands fold at compile time |
| `form` | `Option<OpCode>` | The register form the lowering writes for it |
| `branch` | `Option<OpCode>` | The compare and branch form of a comparison |

A register row has three and an internal row the first two. Its pops and pushes read as `?`, since only the run knows them, and its other columns hold their defaults.

| Column | Type | Says |
|---|---|---|
| `stack` | `Option<OpCode>` | The stack op a register form falls back to |
| `rows` | `Rows` | The rows it reads from `b` and writes from `a`, `op` for what its stack op takes and gives, `items` for many values into one, `unpack` for one value into many, `row` for a stack op over the rows from `a` |
| `fast` | `Fast` | The arm the loop and its slow path generate for it, `arith` for two numbers through the kernels of its stack op, `order` for two numbers ordered as its stack op orders them, `test` for a jump unless they keep that order, `bits` for two ints through a bitwise op, `move` for a copy, and a dash for an arm written by hand |

## What the macro generates

`edge::ops!` takes the name of a table and its three parts, and it writes the enum and its facts as constants.

| Item | Gives |
|---|---|
| `OpCode` | The enum the table names, one variant for each row, `#[repr(u8)]`, at its byte |
| `ALL`, `EVERY` | The ops of the stack and register parts, and every op with the internal forms past `ALL` |
| `INFO`, `info()` | The columns of each op as an `OpInfo` |
| `effect(operand, chunk)` | What an op pops and pushes falling through, and `None` where only the run knows, one arm per op as its columns count |
| `plain_effect(operand)` | The same where its operand alone sets the counts, and `None` where a chunk or the run must |
| `form`, `branch`, `operator`, `edge`, `rows` | One column each read alone, so a run reads no whole row |
| `HASH` | An FNV-1a hash of every column of every row in order |
| `is_jump`, `is_register`, `names_slot`, `names_attr`, `is_binary`, `folds_binary`, `ends_flow`, `unstacked` | The predicates, each written out of the columns or the parts |
| `folds!`, `attrs!`, `forms!` | The binary ops that fold, the ops naming an attribute and the register forms of one generated arm, as patterns a `match` takes as written |
| `simple!` | The register forms of each generated arm with their stack ops, handed to a macro that builds a whole `match` from them and the arms written by hand |

`OpInfo` adds `fixed` for the pops and pushes no operand sets, `taken` for the way to a jump's target, `rise` for the most it adds to the stack and `falls` for whether control reaches the next op.

The same macro declares a runtime's own table from one part named `own`, which [A runtime's own opcodes](#a-runtimes-own-opcodes) covers.

## What reads it

The compiler reads the table. A front end's `Builder` asks `is_binary` before it emits an operator, the passes over a chunk ask `names_slot` and match `attrs!`, and the folder matches `folds!` and asks `is_jump`. The loop reads `ALL` to decode the stack op a register form carries in `x`, and asks `is_register` and `is_jump` as it dispatches and lowers.

The loop reads the rest of what it knows of an op from the table too. `depth.rs` takes its stack effects, rises, spills and steps from the columns, `lower.rs` its register, branch and stack forms and the counts of an `OpR`, `block.rs` the rows a register form reads and writes, and `rows` the arm each op runs under. Only the counts of a row op stay in `lower.rs` until its islands get columns.

The arms of the simple register forms come from the `fast` column. `run_regs` hands its own arms to `simple!`, which lays the generated ones between them, each calling the kernel of its stack op from `registers.rs`, and the slow path matches the same forms through `forms!`. A generated arm runs the instructions the arm written by hand ran.

## The hash

`OpCode::HASH` covers every column of every row in order, so any change to the table changes it, and `tests/tables.rs` computes it again apart from the macro. The identity a snapshot records hashes it with the hash of the runtime's own table, so a host refuses a blob another table saved before it parses the blob's source, as [Snapshots](./11-snapshots.mdx) lists. The fingerprint of the compiled program holds it too.

## How it is checked

`cargo test --locked -p edge --test tests tables::` runs the checks of `tests/tables.rs`, and these hold the table.

| Check | Holds |
|---|---|
| `every_opcode_is_listed_once_at_its_byte` | Each op of `ALL` sits at its byte with a name of its own |
| `every_op_of_the_table_sits_at_its_byte_with_its_columns` | Each op's class follows its part, each predicate follows its column and each register form falls back to the op whose form or branch it is |
| `the_hash_covers_every_column_in_order` | `HASH` is the hash of the columns as the check computes it |
| `a_runtime_declares_a_table_of_its_own_with_the_same_macro` | A table declared outside the engine gets its facts from the same macro |

`cargo test --locked -p edge --test tests ops::` runs the checks of `tests/ops.rs` over a runtime with an op of its own, which hold that the parser fuses its native, that constants fold, that the loop runs it over rows and registers, that its slow path takes what the fast path declines, that a rebound name runs its binding and that a blob of another table is refused.

## A runtime's own opcodes

A runtime declares opcodes of its own with the same macro, as a table with one part named `own`, and names it as `Language::Ops`. `tests/ops.rs` declares `Clamp`, which clamps a value between two bounds, for a runtime over mini's natives. [Opcodes](../01-get-started/04-book/06-opcodes.mdx) in the book covers why a runtime adds one, what it costs and what `Clamp` saved on a job over the GH Archive hour.

```rust file=tests/ops.rs
mod test {
    use edge::code::OpCode;
    use edge::embed::{Limits, VM};
    use edge::lang::{Args, Cx, Descriptor, EngineError, ErrKind, Front, Language, Misfit, Mode, Names, Native, Natives, Op, OpSet, OpTable, Policy, Ret, Runtime, Sig};
    use edge::lexer::{Spelling, Syntax};
    use edge::value::foreign::Kind;
    use edge::value::{HeapPool, Val, VmErr};
    use mini::Mini;
    use mini::natives::{ARRAY, ATTR, BUFFER, BYTES, CONVERT, DICT, FLOAT, FOLDS, GEN, INT, IO, ITER, LIST, LIST_SORT, NEXT, NUM, RANGE, SET, SET_MANY, SORT, STR, TUPLE, TYPES};

    // clamp of three ints answered in the loop and other numbers by its slow path
    edge::ops! {
        table Clamps: Debug;
        own {
        //  name   pops  fuse     fast        slow        fold
            Clamp  3     "clamp"  clamp_fast  clamp_slow  clamp_fold;
        }
    }

    /* three inline ints clamped or none for the slow path */
    fn ints(args: &[Val]) -> Option<Val> {
        let &[x, lo, hi] = args else { return None };
        (x.is_int() && lo.is_int() && hi.is_int() && lo.as_int() <= hi.as_int()).then(|| Val::int(x.as_int().clamp(lo.as_int(), hi.as_int())))
    }

    /* the loop's path which reads no heap */
    fn clamp_fast(_heap: &mut HeapPool, args: &[Val]) -> Option<Val> { ints(args) }

    /* constant ints clamped as the program compiles */
    fn clamp_fold(args: &[Val]) -> Option<Val> { ints(args) }

    // how often this thread ran the slow path which the fast path should spare
    std::thread_local! { static SLOW: core::cell::Cell<usize> = const { core::cell::Cell::new(0) }; }

    /* any ints or floats clamped and other kinds refused through the runtime's rules */
    fn clamp_slow(cx: &mut Cx<'_, '_>, args: &[Val]) -> Result<Val, VmErr> {
        SLOW.with(|n| n.set(n.get() + 1));
        let &[x, lo, hi] = args else { return Err(VmErr::Runtime("clamp takes three operands")) };
        let bounds = || VmErr::Of(ErrKind::Value, String::from("clamp's low bound lies past its high bound"));
        if let (Some(a), Some(l), Some(h)) = (cx.int(x), cx.int(lo), cx.int(hi)) {
            if l > h { return Err(bounds()); }
            return cx.new_int(a.clamp(l, h));
        }
        let all = [x, lo, hi];
        if let Some(k) = all.iter().position(|&v| cx.float(v).is_none()) { return Err(EngineError::Unsupported { op: Op::Runtime(Clamps::Clamp as u8), a: all[k], b: Some(all[usize::from(k == 0)]) }.into()); }
        let num = |v: Val| cx.float(v).unwrap_or(Ok(f64::NAN));
        let (a, l, h) = (num(x)?, num(lo)?, num(hi)?);
        // a bound that is no number orders past nothing
        if l.is_nan() || h.is_nan() || l > h { return Err(bounds()); }
        Ok(Val::float(a.clamp(l, h)))
    }

    /* the native whose plain calls of three arguments run the op */
    fn clamp_native(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret { clamp_slow(cx, a.pos).map(Into::into) }

    const CLAMP: &[Native] = &[Native::new("clamp", Sig::exact(3), clamp_native)];

    // mini's natives with the clamp the op fuses
    static NATIVES: Natives = edge::natives! {
        language: Clamped,
        fns: [IO, ITER, NEXT, NUM, FOLDS, CONVERT, BYTES, SORT, ATTR, TYPES, CLAMP],
        methods: [
            Str => [STR],
            Bytes => [BUFFER],
            ByteArray => [ARRAY],
            List => [LIST, LIST_SORT],
            Tuple => [TUPLE],
            Dict => [DICT],
            Set => [SET, SET_MANY],
            Int => [INT],
            Float => [FLOAT],
            Range => [RANGE],
            Coro => [GEN],
        ],
        types: mini::types::NAMES,
    };

    static RUNTIME: Runtime = Runtime::of::<Clamped>();

    // mini with an opcode of its own
    struct Clamped;

    impl Spelling for Clamped {
        const SYNTAX: Syntax = mini::MINI;
        const NATIVES: &'static Natives = &NATIVES;
        const OPS: &'static OpSet = <Clamps as OpTable>::SET;
    }

    impl Language for Clamped {
        const VERSION: u32 = 1;
        const POLICY: Policy = Mini::POLICY;
        const NATIVES: &'static Natives = &NATIVES;
        const NAMES: &'static Names = &mini::NAMES;
        const FRONT: Front = Front::spelled::<Clamped>();
        const DESCRIPTOR: &'static Descriptor = &mini::DESCRIPTOR;
        const WIDE: Option<&'static Kind> = <Mini as Language>::WIDE;
        const BUILT: edge::value::foreign::Built = <mini::Mini as Language>::BUILT;
        type Ops = Clamps;

        fn show(cx: &mut Cx<'_, '_>, v: Val, mode: Mode) -> Result<String, VmErr> { <Mini as Language>::show(cx, v, mode) }

        fn format(cx: &mut Cx<'_, '_>, v: Val, spec: &str) -> Result<String, VmErr> { <Mini as Language>::format(cx, v, spec) }

        fn handles(heap: &HeapPool, exc: Val, class: Val) -> Result<bool, VmErr> { <Mini as Language>::handles(heap, exc, class) }

        fn misfit(n: &Native, owner: Option<&str>, m: Misfit<'_>) -> VmErr { <Mini as Language>::misfit(n, owner, m) }

        fn message(cx: &mut Cx<'_, '_>, e: &EngineError) -> String { <Mini as Language>::message(cx, e) }
    }

    /* what `src` prints under the runtime or the error that ends it */
    fn ran(src: &str) -> String {
        let (chunk, errors) = edge::code::compile_as::<Clamped>(src);
        assert!(errors.is_empty(), "{src:?} reports {:?}", errors.iter().map(|d| &d.msg).collect::<Vec<_>>());
        let mut vm = VM::with_runtime(&RUNTIME, &chunk, Limits::sandbox());
        match vm.run() {
            Ok(_) => vm.output_text().trim_end().to_string(),
            Err(e) => vm.error_text(&e),
        }
    }

    /* the ops `src` compiles to in its module body */
    fn ops_of(src: &str) -> Vec<(OpCode, u16)> {
        let (chunk, errors) = edge::code::compile_as::<Clamped>(src);
        assert!(errors.is_empty());
        chunk.instructions.iter().map(|i| (i.opcode, i.operand)).collect()
    }

    #[test]
    fn a_runtime_declares_its_ops_and_the_engine_reads_the_table() {
        assert_eq!(Clamps::ALL, [Clamps::Clamp]);
        assert_eq!((<Clamps as OpTable>::COUNT, Clamps::Clamp.operand()), (1, 3 << 8));
        assert_eq!(RUNTIME.ops.ops[0].fuse, Some("clamp"));
        assert_ne!(<Clamps as OpTable>::HASH, 0);
        // a table of no ops is empty and the identity tells the runtimes apart
        assert_ne!(RUNTIME.identity, mini::RUNTIME.identity);
        assert_eq!(<() as OpTable>::SET.ops.len(), 0);
    }

    #[test]
    fn a_plain_call_of_the_fused_native_compiles_to_the_op() {
        let ops = ops_of("x = 5\ny = clamp(x, 0, 3)\n");
        assert!(ops.contains(&(OpCode::RuntimeOp, Clamps::Clamp.operand())), "{ops:?}");
        // another count of arguments or a keyword calls the native
        for src in ["x = 5\ny = clamp(x, 0)\n", "x = 5\ny = clamp(x, 0, hi=3)\n"] {
            assert!(!ops_of(src).iter().any(|o| o.0 == OpCode::RuntimeOp), "{src:?}");
        }
        // a name the program binds is its own function and no op
        assert!(!ops_of("fn clamp(a, b, c):\n    return a\ny = clamp(1, 2, 3)\n").iter().any(|o| o.0 == OpCode::RuntimeOp));
    }

    #[test]
    fn constant_operands_fold_as_the_table_says() {
        let ops = ops_of("y = clamp(9, 0, 3)\n");
        assert!(!ops.iter().any(|o| o.0 == OpCode::RuntimeOp), "{ops:?}");
        assert_eq!(ran("print(clamp(9, 0, 3), clamp(-4, 0, 3), clamp(1, 0, 3))\n"), "3 0 1");
        // what the rule refuses stays the op and runs
        assert!(ops_of("y = clamp(9, 3, 0)\n").iter().any(|o| o.0 == OpCode::RuntimeOp));
        assert_eq!(ran("y = clamp(9, 3, 0)\n"), "ValueError: clamp's low bound lies past its high bound");
    }

    #[test]
    fn the_loop_runs_the_op_over_rows_and_lowered_registers() {
        assert_eq!(ran("x = 5\nprint(clamp(x, 0, 3), clamp(x - 9, 0, 3), clamp(x, 0, 9))\n"), "3 0 5");
        // a hot loop and a function body lower the op to its register form
        let src = "fn f(n):\n    t = 0\n    for i in range(n):\n        t = t + clamp(i, 10, 20)\n    return t\nprint(f(300), f(300))\nt = 0\nfor i in range(300):\n    t = t + clamp(i, 10, 20)\nprint(t)\n";
        assert_eq!(ran(src), "5845 5845\n5845");
    }

    #[test]
    fn the_slow_path_takes_what_the_fast_path_declines() {
        assert_eq!(ran("x = 2.5\nprint(clamp(x, 0, 1), clamp(x, 0.5, 9), clamp(true, 0, 9))\n"), "1.0 2.5 1");
        let wide = "x = 10 ** 30\nprint(clamp(x, 0, 7), clamp(-x, 0, 7))\n";
        assert_eq!(ran(wide), "7 0");
        assert_eq!(ran("x = 'a'\nclamp(x, 0, 1)\n"), "TypeError: unsupported operand type(s) for clamp: 'str' and 'int'");
        assert_eq!(ran("fn f(x):\n    return clamp(x, 0, 1)\nprint(f(3), f(2.5))\n"), "1 1.0");
        assert_eq!(ran("fn f(x):\n    return clamp(x, 0, 1)\nfor v in [3, 2.5, 'b']:\n    f(v)\n"), "TypeError: unsupported operand type(s) for clamp: 'str' and 'int'");
        // an unbound operand raises as its read would
        assert!(ran("fn f():\n    clamp(y, 0, 1)\n    y = 1\nf()\n").starts_with("UnboundLocalError"));
    }

    #[test]
    fn a_rebound_name_runs_its_binding() {
        let src = "fn swap():\n    global clamp\n    clamp = lambda a, b, c: a + b + c\nx = 5\nprint(clamp(x, 0, 3))\nswap()\nprint(clamp(x, 0, 3))\n";
        assert_eq!(ran(src), "3\n8");
        let hot = "fn f(n):\n    t = 0\n    for i in range(n):\n        t = t + clamp(i, 0, 1)\n    return t\nprint(f(100))\nfn g(a, b, c):\n    return 2\nfn swap():\n    global clamp\n    clamp = g\nswap()\nprint(f(100))\n";
        assert_eq!(ran(hot), "99\n200");
    }

    #[test]
    fn another_rebound_name_leaves_the_op_on_its_fast_path() {
        let src = "fn sum(xs):\n    return 0\nfn f(n):\n    t = 0\n    for i in range(n):\n        t = t + clamp(i, 10, 20)\n    return t\nprint(f(300), f(300))\nt = 0\nfor i in range(300):\n    t = t + clamp(i, 10, 20)\nprint(t, sum([1]))\n";
        let before = SLOW.with(|n| n.get());
        assert_eq!(ran(src), "5845 5845\n5845 0");
        // every operand was an int in order so no op left its fast path
        assert_eq!(SLOW.with(|n| n.get()), before);
    }

    #[test]
    fn a_module_binding_of_the_fused_name_is_called_as_a_function() {
        let own = "fn clamp(x, lo, hi):\n    return x + lo + hi\nfn f(n):\n    t = 0\n    for i in range(n):\n        t = t + clamp(i, 1, 2)\n    return t\nprint(f(100), f(100))\n";
        assert_eq!(ran(own), "5250 5250");
        // a new binding is called and once deleted the op's own rule answers again
        let swapped = "fn clamp(x, lo, hi):\n    return 1\nfn f(n):\n    t = 0\n    for i in range(n):\n        t = t + clamp(i, 0, 5)\n    return t\nprint(f(100))\nfn swap():\n    global clamp\n    clamp = lambda x, lo, hi: 2\nswap()\nprint(f(100))\ndel clamp\nprint(f(100))\n";
        assert_eq!(ran(swapped), "100\n200\n485");
        // its own function raising inside the loop raises as that function
        let raised = "fn clamp(x, lo, hi):\n    if x == 70:\n        raise ValueError('mine')\n    return x\nfn f(n):\n    t = 0\n    for i in range(n):\n        t = t + clamp(i, 0, 5)\n    return t\nf(100)\n";
        assert_eq!(ran(raised), "ValueError: mine");
    }

    #[test]
    fn a_helper_holding_the_op_runs_it_in_hot_loops() {
        let plain = "fn bar(x):\n    return clamp(x, 10, 20)\nfn f(n):\n    t = 0\n    for i in range(n):\n        t = t + bar(i)\n    return t\nprint(f(300), f(300))\n";
        assert_eq!(ran(plain), "5845 5845");
        // operands its fast path declines take the slow path from inside the helper
        let slow = "fn bar(x):\n    return clamp(x, 0, 7)\nt = 0\nfor k in range(100):\n    t = t + bar(10 ** 30) + bar(2.5) + bar(true)\nprint(t)\n";
        assert_eq!(ran(slow), "1050.0");
        let wrong = "fn bar(x):\n    return clamp(x, 0, 1)\nt = 0\nfor v in [3, 2.5, -1] * 30 + ['b']:\n    t = t + bar(v)\n";
        assert_eq!(ran(wrong), "TypeError: unsupported operand type(s) for clamp: 'str' and 'int'");
        let bounds = "fn bar(x, lo):\n    return clamp(x, lo, 4)\nt = 0\nfor i in range(100):\n    t = t + bar(i, i ~/ 50 * 9)\n";
        assert_eq!(ran(bounds), "ValueError: clamp's low bound lies past its high bound");
        // a recursion and a generator holding the op keep their values across their levels
        let walk = "fn walk(n):\n    if n == 0:\n        return 0\n    return clamp(n, 0, 5) + walk(n - 1)\nt = 0\nfor k in range(100):\n    t = t + walk(10)\nprint(t)\n";
        assert_eq!(ran(walk), "4000");
        let stepped = "fn clamped(xs):\n    for x in xs:\n        yield clamp(x, 0, 9)\nt = 0\nfor k in range(50):\n    for v in clamped([-3, 4, 12]):\n        t = t + v\nprint(t)\n";
        assert_eq!(ran(stepped), "650");
```

A row of `own` names the op and five columns, and a dash leaves a column out.

| Column | Says |
|---|---|
| `pops` | The values the op takes off the stack, where it leaves one |
| `fuse` | The native whose plain calls of that many positionals the parser emits as the op |
| `fast` | `fn(&mut HeapPool, &[Val]) -> Option<Val>`, what the loop answers in place, and `None` for its slow path |
| `slow` | `fn(&mut Cx, &[Val]) -> Result<Val, VmErr>`, what the op gives once `fast` declines, which no row leaves out |
| `fold` | `fn(&[Val]) -> Option<Val>`, the constant the op folds constant operands to as the program compiles |

The macro writes the enum of the ops at their bytes, their `ALL` and `OPS`, `operand` for the operand that runs each, and an `OpTable` whose `COUNT`, `HASH`, `fast` and `SET` the engine reads. `SET` is the table erased for the code outside the loop, and a runtime that reads its sources through a token table names it as `Spelling::OPS` too, so its parser fuses and folds the ops.

| Piece | What the engine does with it |
|---|---|
| Fuse | A call of the native the row names, with the row's count of positionals and no keyword or spread, compiles to `RuntimeOp`. A name the program binds stays its own call, and a call of another shape stays the native's |
| Fold | A call whose operands are each one constant folds to the constant `fold` gives, and the op stays where `fold` gives none or the program binds its name |
| Fast | The loop runs `RuntimeOp` over rows and the lowering writes `RuntimeR` over a row of registers, and each arm calls `fast` in place. A runtime with no ops of its own builds a loop with neither arm, so the engine's loop is the loop it ran before |
| Slow | Once `fast` declines, the op reads its operands, raising for an unbound one, and runs `slow`. An unsupported operand error `slow` raises for `Op::Runtime(n)` asks the runtime's `bind_op` as an operator does, and its words name the op by its native |
| Rebinding | Where the program binds the name of the fused native, the op calls that binding as a call of it would. The ops of the other natives keep their fast paths |
| Format | The identity a blob records hashes the table, so a host refuses a blob of another table before it parses its source |

A runtime with a front end of its own emits the op through `Builder::op`.

Clamp was measured on 26 October 2026 in wasm instructions, in a runtime of mini's natives with the op and again without it, where the same call compiles to the native. Each figure is what 100,000 more calls of `x = clamp(i, 10, 20)` in a function's loop add, less the loop's own 258 an iteration, which is the same in both builds.

| `clamp(i, 10, 20)` as | Instructions a call |
|---|---:|
| `RuntimeR` with its three operands moved into a row | 187 |
| A function of the program with the same rule | 239 |
| The native through `CallNativeR` | 799 |

A call of constants folds to its value as the program compiles, so it costs nothing at run time, unless the program binds the op's name somewhere and every call of it runs that binding. The second loop a runtime with ops builds makes its wasm about 107 KB larger before wasm-opt, 109,597 bytes for this one.
