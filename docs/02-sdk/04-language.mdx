# Language

`edge::lang::Language` is everything a runtime hands the engine past its natives, as one type. The book's [Rules](../01-get-started/04-book/04-rules.mdx) and [Errors](../01-get-started/04-book/05-errors.mdx) cover why the engine asks for each part and how mini, tiny and uptime choose. This page is the reference of the trait and the types it names, with what the engine reads of each today.

A runtime writes little of it. Uptime's implementation is the 44 lines of `examples/uptime/src/language.rs`, its policy, the tables and names it hands the engine, and three functions that pass lib's answers on. Every part it leaves out keeps the default the table below lists.

```rust file=examples/uptime/src/language.rs
use alloc::string::String;

use edge::lang::{Cx, Descriptor, Falsy, Front, IntDiv, IntMod, Language, MapIter, Mode, Names, Natives, NegPow, NumEq, Overflow, Policy, StrIter, ZeroDiv};
use edge::value::foreign::Kind;
use edge::value::{HeapPool, Val, VmErr};

use crate::Uptime;

impl Language for Uptime {
    const VERSION: u32 = 1;
    // the engine's own rules but for map fields and the digit limit
    const POLICY: Policy = Policy {
        int_overflow: Overflow::Promote,
        int_div: IntDiv::ToFloat,
        int_mod: IntMod::Truncated,
        zero_div: ZeroDiv::Error,
        neg_pow: NegPow::ToFloat,
        numeric_eq: NumEq::Unified,
        bool_is_int: true,
        falsy: Falsy::NIL.or(Falsy::FALSE).or(Falsy::ZERO).or(Falsy::NAN).or(Falsy::EMPTY_TEXT),
        identity_first: true,
        neg_index: true,
        str_iter: StrIter::CodePoints,
        map_iter: MapIter::Keys,
        // an answer's fields read as `status.indicator`
        map_fields: true,
        builtins_scope: true,
        receiver_slot: true,
        recursion_limit: 1000,
        max_int_digits: Some(10_000),
    };
    const NATIVES: &'static Natives = &crate::NATIVES;
    const NAMES: &'static Names = &crate::NAMES;
    const FRONT: Front = crate::FRONT;
    const DESCRIPTOR: &'static Descriptor = &crate::DESCRIPTOR;
    const WIDE: Option<&'static Kind> = Some(&crate::natives::WIDE);
    type Ops = ();

    fn show(cx: &mut Cx<'_, '_>, v: Val, mode: Mode) -> Result<String, VmErr> { lib::fmt::render::hook::<Uptime>(cx, v, mode) }

    fn format(cx: &mut Cx<'_, '_>, v: Val, spec: &str) -> Result<String, VmErr> { lib::fmt::spec::hook::<Uptime>(cx, v, spec) }

    fn handles(heap: &HeapPool, exc: Val, class: Val) -> Result<bool, VmErr> { lib::types::match_exc::<Uptime>(heap, exc, class) }
}
```

## The trait

```rust file=src/lang/language.rs
use alloc::{string::String, vec, vec::Vec};

use crate::abi::ErrorKind;
use crate::syntax::chunk::SSAChunk;
use crate::value::foreign::Kind;
use crate::value::{HeapPool, Val, VmErr, cold_runtime};
use crate::vm::VM;
use super::{Access, ArityFn, CallRule, CallShape, Cx, Descriptor, EngineError, FormatFn, Front, GetRule, Key, MatchFn, Misfit, Mode, Name, Names, Native, Natives, Op, OpRule, OpSet, OpTable, Overflow, Policy, RenderFn, WordsFn};

/* everything a runtime gives the engine as one type the loop is generic over */
pub trait Language: Sized + 'static {
    // the identity a snapshot records and a restore checks
    const NAME: &'static str = Self::DESCRIPTOR.language;
    const VERSION: u32;
    // the rules the loop folds as constants
    const POLICY: Policy;
    // the static tables `natives!` builds with no work at boot
    const NATIVES: &'static Natives;
    // what the runtime calls the engine's kinds errors and conventions
    const NAMES: &'static Names;
    // how sources become chunks through a token table or a front end of its own
    const FRONT: Front;
    // how the tools around the engine name the runtime's files and errors
    const DESCRIPTOR: &'static Descriptor;
    // the kind that boxes an int past the inline range
    const WIDE: Option<&'static Kind> = None;
    // the kinds natives box on first use which a restore names before any value
    const KINDS: &'static [&'static Kind] = &[];
    // the kinds of the slices and the ellipsis the engine builds itself
    const BUILT: crate::value::foreign::Built = crate::value::foreign::Built::NONE;
    // how every host shows an uncaught error where none keeps the engine's report
    const REPORT: Option<WordsFn> = None;
    // the runtime's own opcodes or the unit type for none
    type Ops: OpTable;

    /* the rule for `recv.name` the engine asks where its own lookup misses */
    fn bind_get(_cx: &mut Cx<'_, '_>, _recv: Key, _name: Name, _how: Access) -> GetRule { GetRule::Ask }

    /* the rule for calling `callee` the engine asks where it cannot call it */
    fn bind_call(_cx: &mut Cx<'_, '_>, _callee: Val, _shape: CallShape) -> CallRule { CallRule::Ask }

    /* the rule for `op` the engine asks where its kernels refuse both keys */
    fn bind_op(_cx: &mut Cx<'_, '_>, _op: Op, _a: Key, _b: Key) -> OpRule { OpRule::Kernel }

    /* `v` as text in `mode` wherever the engine shows a value */
    fn show(_cx: &mut Cx<'_, '_>, _v: Val, _mode: Mode) -> Result<String, VmErr> { Err(VmErr::Runtime("this runtime renders no values")) }

    /* `v` under format spec `spec` where a runtime with no specs writes only plain fields */
    fn format(cx: &mut Cx<'_, '_>, v: Val, spec: &str) -> Result<String, VmErr> {
        if spec.is_empty() { cx.render(v, Mode::Str) } else { Err(VmErr::Runtime("this runtime formats no values")) }
    }

    /* whether exception `exc` is of the class or tuple of classes a handler names */
    fn handles(_heap: &HeapPool, _exc: Val, _class: Val) -> Result<bool, VmErr> { Err(cold_runtime("the runtime gives no exception matcher")) }

    /* the error of a call missing native `n` until misfits reach `message` */
    fn misfit(n: &Native, owner: Option<&str>, m: Misfit<'_>) -> VmErr { super::sig::plain(n, owner, m) }

    /* the message of `e` in the runtime's words with its class from `NAMES` */
    fn message(cx: &mut Cx<'_, '_>, e: &EngineError) -> String { super::plain(cx, e) }

    /* the value a handler binds for `e` which a reraise throws again */
    fn raise(cx: &mut Cx<'_, '_>, e: EngineError) -> Result<Val, VmErr> { raised::<Self>(cx, e) }

    /* the name of the type of `v` wherever the engine names one and `cx.type_name` asks */
    fn type_name<'h>(cx: &'h Cx<'_, '_>, v: Val) -> &'h str { cx.plain_type(v) }

    /* the error kind a plugin sees for exception `exc` */
    fn error_kind(cx: &Cx<'_, '_>, exc: Val) -> ErrorKind { error_kind_of(cx.heap(), Self::NAMES, exc) }
}

/* the engine's exception object for `e` of the class `L` names holding `L`'s words */
pub fn raised<L: Language>(cx: &mut Cx<'_, '_>, e: EngineError) -> Result<Val, VmErr> {
    let Some(kind) = e.kind() else {
        return match e { EngineError::Raised(v) => Ok(v), _ => Err(cold_runtime("a signal reached the language")) };
    };
    let args: Vec<Val> = match e {
        // the key a map lacked rides whole as the one argument
        EngineError::MissingKey(k) => vec![k],
        // these carry their value as the one argument when they have one
        EngineError::Exit(v) | EngineError::Stop(v) | EngineError::Assert(v) => if v.is_undef() || v.is_none() { Vec::new() } else { vec![v] },
        // words a native or the runtime already wrote ride as they are
        EngineError::Of(_, text) => if text.is_empty() { Vec::new() } else { vec![cx.new_str(text)?] },
        _ => match L::message(cx, &e) { text if text.is_empty() => Vec::new(), text => vec![cx.new_str(text)?] },
    };
    cx.heap_mut().engine_error(kind, args)
}

/* the abi kind of an exception by the engine error kind its class names */
fn error_kind_of(heap: &HeapPool, names: &Names, exc: Val) -> ErrorKind {
    let class = heap.instance_type(exc).unwrap_or("");
    super::error::abi_of(names.error_named(class))
}

// the loop of one language the vm enters once per nested run
pub(crate) type DriveFn = for<'v, 'm, 'c> fn(&'m mut VM<'v>, &'c SSAChunk, usize) -> Result<Val, VmErr>;
pub type MessageFn = fn(&mut Cx<'_, '_>, &EngineError) -> String;
pub type RaiseFn = fn(&mut Cx<'_, '_>, EngineError) -> Result<Val, VmErr>;
pub type TypeNameFn = for<'h> fn(&'h Cx<'_, '_>, Val) -> &'h str;
pub type ErrorKindFn = fn(&Cx<'_, '_>, Val) -> ErrorKind;
pub type BindGetFn = fn(&mut Cx<'_, '_>, Key, Name, Access) -> GetRule;
pub type BindCallFn = fn(&mut Cx<'_, '_>, Val, CallShape) -> CallRule;
pub type BindOpFn = fn(&mut Cx<'_, '_>, Op, Key, Key) -> OpRule;

/* one language erased to the tables and calls the engine reads outside the loop */
pub struct Runtime {
    pub natives: &'static Natives,
    pub descriptor: &'static Descriptor,
    // the front end code compiled while a program runs goes through where none compiles nothing
    pub front: Option<Front>,
    pub wide: Option<&'static Kind>,
    pub kinds: &'static [&'static Kind],
    pub report: Option<WordsFn>,
    pub name: &'static str,
    pub version: u32,
    // each operator as its front end's table spells it which its words name
    pub spellings: [&'static str; super::SPELLED],
    // what a blob it saves records of its name version natives opcodes and rules
    pub identity: u64,
    // its own opcodes as the slow paths and the words read them
    pub ops: &'static OpSet,
    // whether it runs the engine's own loop which a nested run enters directly
    pub(crate) engine_loop: bool,
    pub(crate) drive: DriveFn,
    pub show: RenderFn,
    pub format: FormatFn,
    pub handles: MatchFn,
    pub misfit: ArityFn,
    pub message: MessageFn,
    pub raise: RaiseFn,
    pub type_name: TypeNameFn,
    pub error_kind: ErrorKindFn,
    pub bind_get: BindGetFn,
    pub bind_call: BindCallFn,
    pub bind_op: BindOpFn,
}

/* whether `s` spells the token of the ellipsis as a symbol or a word */
const fn spells_ellipsis(s: &crate::syntax::lexer::Syntax) -> bool {
    let (mut k, mut w) = (0, 0);
    while k < s.symbols.len() { if matches!(s.symbols[k].1, crate::syntax::lexer::TokenType::Ellipsis) { return true; } k += 1; }
    while w < s.words.len() { if matches!(s.words[w].1, crate::syntax::lexer::TokenType::Ellipsis) { return true; } w += 1; }
    false
}

impl Runtime {
    /* the runtime of `L` with every rule it states checked as the build evaluates it */
    pub const fn of<L: Language>() -> Runtime {
        // an int past the inline range goes to the wide kind so it decides overflow
        assert!(matches!(L::POLICY.int_overflow, Overflow::Promote) == L::WIDE.is_some(), "a policy promotes ints exactly when its language names a wide kind");
        L::POLICY.refuse_unread();
        // the slow paths and folder read the natives' rules and the loop the language's
        assert!(L::NATIVES.policy.same(&L::POLICY) && L::FRONT.policy.same(&L::POLICY), "a language builds its natives and folds its constants under the rules it states");
        assert!(<L::Ops as OpTable>::SET.ops.len() == <L::Ops as OpTable>::COUNT as usize && <L::Ops as OpTable>::SET.hash == <L::Ops as OpTable>::HASH, "a runtime's own opcodes are the table its type names");
        // the value a spelled ellipsis makes takes the kind the language names for it
        assert!(L::BUILT.ellipsis.is_some() || !matches!(L::FRONT.syntax, Some(s) if spells_ellipsis(&s)), "a language whose syntax spells the ellipsis names its kind in BUILT");
        // a language keeping the engine's loop rules runs the one loop the engine builds
        let engine_loop = L::POLICY.loops_as(&Policy::ENGINE) && L::Ops::COUNT == 0;
        Runtime {
            natives: L::NATIVES,
            descriptor: L::DESCRIPTOR,
            front: Some(L::FRONT),
            wide: L::WIDE,
            kinds: L::KINDS,
            report: L::REPORT,
            name: L::NAME,
            version: L::VERSION,
            spellings: match L::FRONT.syntax { Some(s) => super::spellings(&s), None => [""; super::SPELLED] },
            identity: identity::<L>(),
            ops: <L::Ops as OpTable>::SET,
            engine_loop,
            drive: if engine_loop { crate::vm::engine_drive } else { crate::vm::driven::<L> },
            show: L::show,
            format: L::format,
            handles: L::handles,
            misfit: L::misfit,
            message: L::message,
            raise: L::raise,
            type_name: L::type_name,
            error_kind: L::error_kind,
            bind_get: L::bind_get,
            bind_call: L::bind_call,
            bind_op: L::bind_op,
        }
    }

    /* a machine with no runtime which names nothing and compiles nothing while it runs */
    pub const EMPTY: Runtime = Runtime { front: None, ..Runtime::of::<Bare>() };

    /* the rules this runtime states */
    #[inline(always)]
    pub fn policy(&self) -> &'static Policy { &self.natives.policy }

    /* what this runtime calls the engine's kinds errors and conventions */
    #[inline(always)]
    pub fn names(&self) -> &'static Names { self.natives.names() }
}

/* the identity of `L` from its name version natives digest both opcode tables and rules */
const fn identity<L: Language>() -> u64 {
    use crate::code::ops::{FNV, fnv};
    let mut h = fnv(FNV, L::NAME.as_bytes());
    h = fnv(h, &[0xFF]);
    h = fnv(h, &L::VERSION.to_le_bytes());
    h = fnv(h, &L::NATIVES.digest.to_le_bytes());
    h = fnv(h, &[<L::Ops as OpTable>::COUNT]);
    h = fnv(h, &<L::Ops as OpTable>::HASH.to_le_bytes());
    // the engine's table too so a host refuses a blob of other opcodes before parsing
    h = fnv(h, &crate::code::OpCode::HASH.to_le_bytes());
    fnv(h, &L::POLICY.bytes())
}

/* the language of a machine booted with no runtime whose loop every engine policy shares */
pub(crate) struct Bare;

// no natives built under the rules the bare machine states
static BARE_NATIVES: Natives = Natives::EMPTY.under(<Bare as Language>::POLICY);

impl Language for Bare {
    const VERSION: u32 = 0;
    // no wide kind so an int past the inline range raises
    const POLICY: Policy = Policy { int_overflow: Overflow::Error, ..Policy::ENGINE };
    const NATIVES: &'static Natives = &BARE_NATIVES;
    const NAMES: &'static Names = &Names::PLAIN;
    const FRONT: Front = Front { policy: &<Bare as Language>::POLICY, ..Front::NONE };
    const DESCRIPTOR: &'static Descriptor = &Descriptor::NONE;
    type Ops = ();
}
```

| Item | Holds | Default | The engine reads it today |
|---|---|---|---|
| `NAME`, `VERSION` | The identity of the language | The descriptor's `language` for `NAME`, and none for `VERSION` | Yes, in the identity a snapshot records and a restore checks |
| `POLICY` | The rules programs run on | None | Yes, as constants the loop folds, as [Policy](#policy) lists |
| `NATIVES` | The tables `edge::natives!` builds | None | Yes |
| `NAMES` | The words for the engine's kinds, errors and conventions | None | Yes, through the tables `natives!` builds for the language |
| `FRONT` | How sources become chunks | None | Yes, for the code a program compiles while it runs |
| `DESCRIPTOR` | How the tools around the engine name the runtime's files and errors | None | Yes, by every host |
| `WIDE` | The kind an int past the inline range boxes in | `None` | Yes |
| `KINDS` | The kinds natives box on first use, which a restore names before any value | `&[]` | Yes |
| `BUILT` | The kinds of the slices and the ellipsis the engine builds itself | `Built::NONE` | Yes, for the slice a kept key makes and for the ellipsis |
| `REPORT` | How every host shows an error no handler caught | `None`, the engine's report | Yes |
| `Ops` | The runtime's own opcodes | None, and mini, tiny and uptime write `()` | Yes, as the loop runs them, the parser fuses and folds them and the identity a snapshot records hashes their table, as [Opcodes](./08-opcodes.mdx#a-runtimes-own-opcodes) explains |
| `bind_get`, `bind_call` | The rule for `recv.name` and for a call | `GetRule::Ask`, `CallRule::Ask` | Yes, where the engine's own lookup misses and where it cannot call a value |
| `bind_op` | The rule for an operator | `OpRule::Kernel` | Yes, where the kernels refuse the operands |
| `show` | A value as text in a `Mode` | Refuses, since the runtime renders no values | Yes |
| `format` | A value under a format spec | Plain fields only | Yes |
| `handles` | Whether an exception is of the class or classes a handler names | Refuses, since the runtime gives no matcher | Yes |
| `misfit` | The error of a call that misses a native's signature | The engine's words | Yes |
| `message` | The words of an `EngineError` | `edge::lang::plain` | Yes, where a handler catches an engine error and where one leaves the machine |
| `raise` | The value a handler binds for an `EngineError` | `edge::lang::raised::<Self>` | Yes, where a handler catches an error of the engine |
| `type_name` | The name of the type of a value for errors and hints | `cx.plain_type`, the name `NAMES` gives | Yes, wherever the engine or lib names a type through `cx.type_name` |
| `error_kind` | The ABI error kind a plugin sees for an exception | The kind its class names in `NAMES` | Yes, where a plugin reads the error of what the program raised |

The engine reads every part. `Runtime::of::<L>()` erases `L` into the `Runtime` its exports and every host boot, as `pub static RUNTIME: Runtime = Runtime::of::<Mini>();` does in `examples/mini/src/lib.rs`, and `edge::web_exports!(RUNTIME)` builds the wasm exports over it. `natives!` names the language as `language: Mini` and takes its names and its policy from it. The loop is generic over `L`, so it folds `L::POLICY` as constants. A language that keeps the rules the engine's own loop is built with shares that one loop, and any other runs a loop of its own. `Runtime::of` runs inside a static, so its checks fail the build with the broken rule as the message. A policy promotes ints exactly when its language names a `WIDE` kind, it reads nil and false as false, each field the loop does not read yet states the engine's own value, and a syntax that spells the ellipsis comes with the kind `BUILT` names for it.

## Policy

```rust file=src/lang/policy.rs
use crate::value::Val;

/* the rules a runtime picks which the loop reads as constants of its language */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Policy {
    // what an int result past the inline range becomes
    pub int_overflow: Overflow,
    // what `/` gives for two ints
    pub int_div: IntDiv,
    // how `//` rounds and whose sign `%` takes for ints and floats alike
    pub int_mod: IntMod,
    // what a float divided by zero gives since an int divided by zero always raises
    pub zero_div: ZeroDiv,
    // what an int raised to a negative int gives
    pub neg_pow: NegPow,
    // whether equal numbers of different kinds are one value and one key
    pub numeric_eq: NumEq,
    // whether a bool counts as the int zero or one in arithmetic indexes and keys
    pub bool_is_int: bool,
    // the values a test reads as false
    pub falsy: Falsy,
    // whether a container finds an item by identity before it compares
    pub identity_first: bool,
    // whether a negative index or slice bound counts from the end
    pub neg_index: bool,
    // what a loop over a text steps through
    pub str_iter: StrIter,
    // what a loop over a map steps through
    pub map_iter: MapIter,
    // whether an attribute a map lacks reads its key of that name
    pub map_fields: bool,
    // whether a name no module binds reads the runtime's builtins
    pub builtins_scope: bool,
    // whether a method takes its receiver as its first parameter
    pub receiver_slot: bool,
    // how deep calls nest before the recursion error
    pub recursion_limit: u32,
    // the decimal digits an int literal or text may hold where none sets no limit
    pub max_int_digits: Option<u32>,
}

/* what an int result past the inline range becomes */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Overflow {
    // the runtime's wide kind boxes it so ints grow without bound
    Promote,
    // the overflow error kind raises
    Error,
}

/* what `/` gives for two ints */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum IntDiv { ToFloat, Floor, Trunc }

/* how `//` rounds and whose sign `%` takes */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum IntMod {
    // toward negative infinity so the remainder takes the divisor's sign
    Floored,
    // toward zero so the remainder takes the dividend's sign
    Truncated,
}

/* what a float divided by zero gives */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum ZeroDiv {
    // the division by zero error kind raises
    Error,
    // an infinity or a NaN as the float standard gives
    Ieee,
}

/* what an int raised to a negative int gives */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum NegPow { ToFloat, Error }

/* whether equal numbers of different kinds are one value */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum NumEq {
    // an int and a float of one value are equal with one hash
    Unified,
    // values of different kinds never compare equal
    ByKind,
}

/* what a loop over a text steps through */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum StrIter { CodePoints, Bytes }

    Keys,

    Pairs,

/* the values a test reads as false which the loop tests with one mask */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub struct Falsy(u8);

impl Falsy {
    pub const NIL: Falsy = Falsy(1);
    pub const FALSE: Falsy = Falsy(2);
    // the int zero and either float zero
    pub const ZERO: Falsy = Falsy(4);
    pub const EMPTY_TEXT: Falsy = Falsy(8);
    pub const NAN: Falsy = Falsy(16);
    // an empty bytes buffer list tuple map set or range
    pub const EMPTY_CONTAINER: Falsy = Falsy(32);
    // an empty text and an empty container alike
    pub const EMPTY: Falsy = Falsy::EMPTY_TEXT.or(Falsy::EMPTY_CONTAINER);

    /* both sets of values */
    pub const fn or(self, other: Falsy) -> Falsy { Falsy(self.0 | other.0) }

    /* whether every value of `other` reads as false */
    pub const fn has(self, other: Falsy) -> bool { self.0 & other.0 == other.0 }

    /* the mask the loop tests */
    pub const fn bits(self) -> u8 { self.0 }

    /* the truth of a bool which every mask reads as itself */
    #[inline(always)]
    pub const fn bool_truth(self, b: bool) -> bool { b }

    /* the truth of an int under this mask */
    #[inline(always)]
    pub const fn int_truth(self, i: i64) -> bool { i != 0 || !self.has(Falsy::ZERO) }

    /* the truth of nil which every mask reads as false */
    #[inline(always)]
    pub const fn nil_truth(self) -> bool { false }

    /* the truth of a text that may be empty under this mask */
    #[inline(always)]
    pub const fn text_truth(self, empty: bool) -> bool { !empty || !self.has(Falsy::EMPTY_TEXT) }

    /* the truth of a container that may be empty under this mask */
    #[inline(always)]
    pub const fn container_truth(self, empty: bool) -> bool { !empty || !self.has(Falsy::EMPTY_CONTAINER) }

    /* the truth of a float under this mask */
    #[inline(always)]
    pub fn float_truth(self, x: f64) -> bool { !(x == 0.0 && self.has(Falsy::ZERO) || x.is_nan() && self.has(Falsy::NAN)) }
}

impl Policy {
    /* the rules the engine keeps where a runtime states none of its own */
    pub const ENGINE: Policy = Policy {
        int_overflow: Overflow::Promote,
        int_div: IntDiv::ToFloat,
        int_mod: IntMod::Truncated,
        zero_div: ZeroDiv::Error,
        neg_pow: NegPow::ToFloat,
        numeric_eq: NumEq::Unified,
        bool_is_int: true,
        // an empty text reads as false and an empty container as true
        falsy: Falsy::NIL.or(Falsy::FALSE).or(Falsy::ZERO).or(Falsy::NAN).or(Falsy::EMPTY_TEXT),
        identity_first: true,
        neg_index: true,
        str_iter: StrIter::CodePoints,
        map_iter: MapIter::Keys,
        map_fields: false,
        builtins_scope: true,
        receiver_slot: true,
        recursion_limit: 1000,
        max_int_digits: Some(4300),
    };

    /* whether the loop compiles alike under this policy and `other` */
    pub const fn loops_as(&self, other: &Policy) -> bool {
        self.int_div as u8 == other.int_div as u8 && self.int_mod as u8 == other.int_mod as u8 && self.zero_div as u8 == other.zero_div as u8
            && self.neg_pow as u8 == other.neg_pow as u8 && self.numeric_eq as u8 == other.numeric_eq as u8 && self.bool_is_int == other.bool_is_int
            && self.falsy.bits() == other.falsy.bits() && self.identity_first == other.identity_first && self.neg_index == other.neg_index
            && self.str_iter as u8 == other.str_iter as u8 && self.map_iter as u8 == other.map_iter as u8
            && self.builtins_scope == other.builtins_scope && self.receiver_slot == other.receiver_slot
    }

    /* every rule as bytes so a blob records the rules it ran under */
    pub const fn bytes(&self) -> [u8; 21] {
        let (r, d) = (self.recursion_limit.to_le_bytes(), self.digits().to_le_bytes());
        [
            self.int_overflow as u8, self.int_div as u8, self.int_mod as u8, self.zero_div as u8, self.neg_pow as u8, self.numeric_eq as u8,
            self.bool_is_int as u8, self.falsy.bits(), self.identity_first as u8, self.neg_index as u8, self.str_iter as u8, self.map_iter as u8,
            self.map_fields as u8, self.builtins_scope as u8, self.receiver_slot as u8, r[0], r[1], r[2], r[3], d[0], d[1],
        ]
    }

    /* whether this policy states every rule `other` states */
    pub const fn same(&self, other: &Policy) -> bool {
        let (a, b) = (self.bytes(), other.bytes());
        let mut i = 0;
        while i < a.len() {
            if a[i] != b[i] { return false; }
            i += 1;
        }
        self.digits() == other.digits()
    }

    /* the digit limit where none reads as no limit */
    pub const fn digits(&self) -> u32 {
        match self.max_int_digits { Some(d) => d, None => u32::MAX }
    }

    /* refuses a rule the loop does not read yet unless it is the engine's own */
    pub const fn refuse_unread(&self) {
        assert!(self.falsy.has(Falsy::NIL.or(Falsy::FALSE)), "a policy reads nil and false as false");
        assert!(matches!(self.numeric_eq, NumEq::Unified), "the loop reads no numeric_eq yet so a policy states the engine's Unified");
        assert!(self.identity_first, "the loop reads no identity_first yet so a policy states the engine's true");
        assert!(matches!(self.str_iter, StrIter::CodePoints), "the loop reads no str_iter yet so a policy states the engine's CodePoints");
        assert!(matches!(self.map_iter, MapIter::Keys), "the loop reads no map_iter yet so a policy states the engine's Keys");
        assert!(self.builtins_scope, "the loop reads no builtins_scope yet so a policy states the engine's true");
        assert!(self.receiver_slot, "the loop reads no receiver_slot yet so a policy states the engine's true");
    }
}

/* the arithmetic of each rule as one kernel the loop the folder and lib share */
impl Policy {
    /* the quotient and remainder of `a` by `b` rounded by `int_mod` or none for zero */
    #[inline(always)]
    pub const fn int_divmod(&self, a: i128, b: i128) -> Option<(i128, i128)> {
        // one division since a wide one is a call on 32-bit targets
        let Some(q) = a.checked_div(b) else { return None };
        let r = a - q * b;
        Some(match self.int_mod {
            IntMod::Floored if r != 0 && (r < 0) != (b < 0) => (q - 1, r + b),
            _ => (q, r),
        })
    }

    /* the quotient `a // b` of two inline ints and none for a zero divisor */
    #[inline(always)]
    pub const fn int_floordiv(&self, a: i64, b: i64) -> Option<i64> {
        if b == 0 { return None; }
        let (q, r) = (a / b, a % b);
        Some(if matches!(self.int_mod, IntMod::Floored) && r != 0 && (r < 0) != (b < 0) { q - 1 } else { q })
    }

    /* the remainder `a % b` of two inline ints and none for a zero divisor */
    #[inline(always)]
    pub const fn int_rem(&self, a: i64, b: i64) -> Option<i64> {
        if b == 0 { return None; }
        let r = a % b;
        Some(if matches!(self.int_mod, IntMod::Floored) && r != 0 && (r < 0) != (b < 0) { r + b } else { r })
    }

    /* `a / b` of two inline ints by `int_div` or none for a zero divisor */
    #[inline(always)]
    pub fn int_quotient(&self, a: i64, b: i64) -> Option<Val> {
        if b == 0 { return None; }
        match self.int_div {
            IntDiv::ToFloat => Some(Val::float(a as f64 / b as f64)),
            // a quotient past the inline range leaves for the slow path which boxes it
            IntDiv::Floor => Val::int_checked(self.int_floordiv_floored(a, b)),
            IntDiv::Trunc => Val::int_checked(a / b),
        }
    }

    /* the floored quotient whatever `int_mod` says as `int_div` Floor asks */
    #[inline(always)]
    const fn int_floordiv_floored(&self, a: i64, b: i64) -> i64 {
        let (q, r) = (a / b, a % b);
        if r != 0 && (r < 0) != (b < 0) { q - 1 } else { q }
    }

    /* `a / b` of two floats or none where `zero_div` raises for a zero divisor */
    #[inline(always)]
    pub fn float_quotient(&self, a: f64, b: f64) -> Option<Val> {
        if b == 0.0 && matches!(self.zero_div, ZeroDiv::Error) { return None; }
        Some(Val::float(a / b))
    }

    /* the quotient and remainder of floats as `int_mod` rounds them and none where `zero_div` raises */
    pub fn float_divmod(&self, a: f64, b: f64) -> Option<(f64, f64)> {
        if b == 0.0 {
            return match self.zero_div { ZeroDiv::Error => None, ZeroDiv::Ieee => Some((libm::floor(a / b), f64::NAN)) };
        }
        Some(match self.int_mod {
            IntMod::Floored => crate::value::float_divmod(a, b),
            IntMod::Truncated => {
                let r = libm::fmod(a, b);
                let d = (a - r) / b;
                // a zero quotient keeps the sign the two operands give it
                if d == 0.0 { return Some((f64::from_bits((a.to_bits() ^ b.to_bits()) & (1 << 63)), r)); }
                // d is whole but for rounding so the nearest whole is the quotient
                let f = libm::floor(d);
                (if d - f > 0.5 { f + 1.0 } else { f }, r)
            }
        })
    }

    /* whether an int to a negative int power gives a float rather than raising */
    #[inline(always)]
    pub const fn negative_powers(&self) -> bool { matches!(self.neg_pow, NegPow::ToFloat) }

    /* whether `v` reads as false where its tag decides or none for a heap value */
    #[inline(always)]
    pub fn tag_falsy(&self, v: Val) -> Option<bool> {
        let f = self.falsy;
        if v.is_bool() { return Some(!f.bool_truth(v.as_bool())); }
        if v.is_int() { return Some(!f.int_truth(v.as_int())); }
        if v.is_none() { return Some(!f.nil_truth()); }
        if v.is_float() { return Some(!f.float_truth(v.as_float())); }
        None
    }
}
```

| Field | Values |
|---|---|
| `int_overflow` | `Promote` boxes the result in the wide kind, `Error` raises the overflow error |
| `int_div` | `ToFloat`, `Floor` or `Trunc` |
| `int_mod` | `Truncated` rounds toward zero and gives `%` the dividend's sign, `Floored` rounds down and gives it the divisor's |
| `zero_div` | `Error` raises, `Ieee` gives an infinity or a NaN |
| `neg_pow` | `ToFloat` or `Error` |
| `numeric_eq` | `Unified` makes an int and a float of one value equal with one hash, `ByKind` never equal |
| `falsy` | A mask over `Falsy::NIL`, `FALSE`, `ZERO`, `NAN`, `EMPTY_TEXT` and `EMPTY_CONTAINER`, with `EMPTY` for both empty flags, joined with `or` and tested with `has` |
| `str_iter` | `CodePoints` or `Bytes` |
| `map_iter` | `Keys` or `Pairs` |
| `max_int_digits` | `Some(n)` digits, or `None` for no limit |

The other fields are `bool`, and `recursion_limit` is a `u32`.

The loop, the folder, the slow paths and lib read `int_div`, `int_mod`, `zero_div` and `neg_pow` through one kernel each, so a constant the compiler folds, a hot loop and lib's `divmod` and `pow` give the same answer. `falsy` decides every truth test, where nil and false are always false and the mask adds zero, NaN, an empty text and the empty containers, the last two on flags apart so that `Policy::ENGINE` reads `""` as false and `[]` as true. `int_overflow` must agree with `WIDE`, since an int past the inline range goes to the wide kind. `map_fields` is read on each attribute miss, `recursion_limit` once as a VM boots, and `max_int_digits` by the parser at each int literal and by lib's conversions. `bool_is_int` is read by the slow paths where a bool meets a number, in arithmetic, order, indexes, keys and method lookup, and by lib's kernels and type tests. `neg_index` is read by the loop's item paths and the slow paths of indexes and slices. The loop reads no other field yet, so `Runtime::of` refuses a policy that states anything but the engine's own value for `numeric_eq`, `identity_first`, `str_iter`, `map_iter`, `builtins_scope` or `receiver_slot`. Mini, tiny and uptime state the engine's own for each, and tiny states its own `int_overflow`, `bool_is_int`, `falsy` and `recursion_limit`. `tests/policy.rs` runs a runtime whose `/` keeps two ints an int, which gives an infinity for a float divided by zero, refuses an int to a negative power and reads only nil and false as false, a second whose bools are no ints and whose negative indexes count from no end, and a third that floors `~/` and reads every empty value as false.

```rust file=src/lang/bind.rs
    // the hash of the table the identity of a blob records
    pub hash: u64,
    // what op `op` gives of `args` once its fast path declined
    pub slow: fn(&mut Cx<'_, '_>, u8, &[Val]) -> Result<Val, VmErr>,
    // the constant op `op` folds `args` to or none
    pub fold: fn(u8, &[Val]) -> Option<Val>,
}

impl OpSet {
    /* the table of a runtime with no opcodes of its own */
    pub const NONE: OpSet = OpSet { ops: &[], hash: 0, slow: |_, _, _| Err(OpSet::lacks()), fold: |_, _| None };

    /* the error of an opcode the runtime's own table lacks */
    #[cold]
    pub fn lacks() -> VmErr { cold_runtime("an opcode the runtime's own table lacks") }

    /* an FNV-1a hash of each op's name pops fused native and fold in order */
    pub const fn hash_of(ops: &[OwnOp]) -> u64 {
        use crate::code::ops::{FNV, fnv};
        let (mut h, mut k) = (FNV, 0);
        while k < ops.len() {
            let o = ops[k];
            h = fnv(h, &[o.name.len() as u8]);
            h = fnv(h, o.name.as_bytes());
            let fuse = match o.fuse { Some(f) => f, None => "" };
            h = fnv(h, &[o.pops, fuse.len() as u8, o.folds as u8]);
            h = fnv(h, fuse.as_bytes());
            k += 1;
        }
        h
    }

    /* the op whose fused native `name` a plain call of `pos` arguments runs */
    pub fn fused(&self, name: &str, pos: u8) -> Option<u8> {
        self.ops.iter().position(|o| o.pops == pos && o.fuse == Some(name)).map(|k| k as u8)
    }
}
```

A rule answers for one site and one `Key`, so a site needs one answer for each key it meets.

| Key | Stands for |
|---|---|
| `Kind(k)` | A value of an engine kind, whose rules the kind alone decides |
| `Object(class)` | An object, keyed by its class, whose meta decides its fields, methods and operators |
| `Foreign(token)` | A value of a kind lib or the runtime registered, keyed by its token |

`Key::of(heap, v)` is the key of a value. `Name` is an interned text a site compares by its bits, `Access` says whether a site loads, stores, deletes or calls a method, and `CallShape` counts the positionals and keywords a call passes and marks a spread.

`bind_get` answers a `GetRule`.

| `GetRule` | Means |
|---|---|
| `Slot` | The object's own slot, whose shape and index the engine keeps |
| `Const(v)` | A value fixed for the key, such as a module's global |
| `Method { func, bind }` | A function the meta holds, with the receiver bound first when `bind` is set |
| `Native(id)` | A native method of the receiver's kind |
| `Field` | A map's key or a foreign kind's field of that name |
| `Fail` | The attribute error, which the runtime words |
| `Ask` | No rule, so the engine's own path decides each time |

`bind_call` answers a `CallRule`.

| `CallRule` | Means |
|---|---|
| `Function` | A function of the program, run as frames, sections and calls as jumps |
| `Construct { meta, init, slots }` | A new object of `meta`, whose `init` runs as a frame that hands it back |
| `Bound { func, recv }` | `func` called with `recv` before the arguments |
| `Native(id)` | A native |
| `Fail` | The error of a value no call takes, which the runtime words |
| `Ask` | No rule, so the engine's own path decides each time |

`bind_op` answers an `OpRule`.

| `OpRule` | Means |
|---|---|
| `Kernel` | The engine's inline path for its own kinds under the policy |
| `Native(id)` | A native of lib or of the runtime |
| `Call { func, swap, negate }` | A function of the program laid as a section, with its operands swapped or its answer negated |
| `Identity` | Equality as identity |
| `Fail` | The unsupported operand error, which the runtime words |

An `Op` is what an operator site asks of its operands.

| Op | Asks |
|---|---|
| `Bin(b)`, `InPlace(b)` | A binary operator, or its augmented form, which may change its left operand |
| `Cmp(c)` | `Eq`, `Ne`, `Lt`, `Le`, `Gt` or `Ge` |
| `In` | Whether the right operand holds the left |
| `Unary(u)` | `Neg`, `Pos`, `Abs` or `Invert` |
| `Truth`, `Len`, `Iter`, `Hash` | A test, a length, an iteration and a hash |
| `GetItem`, `SetItem`, `DelItem` | Item access |
| `Runtime(n)` | Opcode `n` of the runtime's own table |

`edge::lang::token_of(op)` is the token a table spells an operator with, and `spelled(cx, op)` is how the runtime's own table spells it, so the words of a `message` name `~/` where the table spells integer division that way.

The engine asks for a rule only where its own path has no answer, so a rule adds to what the engine does and never changes a hit of the inline caches of [Key mechanisms](../05-internals/01-design.mdx#key-mechanisms). It asks `bind_get` where an attribute lookup misses, for a load, a method call, a store and a delete, and a `Field` rule then reads, writes or removes that key of a map. It asks `bind_call` where a value is no function, class or native, and `bind_op` where the kernels refuse an operator's operands, with a unary operator giving its one key twice. `OpRule::Call` runs its function as a frame of the loop, and the op then runs again with what the function gave. A site keeps the rule an answer gave in its cache with the key it met, the name it read and the epoch of the classes, so it asks the runtime once for each key until a class changes or a collection runs. A refusal ends in an error, so no site keeps one. `tests/rules.rs` runs a runtime whose rules read map keys as fields, answer `+` and `<` through an object's class and make instances callable, and counts how often a loop of 300 asks each hook, about twice a site where it asked every time before.

```rust file=src/lang/error.rs
    // stand as a format spec
    Spec,
    // name a keyword argument
    Keyword,
    // lose an attribute when it is no object
    DeleteAttr,
    // lose the arguments an error holds
    DropArgs,
    // be resumed as a body of this kind
    Resume(Body),
    // stand as a complex number which the engine has none of
    Complex,
}

/* why a store cannot change an attribute */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Lock {
    // the receiver is a builtin type
    Type,
    // the attribute is a native method of the receiver's kind
    Native,
    // the receiver keeps only its fixed fields
    Fixed,
    // the attribute exists and takes no store
    Plain,
}

/* where an unhashable value was put */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Use { Plain, Key, Element }

/* the body a generator protocol error names */
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Body { Generator, Coroutine }

/* what a call that misses its signature called */
#[derive(Clone, Debug)]
pub enum Callee {
    // a function of the program by its qualified name with its normal and default parameters
    Function { name: String, normal: u32, defaults: u32 },
    // a native and the kind whose method it is
    Native { id: NativeId, owner: Option<KindId> },
}

/* how a call misses a signature */
#[derive(Clone, Debug)]
pub enum Fit {
    // the positionals given past what the callee takes
    Count(u32),
    // a keyword no parameter takes with the parameter it may mean
    Unexpected { key: String, near: Option<String> },
    // a parameter given twice
    Twice(String),
    // required parameters left unfilled from place `at` where `keyword` marks keyword only ones
    Missing { at: u32, names: Vec<String>, keyword: bool },
    // a positional only parameter given by keyword
    ByKeyword(String),
}

/* a call its callee refuses before binding */
#[derive(Clone, Debug)]
pub enum CallFault {
    // a callee taking no arguments where `keywords` marks keywords and `called` the parentheses
    NoArgs { name: String, keywords: bool, called: bool },
    // the default init given arguments past its object
    InitArgs,
    // an exception class given keywords
    ExcKeywords,
    // a class with no init given arguments
    CtorArgs,
    // a method called off its kind's type with no receiver
    NoReceiver { kind: KindId, name: &'static str },
    // a method called off its kind's type on a value of another kind
    WrongReceiver { kind: KindId, name: &'static str, got: Val },
    // a call past the arguments one call passes
    TooMany { name: String, got: u32 },
    // a builtin type whose instances no call makes
    Instantiate(String),
    // a base no class may derive from where none marks no class at all
    Base(Option<String>),
}

/* the generator and coroutine protocol */
#[derive(Clone, Debug)]
pub enum Gen {
    // resumed while it runs
    Running(Body),
    // a value other than nil sent before it started
    FreshSend(Body),
    // a coroutine awaited after it finished
    Reused,
    // a body that yielded when a close asked it to end
    IgnoredClose(Body),
    // a host wait inside a body that cannot park where `inside` names the body
    Wait { inside: &'static str },
    // a class body that tried to suspend
    ClassSuspend,
    // a value sent into a builtin iterator a body waits inside which takes none
    Sent,
}

/* a class pattern that does not fit its class */
#[derive(Clone, Debug)]
pub enum Pattern {
    // more than one positional pattern for a builtin subject
    OnePositional(Val),
    // positional patterns for a class with no matched fields
    NoFields,
    // more positional patterns than matched fields
    TooMany,
}

/* the errors raised most built in calls of their own so sites keep no room */
impl EngineError {
    #[cold]
    #[inline(never)]

    #[cold]
    #[inline(never)]
    pub fn bad_index(recv: Val, index: Val) -> VmErr { EngineError::BadIndex { recv, index }.into() }

    #[cold]
    #[inline(never)]
    pub fn out_of_range(recv: Val, store: bool) -> VmErr { EngineError::OutOfRange { recv, store }.into() }

    #[cold]
    #[inline(never)]
    pub fn unsupported(op: Op, a: Val, b: Option<Val>) -> VmErr { EngineError::Unsupported { op, a, b }.into() }

    #[cold]
    #[inline(never)]
    pub fn bad_slice(index: Val, step: bool) -> VmErr { EngineError::BadSlice { index, step }.into() }

    #[cold]
    #[inline(never)]
    pub fn zero_step(range: bool) -> VmErr { EngineError::ZeroStep { range }.into() }
}

impl EngineError {
    /* the kind whose class the runtime names and none for a raised value or signal */
    #[inline(never)]
    pub fn kind(&self) -> Option<ErrKind> {
        use EngineError as E;
        Some(match self {
            E::Unsupported { .. } | E::BadIndex { .. } | E::BadSlice { .. } | E::Arity { .. } | E::Call(_) | E::Pattern(_) => ErrKind::Type,
            E::Cannot { act: Act::Complex, .. } => ErrKind::Value,
            E::Cannot { .. } => ErrKind::Type,
            E::OutOfRange { .. } => ErrKind::Index,
            &E::TooWide(k) => k,
            E::MissingKey(_) => ErrKind::Key,
            E::Changed(_) => ErrKind::Runtime,
            E::ZeroStep { .. } | E::NegativeShift | E::ByteRange | E::Unpack { .. } | E::SliceSize { .. } | E::Uneven { .. } | E::NegativePower => ErrKind::Value,
            E::Undefined(_) | E::Unbound { free: true, .. } => ErrKind::Name,
            E::Unbound { .. } => ErrKind::Unbound,
            E::ReadOnly { lock: Lock::Type, .. } => ErrKind::Type,
            E::NoAttribute { .. } | E::ReadOnly { .. } => ErrKind::Attribute,
            E::ZeroDiv | E::ZeroPow => ErrKind::ZeroDiv,
            E::Overflow | E::IntRange | E::FloatRange => ErrKind::Overflow,
            E::Generator(Gen::Running(_)) => ErrKind::Value,
            E::Generator(Gen::Sent) => ErrKind::Attribute,
            E::Generator(Gen::FreshSend(_)) => ErrKind::Type,
            E::Generator(_) => ErrKind::Runtime,
            E::Stop(_) => ErrKind::Stop,
            E::Close => ErrKind::Close,
            E::Exit(_) => ErrKind::Exit,
            E::Assert(_) => ErrKind::Assert,
            E::Recursion => ErrKind::Recursion,
            E::Memory => ErrKind::Memory,
            &E::Of(k, _) => k,
            E::Internal(_) => ErrKind::Runtime,
            E::Raised(_) | E::Budget | E::HostYield(_) | E::HostCallDeferred | E::Redo => return None,
        })
    }
}

/* the token a table spells binary operator `b` with or its augmented form with `place` */
const fn bin_token(b: BinOp, place: bool) -> TokenType {
    use TokenType as T;
    match (b, place) {
        (BinOp::Add, false) => T::Plus, (BinOp::Add, true) => T::PlusEqual,
        (BinOp::Sub, false) => T::Minus, (BinOp::Sub, true) => T::MinusEqual,
        (BinOp::Mul, false) => T::Star, (BinOp::Mul, true) => T::StarEqual,
        (BinOp::TrueDiv, false) => T::Slash, (BinOp::TrueDiv, true) => T::SlashEqual,
        (BinOp::FloorDiv, false) => T::FloorDiv, (BinOp::FloorDiv, true) => T::FloorDivEqual,
        (BinOp::Mod, false) => T::Percent, (BinOp::Mod, true) => T::PercentEqual,
        (BinOp::Pow, false) => T::Pow, (BinOp::Pow, true) => T::PowEqual,
        (BinOp::And, false) => T::BitAnd, (BinOp::And, true) => T::BitAndEqual,
        (BinOp::Or, false) => T::BitOr, (BinOp::Or, true) => T::BitOrEqual,
        (BinOp::Xor, false) => T::BitXor, (BinOp::Xor, true) => T::BitXorEqual,
        (BinOp::Shl, false) => T::LeftShift, (BinOp::Shl, true) => T::LeftShiftEqual,
        (BinOp::Shr, false) => T::RightShift, (BinOp::Shr, true) => T::RightShiftEqual,
        (BinOp::MatMul, false) => T::At, (BinOp::MatMul, true) => T::AtEqual,
    }
}

/* the token a table spells operator `op` with */
pub const fn token_of(op: Op) -> Option<TokenType> {
    use TokenType as T;
    Some(match op {
        Op::Bin(b) => bin_token(b, false),
        Op::InPlace(b) => bin_token(b, true),
        Op::Cmp(c) => match c { Cmp::Eq => T::EqualEqual, Cmp::Ne => T::NotEqual, Cmp::Lt => T::Less, Cmp::Le => T::LessEqual, Cmp::Gt => T::Greater, Cmp::Ge => T::GreaterEqual },
        Op::Unary(UnOp::Neg) => T::Minus,
        Op::Unary(UnOp::Pos) => T::Plus,
        Op::Unary(UnOp::Invert) => T::Tilde,
        Op::In => T::In,
        _ => return None,
    })
}

/* how many operators a runtime keeps the spelling of */
pub const SPELLED: usize = 36;

// the binary operators in their order as the spellings keep them
const BINS: [BinOp; 13] = [BinOp::Add, BinOp::Sub, BinOp::Mul, BinOp::FloorDiv, BinOp::Mod, BinOp::TrueDiv, BinOp::Pow, BinOp::And, BinOp::Or, BinOp::Xor, BinOp::Shl, BinOp::Shr, BinOp::MatMul];

/* where the spellings keep `op` and none for an operator no token spells */
pub const fn slot(op: Op) -> Option<usize> {
    Some(match op {
        Op::Bin(b) => b as usize,
        Op::InPlace(b) => BINS.len() + b as usize,
        Op::Cmp(c) => 2 * BINS.len() + c as usize,
        Op::Unary(UnOp::Neg) => 32,
        Op::Unary(UnOp::Pos) => 33,
        Op::Unary(UnOp::Invert) => 34,
        Op::In => 35,
        _ => return None,
    })
}

/* each operator as `syntax` spells it at its slot or empty where it lacks one */
pub const fn spellings(syntax: &crate::syntax::lexer::Syntax) -> [&'static str; SPELLED] {
    let mut out = [""; SPELLED];
    let cmps = [Cmp::Eq, Cmp::Ne, Cmp::Lt, Cmp::Le, Cmp::Gt, Cmp::Ge];
    let mut k = 0;
    while k < BINS.len() {
        out[k] = spelling_in(syntax, bin_token(BINS[k], false));
        out[BINS.len() + k] = spelling_in(syntax, bin_token(BINS[k], true));
        k += 1;
    }
    k = 0;
    while k < cmps.len() {
        if let Some(t) = token_of(Op::Cmp(cmps[k])) { out[2 * BINS.len() + k] = spelling_in(syntax, t); }
        k += 1;
    }
    (out[32], out[33], out[34], out[35]) = (spelling_in(syntax, TokenType::Minus), spelling_in(syntax, TokenType::Plus), spelling_in(syntax, TokenType::Tilde), spelling_in(syntax, TokenType::In));
    out
}

/* the first spelling of token `t` in the words and then the symbols of `syntax` */
const fn spelling_in(syntax: &crate::syntax::lexer::Syntax, t: TokenType) -> &'static str {
    let mut k = 0;
    while k < syntax.words.len() {
        if syntax.words[k].1 as usize == t as usize { return syntax.words[k].0; }
        k += 1;
    }
    k = 0;
    while k < syntax.symbols.len() {
        if syntax.symbols[k].1 as usize == t as usize { return syntax.symbols[k].0; }
        k += 1;
    }
    ""
}

/* how the runtime's own table spells `op` or its role where the table lacks it */
pub fn spelled(cx: &Cx<'_, '_>, op: Op) -> &'static str {
    match slot(op).map(|k| cx.runtime().spellings[k]) {
        Some(s) if !s.is_empty() => s,
        _ => match op {
            Op::Bin(_) | Op::InPlace(_) => "the operator",
            Op::Cmp(_) => "the comparison",
            // a runtime opcode reads as the native it fuses or its own name
            Op::Runtime(n) => cx.runtime().ops.ops.get(n as usize).map_or("the operation", |o| o.fuse.unwrap_or(o.name)),
            _ => "the operation",
        },
    }
}

/* the engine's plain words for `e` which a runtime naming its own replaces */
pub fn plain(cx: &mut Cx<'_, '_>, e: &EngineError) -> String {
    use EngineError as E;
    let ty = |cx: &Cx<'_, '_>, v: Val| String::from(cx.type_name(v));
    match e {
        &E::Unsupported { op, a, b: Some(b) } => crate::s!(str spelled(cx, op), " does not apply to ", str &ty(cx, a), " and ", str &ty(cx, b)),
        &E::Unsupported { op, a, b: None } => crate::s!(str spelled(cx, op), " does not apply to ", str &ty(cx, a)),
        &E::Cannot { act, recv } => {
            let what = recv.map_or(String::from("the value"), |v| crate::s!("a value of kind ", str &ty(cx, v)));
            crate::s!(str &what, " cannot ", str verb(act))
        }
        &E::BadIndex { recv, index } => crate::s!(str &ty(cx, recv), " takes no index of kind ", str &ty(cx, index)),
        &E::BadSlice { index, .. } => crate::s!("a slice takes no bound of kind ", str &ty(cx, index)),
        &E::OutOfRange { recv, .. } => crate::s!(str &ty(cx, recv), " index out of range"),
        E::TooWide(_) => String::from("the int is too wide for an index"),
        &E::MissingKey(k) => crate::s!("no key ", str &cx.render(k, Mode::Repr).unwrap_or_default()),
        &E::Changed(k) => crate::s!("the ", str cx.names().kind(k), " changed its size while a loop walked it"),
        E::ZeroStep { .. } => String::from("a step of zero"),
        E::Arity { callee, fit } => arity(cx, callee, fit),
        E::Call(f) => call_fault(cx, f),
        E::Undefined(n) => crate::s!(str n, " is not bound"),
        E::Unbound { name: Some(n), .. } => crate::s!(str n, " is read before it is bound"),
        E::Unbound { name: None, .. } => String::from("a local is read before it is bound"),
        E::NoAttribute { recv, name, .. } => crate::s!(str &ty(cx, *recv), " has no field ", str name),
        E::ReadOnly { recv, name, .. } => crate::s!("the field ", str name, " of ", str &ty(cx, *recv), " is read only"),
        E::ZeroDiv => String::from("division by zero"),
        E::ZeroPow => String::from("zero to a negative power"),
        E::NegativePower => String::from("an int to a negative power"),
        E::Overflow => String::from(cx.names().overflow),
        E::IntRange => String::from("the int result is past the range ints hold"),
        E::FloatRange => String::from("the float result is out of range"),
        E::NegativeShift => String::from("a negative shift count"),
        E::ByteRange => String::from("a byte lies from 0 to 255"),
        &E::Unpack { want, got, .. } => match got {
            Some(got) => crate::s!("unpacking takes ", int want as i64, " values and got ", int got as i64),
            None => crate::s!("unpacking takes ", int want as i64, " values"),
        },
        &E::SliceSize { size, span } => crate::s!("a sequence of ", int size as i64, " cannot fill a slice of ", int span as i64),
        &E::Uneven { arg, longer } => crate::s!("iterable ", int i64::from(arg) + 1, " of a strict walk ends ", str if longer { "after" } else { "before" }, " the ones ahead of it"),
        E::Generator(g) => match g {
            Gen::Running(_) => String::from("the body is already running"),
            Gen::FreshSend(_) => crate::s!("a body that has not started takes only ", str cx.names().nil),
            Gen::Reused => String::from("the body already ran to its end"),
            Gen::IgnoredClose(_) => String::from("the body went on after a close"),
            Gen::Wait { inside } => crate::s!("a host wait cannot park inside ", str inside),
            Gen::ClassSuspend => String::from("a class body cannot suspend"),
            Gen::Sent => String::from("a builtin iterator takes no sent value"),
        },
        E::Pattern(_) => String::from("the class pattern does not fit its class"),
        &E::Stop(v) | &E::Exit(v) | &E::Assert(v) => if v.is_undef() || v.is_none() { String::new() } else { cx.render(v, Mode::Str).unwrap_or_default() },
        E::Close => String::new(),
        E::Recursion => String::from("calls nested past the recursion limit"),
        E::Memory => String::from("memory limit"),
        E::Of(_, text) => text.clone(),
        &E::Raised(v) => cx.render(v, Mode::Str).unwrap_or_default(),
        E::Internal(text) => String::from(*text),
        E::Budget => String::from("budget exceeded"),
        E::HostYield(_) | E::HostCallDeferred | E::Redo => String::from("a signal left the run"),
    }
}

/* what `act` asks in plain words */
fn verb(act: Act) -> &'static str {
    match act {
        Act::Iterate => "be iterated", Act::Next => "step as an iterator", Act::Call => "be called", Act::Subscript => "be indexed",
        Act::AssignItem => "take an item", Act::DeleteItem => "drop an item", Act::AssignSlice => "take a slice", Act::Slice => "be sliced",
        Act::Sequence => "be sliced as a sequence", Act::Size => "report a size", Act::Hash { .. } => "stand as a key", Act::Await => "be awaited",
        Act::Map { .. } => "be read as a map", Act::Contain => "hold items", Act::Index => "stand for an index", Act::Raise { .. } => "be raised",
        Act::Bytes => "be read as bytes", Act::Spec => "stand as a format spec", Act::Keyword => "name a keyword", Act::DeleteAttr => "lose a field", Act::DropArgs => "lose the arguments it holds",
        Act::Resume(_) => "be resumed", Act::Complex => "be a complex number",
    }
}

/* a misfit call in plain words */
fn arity(cx: &mut Cx<'_, '_>, callee: &Callee, fit: &Fit) -> String {
    let name = match callee {
        Callee::Function { name, .. } => name.as_str(),
        &Callee::Native { id, .. } => cx.vm().natives.name(id),
    };
    match fit {
        Fit::Count(got) => crate::s!(str name, " takes another count of arguments than ", int *got as i64),
        Fit::Unexpected { key, .. } => crate::s!(str name, " takes no keyword ", str key),
        Fit::Twice(key) => crate::s!(str name, " got ", str key, " twice"),
        Fit::Missing { names, .. } if !names.is_empty() => crate::s!(str name, " misses ", str &names.join(" and ")),
        Fit::Missing { at, .. } => crate::s!(str name, " misses argument ", int *at as i64 + 1),
        Fit::ByKeyword(key) => crate::s!(str name, " takes ", str key, " only by position"),
    }
}

/* a refused call in plain words */
fn call_fault(cx: &Cx<'_, '_>, f: &CallFault) -> String {
    match f {
        CallFault::NoArgs { name, .. } => crate::s!(str name, " takes no arguments"),
        CallFault::InitArgs | CallFault::CtorArgs => String::from("the class takes no arguments"),
        CallFault::ExcKeywords => String::from("an error class takes no keywords"),
        &CallFault::NoReceiver { kind, name } => crate::s!(str name, " of ", str cx.names().kind(kind), " needs a receiver"),
        &CallFault::WrongReceiver { kind, name, got } => crate::s!(str name, " of ", str cx.names().kind(kind), " takes no receiver of kind ", str cx.type_name(got)),
        CallFault::TooMany { name, got } => crate::s!(str name, " got ", int *got as i64, " arguments past the most a call passes"),
        CallFault::Instantiate(name) => crate::s!(str name, " makes no instances"),
        CallFault::Base(Some(name)) => crate::s!(str name, " cannot be a base"),
        CallFault::Base(None) => String::from("a base must be a class"),
    }
}

/* the words of `e` with no machine to name its values */
pub fn bare(e: &EngineError) -> String {
    use EngineError as E;
    match e {
        E::Unsupported { .. } => String::from("an operator does not apply to its operands"),
        &E::Cannot { act, .. } => crate::s!("the value cannot ", str verb(act)),
        E::OutOfRange { .. } => String::from("index out of range"),
        E::Undefined(n) => crate::s!(str n, " is not bound"),
        E::NoAttribute { name, .. } => crate::s!("no field ", str name),
        E::Of(_, text) => text.clone(),
        E::Internal(text) => String::from(*text),
        E::ZeroDiv => String::from("division by zero"),
        E::Recursion => String::from("calls nested past the recursion limit"),
        E::Memory => String::from("memory limit"),
        E::Budget => String::from("budget exceeded"),
        _ => String::from("the engine refused the operation"),
    }
}
```

`EngineError` is an error as facts, and `e.kind()` is the `ErrKind` whose class `NAMES.errors` gives it.

| Variant | Kind |
|---|---|
| `Unsupported`, `BadIndex`, `BadSlice`, `Arity`, `Call`, `Pattern` | `Type` |
| `Cannot` | `Type` |
| `Cannot` with `Act::Complex` | `Value` |
| `OutOfRange` | `Index` |
| `TooWide(k)` | `k` |
| `MissingKey` | `Key` |
| `Changed`, a map or a set that changed its size while a loop walked it | `Runtime` |
| `ZeroStep`, `NegativeShift`, `ByteRange`, `Unpack`, `SliceSize`, `NegativePower` | `Value` |
| `Undefined`, and `Unbound` of a free cell | `Name` |
| `Unbound` of a local | `Unbound` |
| `NoAttribute`, and `ReadOnly` past a builtin type | `Attribute` |
| `ReadOnly` of a builtin type | `Type` |
| `ZeroDiv`, `ZeroPow` | `ZeroDiv` |
| `Overflow`, `IntRange`, `FloatRange` | `Overflow` |
| `Generator` of a body already running | `Value` |
| `Generator` of a value sent before the body starts | `Type` |
| `Generator` of a value sent into a builtin iterator a body waits inside | `Attribute` |
| Any other `Generator` | `Runtime` |
| `Stop`, `Close`, `Exit`, `Assert`, `Recursion`, `Memory` | Each its own |
| `Of(k, words)` | `k` |
| `Internal` | `Runtime` |
| `Raised`, `Budget`, `HostYield`, `HostCallDeferred`, `Redo` | None |

The types a variant holds say how it went wrong. `Act` names what a value was asked to do, `Lock` why a store cannot change an attribute, `Use` where an unhashable value was put, `Callee` and `Fit` what a call missed and how, `CallFault` a call refused before it binds, `Gen` the generator protocol and `Pattern` a class pattern that does not fit.

The engine raises its own errors as an `EngineError` and words each one through the runtime's `message` where a handler catches it or where it leaves the machine, so a program reads every error of the engine in its runtime's words. `edge::lang::plain(cx, e)` words each variant in the engine's plain terms, naming kinds as `NAMES.kinds` does and operators as the table spells them, and a runtime's `message` may hand back to it for the variants it leaves. A handler of the program binds what the runtime's `raise` makes of an error of the engine, whose words the engine has written as an `Of` by then. `raised::<L>`, the default, builds an exception of `L`'s class for the kind holding `L::message`'s words, the words as they are for `Of`, the key itself for `MissingKey`, and the value for `Exit`, `Stop` and `Assert`.
