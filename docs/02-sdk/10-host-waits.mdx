# Host waits

A run can stop and wait for its host, then carry on where it stopped once the host answers. The engine has no event loop of its own. The host drives the run, and a run that waits hands control back with a status that names what it waits for. A run waits for one of two things, the next event the host pushes or the answer to a host call.

| Wait | Starts when | Status | The host answers with |
|---|---|---|---|
| Event | A native returns `Step::Wait`, as lib's `io::receive` does when no event is queued | `PENDING_EVENT` | `run_push_event`, then `run_resume` |
| Host call | A host module or a plugin answers a call later | `PENDING_HOST_CALL` | `set_host_result_by_id` or `set_host_error_by_id`, then `run_resume` |

A run under a preempt interval also stops every `n` loop back-edges with `PREEMPTED`, and its host resumes it at once or saves it first. [Rust](../03-platforms/04-rust.mdx#the-status-word) lists every status and the loop that serves them.

## A native that waits

A native waits by returning `Step::Wait`. The engine parks the run, and the event the host pushes next becomes the native's value. An event is a text, and one pushed while the run is busy waits in a queue. `Cx::take_event` takes the oldest queued event without waiting, so lib's `io::receive` is a single match.

```rust file=lib/src/io.rs
use alloc::borrow::Cow;
use alloc::string::String;

use edge::lang::{Args, Cx, Language, Mode, Ret, STEPS, Sig, Step};
use edge::value::{HeapObj, HeapPool, Val, VmErr};

use crate::fail::{Fail, fail};
use crate::fmt::render::{Style, push_f64};
use crate::{Kernel, Lang, Site};

/* writes each value as the runtime renders it between a separator and before an end */
pub const fn print<S: Site>() -> Kernel {
    let print = Kernel::new(Sig::var(0), print_run::<S>).reads(2);
    if <S::Lang as Lang>::PLAIN { print.fast_out(print_plain::<S>) } else { print }
}

/* the next line the host fed */
pub const fn read_line<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), read_line_run::<S>) }

/* the oldest event the host pushed or a wait for the next */
pub const fn receive<S: Site>() -> Kernel { Kernel::new(Sig::exact(0), receive_run).flags(STEPS) }

/* hands one message to the host's scheduler */
pub const fn send<S: Site>() -> Kernel { Kernel::new(Sig::exact(2), send_run::<S>) }

/* ends the run with the status it is given where none means zero */
pub const fn exit<S: Site>() -> Kernel { Kernel::new(Sig::range(0, 1), exit_run::<S>) }

fn print_run<S: Site>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let (sep, end) = if a.kw.is_empty() { (Cow::Borrowed(" "), Cow::Borrowed("\n")) } else { (text_kw::<S>(cx, a.kw(0), " ", 0)?, text_kw::<S>(cx, a.kw(1), "\n", 1)?) };
    let mut body = cx.line();
    for (i, &v) in a.pos.iter().enumerate() {
        if i > 0 { body.push_str(&sep); }
        <S::Lang as Lang>::show_into(cx, v, Mode::Str, &mut body)?;
    }
    body.push_str(&end);
    cx.write_line(body);
    Ok(Val::none().into())
}

/* the line a print of scalars and texts writes with the units their rendering charges */
fn print_plain<S: Site>(heap: &HeapPool, pos: &[Val], out: &mut String) -> Option<usize> {
    let mut units = 0;
    for (i, &v) in pos.iter().enumerate() {
        if i > 0 { out.push(' '); }
        let start = out.len();
        if v.is_int() { out.push_str(itoa::Buffer::new().format(v.as_int())); }
        else if let Some(HeapObj::Str(s)) = heap.try_get(v) { out.push_str(s); }
        else if v.is_bool() { out.push_str(if v.as_bool() { <S::Lang as Style>::TRUE } else { <S::Lang as Style>::FALSE }); }
        else if v.is_none() { out.push_str(<S::Lang as Language>::NAMES.nil); }
        else if v.is_float() { push_f64::<S::Lang>(out, v.as_float()); }
        else { return None; }
        units += out.len() - start;
    }
    out.push('\n');
    Some(units)
}

/* keyword slot `at` as given where nil keeps the default */
fn text_kw<S: Site>(cx: &mut Cx<'_, '_>, v: Option<Val>, default: &'static str, at: u8) -> Result<Cow<'static, str>, VmErr> {
    let Some(v) = v.filter(|v| !v.is_none()) else { return Ok(Cow::Borrowed(default)) };
    match cx.text(v) {
        Some(t) => Ok(Cow::Owned(t.into())),
        None => Err(fail::<S>(cx, Fail::KeywordText { at, v })),
    }
}

fn read_line_run<S: Site>(cx: &mut Cx<'_, '_>, _: Args<'_>) -> Ret {
    match cx.read_line() {
        Some(line) => Ok(cx.new_str(line)?.into()),
        None => Err(fail::<S>(cx, Fail::EndOfInput)),
    }
}

fn receive_run(cx: &mut Cx<'_, '_>, _: Args<'_>) -> Ret {
    match cx.take_event() {
        Some(v) => Ok(v.into()),
        None => Ok(Step::Wait.into()),
    }
}

fn exit_run<S: Site>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let code = a.pos.first().copied().unwrap_or(Val::int(0));
    if !code.is_int() { return Err(fail::<S>(cx, Fail::ExitCode(code))); }
    // an uncaught exit failure ends the run with the status it holds
    Err(fail::<S>(cx, Fail::Exit(code)))
}

fn send_run<S: Site>(cx: &mut Cx<'_, '_>, a: Args<'_>) -> Ret {
    let Some(group) = cx.text(a.pos[0]).map(String::from) else { return Err(fail::<S>(cx, Fail::SendText(1))) };
    let Some(body) = cx.text(a.pos[1]).map(String::from) else { return Err(fail::<S>(cx, Fail::SendText(2))) };
    if !cx.sent(&group, &body)? { return Err(fail::<S>(cx, Fail::NoScheduler)); }
    Ok(Val::none().into())
}
```

Mini names that kernel `receive`. Tiny names no such kernel, so a flow never waits for an event.

## A host call that waits

A call into a host module answers at once or later, and the run parks only for a later answer.

| Host | Answers at once | Parks the run |
|---|---|---|
| The CLI kit | A `Reply` answered before the call returns, through `ok`, `fail` or `answer` | A `Reply` answered after the call returned, from any thread, or through `later` even when the answer is known |
| The JS host | A call that returns a value | A call that returns a promise, until it settles |
| A wasm plugin | A system call `edge_op` answers with `0` | A system call it answers with `2`, which the plugin returns and finishes in `__edge_resume` |

A `Reply` dropped unanswered fails its call, so a host module that forgets one never hangs the run. [Plugins](./15-plugins.mdx#host-modules) describes both kinds of host module, and [System calls](../04-reference/06-abi.mdx#system-calls) the four steps a plugin's wait takes.

`net` uses both answers. `request` answers at once with an id, and the request runs on a thread of its own in the CLI and as a fetch in the browser. On a request, `response` and `read` always park the run, even when the head or the chunk already arrived, so a program waits at the same points on both hosts. A tiny flow whose `from` is a URL, as the GH Archive job's is, parks once on the head and once on every read of the body.

## Where a run may wait

| The wait happens in | What follows |
|---|---|
| The module body, or a function it calls however deep | The whole run parks, and the frames between come back as they were on resume |
| A generator a `for` loop steps, or a function that generator calls | The loop parks with the generator |
| A generator or a coroutine stepped by its `next` or `send` | The engine refuses the wait, and mini prints `receive() and host calls cannot wait inside a generator or a coroutine` |
| A function a native calls, such as the key of a sort or the function a map applies inside a native's loop | The engine refuses the wait, and mini prints `receive() and host calls cannot wait inside a callback a builtin runs` |
| A binding of the name a runtime's own opcode fuses, which the op calls once the program binds it | The engine refuses the wait, and mini prints `receive() and host calls cannot wait inside a call an op makes` |
| A class body | The engine refuses the wait, and mini prints `a class body cannot suspend, await outside it` |

The runtime words each refusal through its `message`, so mini's text above is mini's own. A runtime that keeps the engine's plain words prints `a host wait cannot park inside a generator or a coroutine`, `a host wait cannot park inside a callback a builtin runs`, `a host wait cannot park inside a call an op makes` and `a class body cannot suspend`. Each refusal takes the class the runtime names for the engine's runtime error, and a handler around the call catches it as it catches any other error. A host call that fails raises its error where the run waits, so a handler around the call catches that too.

## The host side

A host serves both waits through the exports of the runtime's `.wasm`, in the run loop [Rust](../03-platforms/04-rust.mdx#the-run-loop) describes. Each host does it for its own programs.

- `edge run --events <file>` feeds each line of a file as one event, and `--save-state <file>` saves the run when it waits on something the CLI cannot serve.
- An actor waits for its next message in an event wait, and its scheduler pushes the message once one arrives.
- A page hands an event to a worker with `pushEvent`, described in [JavaScript](../03-platforms/02-javascript.mdx#events).

A Rust host that embeds the crate drives the same loop on a `VM`. A native the host binds into a module defers its answer by returning `VmErr::HostCallDeferred`. `run()` returns `VmErr::HostYield` with the status, `push_event` queues an event, and `inject_host_result_by_id` and `inject_host_error_by_id` answer call `id`, numbered from zero in the order the run made its waiting calls. Tiny's suite drives its flows this way in `examples/tiny/tests/flows.rs`. For a case marked `hops` it saves the run at every wait and restores it into a fresh `VM` before it answers.

## Waits and snapshots

A parked run is a point it can be saved at. The snapshot holds the module body, the frames that parked with it and the call it waits on, and a restored run waits for the same answer. A tiny flow parked on its source keeps the rows or records of every report, the header of a CSV file it writes and the line it has not finished across a snapshot. [Snapshots](./11-snapshots.mdx) covers the blob and what it holds.
