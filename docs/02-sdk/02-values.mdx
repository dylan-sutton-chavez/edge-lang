# Values

Every value the engine handles is a `Val`, eight bytes on every target. A number or a constant lives in the bits themselves, and anything else names a slot of the heap or an entry of the FOREIGN table. A native reads and makes values through `Cx`, as [Natives](./05-natives.mdx#cx) lists, and [Memory model](../05-internals/01-design.mdx#memory-model) has the bit pattern of each tag. This page covers what a runtime and its natives see of them.

## Val

| A `Val` holds | Made with | Read with |
|---|---|---|
| A float | `Val::float(f)` | `is_float`, `as_float` |
| An int of 48 bits | `Val::int(i)`, or `Val::int_checked(i)`, which answers `None` past the range | `is_int`, `as_int` |
| One of the two truths | `Val::bool(b)` | `is_bool`, `as_bool`, `is_true`, `is_false` |
| Nil | `Val::none()` | `is_none` |
| The mark of a name nothing bound yet | `Val::undef()` | `is_undef` |
| A slot of the heap | `heap.alloc(obj)` or a maker of `Cx` | `is_heap`, `heap.try_get(v)` |
| An entry of the FOREIGN table | `heap.foreign_new(token, store)` or `heap.foreign_box(token, payload)` | `is_foreign`, `heap.foreign_payload(token, v)` |

An int runs from `Val::INT_MIN` to `Val::INT_MAX`, -140,737,488,355,328 to 140,737,488,355,327, inline with no box. A result past them boxes in the runtime's wide kind, the FOREIGN kind its language's `WIDE` names, and a result that fits again comes back inline, so every int has one form and the inner loop never meets a box. `Cx::new_int` and `heap.int(i)` pick the form, and a runtime that names no wide kind raises its overflow error past 48 bits instead.

Every NaN is stored as one quiet NaN with its sign kept, since the payload of another could read as a tag. Two NaNs are one value, so a set keeps one, while `n == n` stays false.

A 64-bit hash lives past 48 bits from its first value. This one is FNV-1a, the hash the bench keys its cases by, over the first case of `tests/cases/vm/basics.yml` as the bench reads it, and it prints that case's key in `bench/.snapshot`. Each step boxes its result in mini's wide kind, a FOREIGN entry the collector frees once nothing holds it.

```edge
// the key the bench gives the first case of tests/cases/vm/basics.yml
case = '{"output":["True"],"src":"print(true)"}'

fn fnv64(text):
    h = 0xcbf29ce484222325
    for b in text.encode():
        h = (h ^ b) * 0x100000001b3 % 2**64
    return h

key = fnv64(case)
print(f'{key:016x}', key > 2**47)
```

```output
007397267403633c True
```

## Kinds

`kind_of(heap, v)`, which `Cx::kind` reads, gives the `KindId` of a value. A kind is what a native method registers on, and the runtime's `Names.kinds` words each kind for its errors. A wide int reads as `Int`, so the methods of ints answer it too.

| Kind | Holds | Heap object |
|---|---|---|
| `None`, `Bool`, `Int`, `Float` | Nil, the truths, ints and floats | No slot, the bits hold them |
| `Str` | Text in UTF-8 | `Str` |
| `Bytes`, `ByteArray` | Bytes that never change and bytes that do | `Bytes`, `ByteArray` |
| `List`, `Tuple` | A sequence that changes and one that never does | `List`, `Tuple` |
| `Dict`, `Set` | A map and a set, each in the order its keys first came | `Dict`, `Set` |
| `Range` | A range of ints | `Range`, `BigRange` past 64 bits |
| `Func` | A function, or one bound to its receiver | `Func`, `Bound` |
| `Coro` | A generator or a coroutine | `Coroutine` |
| `Iter` | One of the engine's iterators | `Iter` |
| `Module` | A module a program imported | `Module` |
| `Type`, `Class`, `Instance` | A type object, a class and an object of one, a raised error among them | `Object`, which its `meta` tells apart |
| `Cell` | A variable a closure shares with the frame that binds it | `Cell` |
| `Other` | A native, a host's binding or a native bound to its receiver | `Native`, `Bound` |
| `Foreign` | An entry of a kind a runtime or lib registered | No slot, the FOREIGN table holds it |

The heap objects are the leaves the engine knows, and `HeapObj` is closed. An `Object` is a class, a type object or an instance by its `meta`, which is a tag holding the place of a class's or a type's head, its name, bases and members, or else the class or type an instance was made of, so a guard reads one word. A `Bound` holds a receiver and its function or a native's place in the table, and a `Native` holds that place alone. A runtime adds no heap object of its own and boxes its own data in a FOREIGN kind, as mini and tiny box their times.

A list, a map and a set are shared, so every name holding one sees a change through any other. A text, bytes and a tuple never change once built. A map and a set key by content, hashing each key with `hash_val_with_heap` and matching a member by identity before they compare it, so a map keyed by tuples finds an equal tuple built later. A lookup reads one place of its table at a time and pays the op budget for each probe past its first thirty two, so keys chosen to share a hash pay for the probes of each lookup, and a build or a set operation stops once its probes spend the budget. The walks that hash and compare nested containers read up to 1,048,576 items as they go, and past that walk again remembering each container they read, so a value built from shared parts costs what its distinct parts hold.

## The heap

`HeapPool` is the arena of a run, a vector of slots a heap `Val` names by a 28-bit index, so a run holds at most 268,435,456 slots. A freed slot goes on a free list that the next allocations take from, so a run that builds and drops objects in rounds holds no more slots than at its peak. A slot is reused with no generation, so anything that remembers a value by identity is marked or dropped at each collection.

Some values share one slot by content, so equal ones are the same value. The tables that find them pay for each probe past their first thirty two as a map does, so values chosen to share a hash pay for the probes they take.

| Shared | By |
|---|---|
| Names and the text constants of a chunk, up to 128 bytes | Their text, through `intern_str` |
| Every empty text and every text of one byte | Its text, as it is made |
| Bytes up to 128 bytes | Their content, as they are made |
| Type objects | Their name |
| The ellipsis | One value of the runtime's ellipsis kind, made on its first use |
| A function bound to a receiver | The receiver and the function |
| A native method bound to a receiver | The receiver and its place in the table |
| A native method read off its type | Its place in the table |

A text built at run time past one byte is never shared, so two equal texts read from a source are two values that compare equal. A slot keeps a mark of whether its text is all ASCII, read once, so the length of an ASCII text and an index into one cost no scan. An index or a cut into any other text walks from its start, its end or the place the last walk of that text stopped, whichever is nearest, and a walk past 1,024 bytes pays one op for each 16 bytes it reads. A text a loop builds with `+=` grows in place while the loop's register owns it, as [Dispatch shape](../05-internals/01-design.mdx#dispatch-shape) describes.

`heap.alloc(obj)` admits a new slot unless the run holds twice its memory limit or the arena is full, and the makers of `Cx` go through it. Only the error that reports the limit itself is built past that, through `alloc_emergency`.

## FOREIGN kinds

A FOREIGN value is data the engine holds without knowing its insides, owned by the kind that made it. A kind is a static `Kind` of the crate that owns it.

| Field | Is |
|---|---|
| `name`, `version` | What a snapshot names the kind by, and a restore needs a kind of both |
| `type_name` | The name of the kind's type, which errors and a value's type show |
| `family` | Values of different families are never equal, so hashes need agree only within one |
| `immutable` | Whether a value may be copied or shared freely, since its identity is never seen |
| `repr`, `str`, `truthy` | How a value shows, how it shows as text where that differs, and whether it reads as true under the heap's rules |
| `hash`, `eq` | The hash and the equality a key uses, never across families and never running program code |
| `cmp` | The order of two values, or `None` for a kind that does not order |
| `binop`, `unop` | The operators a value answers, each free to decline one |
| `to_f64`, `to_i128` | A value as a float or an int, for a kind that is a number |
| `from_i128`, `from_digits` | How an int past the inline range boxes and how digits past it read, set only by the wide kind |
| `trace` | The engine values a payload keeps alive, which the collector marks |
| `get` | What an attribute load of a value reads where the kind's methods hold no such name |
| `len`, `item`, `cut` | The length a value reports, the item an index reads and the cut its three bounds read |
| `iter` | The `IterFrame` a loop over a value steps |
| `call` | What a call of a value with its positionals gives, free to decline |
| `snapshot` | `Snapshot::Serialize` with the codec of a shared payload, `Snapshot::Store` for a kind of inline stores alone, or `Snapshot::Reject` |
| `transfer` | `Transfer::Copy` or `Transfer::Deny` across the plugin wire |

`heap.register_kind(&KIND)` registers a kind once and gives its `KindToken`, a kind already registered gets its token back, and another kind under a name one holds is refused with a runtime error, since a snapshot finds a kind by its name. The token is the proof of owning the kind. `heap.foreign_new(token, store)` boxes a new value whose `Store` lies inline in its entry, so it takes no allocation of its own. A store is `Words` of three plain words, `Vals` of three values the collector traces, or `Shared`, a payload of the kind's own type behind one allocation. `heap.foreign_box(token, payload)` boxes an `Rc<dyn Any>` as a `Shared` store, `heap.foreign_box_int(token, i)` keeps an `i128` in `Words`, and `heap.foreign_payload::<T>(token, v)` reads a store back as its type, `None` for a value of another kind. Every other part of the engine only passes the `Val` around and calls the kind's operations. `Cx::kind_token(heap, &KIND)` finds the token once the kind is registered, as tiny's `instant` does in `examples/tiny/src/natives.rs`.

A FOREIGN `Val` names its entry by index and by generation. A freed entry takes the next generation, so a stale or forged `Val` finds nothing, and an entry whose generation runs out retires instead of being reused. The table takes its first entries on the first value a run boxes, and a value of an inline store counts toward a collection as a heap slot does. The engine looks for a FOREIGN value only on its slow paths, so the inline int and float paths pay nothing for them. An operation a kind leaves at `None`, or one that answers `None`, declines, and the engine raises its own error for the operands.

Lib's date module holds the two kinds mini and tiny box their times and durations in, built for each runtime with the type names it picks.

```rust file=lib/src/date/kind.rs
use alloc::rc::Rc;
use alloc::string::String;
use alloc::vec::Vec;
use core::any::Any;
use core::cmp::Ordering;

use edge::value::foreign::{BinOp, Kind, Snapshot, Transfer, UnOp};
use edge::value::{HeapPool, Val, VmErr, as_i128};

use super::{Dates, Duration, Time, duration_val, held, part_of, time_val};
use crate::fail::{Fail, bare};

/* the kind a runtime boxes its times in under the type name `type_name` */
pub const fn time_kind<D: Dates>(type_name: &'static str) -> Kind {
    Kind {
        name: "date.time",
        version: 1,
        type_name,
        family: "date.time",
        immutable: true,
        repr: |p| Ok(p.downcast_ref::<Time>().map_or_else(String::new, Time::text)),
        truthy: |_, _| true,
        hash: |_, p| p.downcast_ref::<Time>().map_or(0, |t| mix(t.nanos)),
        // two texts naming one instant in other offsets are equal times
        eq: |heap, p, other| order::<Time>(heap, p, other) == Some(Ordering::Equal),
        cmp: Some(order::<Time>),
        binop: Some(binop::<D>),
        unop: None,
        to_f64: None,
        to_i128: None,
        from_i128: None,
        from_digits: None,
        trace: None,
        get: Some(field),
        snapshot: Snapshot::Serialize { save: save_time, load: load_time },
        transfer: Transfer::Deny,
        ..Kind::PLAIN
    }
}

/* the kind a runtime boxes its durations in under the type name `type_name` */
pub const fn duration_kind<D: Dates>(type_name: &'static str) -> Kind {
    Kind {
        name: "date.duration",
        version: 1,
        type_name,
        family: "date.duration",
        immutable: true,
        repr: |p| Ok(p.downcast_ref::<Duration>().map_or_else(String::new, Duration::text)),
        truthy: |_, p| p.downcast_ref::<Duration>().is_some_and(|d| d.nanos != 0),
        hash: |_, p| p.downcast_ref::<Duration>().map_or(0, |d| mix(d.nanos)),
        eq: |heap, p, other| order::<Duration>(heap, p, other) == Some(Ordering::Equal),
        cmp: Some(order::<Duration>),
        binop: Some(binop::<D>),
        unop: Some(unop::<D>),

        to_i128: None,
        from_i128: None,
        from_digits: None,

/* a time's civil field or a duration's total read by its neutral name */
fn field(heap: &mut HeapPool, v: Val, name: &str) -> Result<Option<Val>, VmErr> { Ok(part_of(heap, v, name)) }

/* a payload ordered by its nanoseconds */
trait Nanos: Any {
    fn nanos(&self) -> i128;
}

impl Nanos for Time {
    fn nanos(&self) -> i128 { self.nanos }
}

impl Nanos for Duration {
    fn nanos(&self) -> i128 { self.nanos }
}

/* the order of a payload against a value holding a payload of its type */
fn order<T: Nanos>(heap: &HeapPool, p: &dyn Any, other: Val) -> Option<Ordering> {
    Some(p.downcast_ref::<T>()?.nanos().cmp(&held::<T>(heap, other)?.nanos()))
}

/* a hash of nanoseconds which equal values share */
fn mix(n: i128) -> u64 { ((n as u64) ^ ((n >> 64) as u64)).wrapping_mul(0x9E37_79B9_7F4A_7C15) }

/* what an operator gives before it is boxed */
enum Out { Time(Time), Span(i128), Float(f64) }

fn binop<D: Dates>(heap: &mut HeapPool, op: BinOp, a: Val, b: Val) -> Result<Option<Val>, VmErr> {
    match compute::<D>(heap, op, a, b)? {
        Some(Out::Time(t)) => time_val::<D>(heap, t).map(Some),
        Some(Out::Span(nanos)) => duration_val::<D>(heap, Duration { nanos }).map(Some),
        Some(Out::Float(f)) => Ok(Some(Val::float(f))),
        None => Ok(None),
    }
}

/* `op` on a time or duration and another operand or none so the engine raises */
fn compute<D: Dates>(heap: &HeapPool, op: BinOp, a: Val, b: Val) -> Result<Option<Out>, VmErr> {
    let (ta, tb) = (held::<Time>(heap, a).copied(), held::<Time>(heap, b).copied());
    let (da, db) = (held::<Duration>(heap, a).map(|d| d.nanos), held::<Duration>(heap, b).map(|d| d.nanos));
    let span = |n: Option<i128>| n.map(Out::Span).ok_or_else(long::<D>);
    let scale = |span: i128, by: Val, divide: bool| number::<D>(heap, by).map(|n| n.and_then(|n| scaled::<D>(span, n, divide)).map(Out::Span));
    Ok(Some(match (op, ta, tb, da, db) {
        (BinOp::Sub, Some(x), Some(y), ..) => span(x.nanos.checked_sub(y.nanos))?,
        (BinOp::Add, Some(t), _, _, Some(d)) | (BinOp::Add, _, Some(t), Some(d), _) => Out::Time(moved::<D>(t, Some(d))?),
        (BinOp::Sub, Some(t), _, _, Some(d)) => Out::Time(moved::<D>(t, d.checked_neg())?),
        (BinOp::Add, _, _, Some(x), Some(y)) => span(x.checked_add(y))?,
        (BinOp::Sub, _, _, Some(x), Some(y)) => span(x.checked_sub(y))?,
        (BinOp::TrueDiv, _, _, Some(_), Some(0)) => return Err(VmErr::ZeroDiv),
        (BinOp::TrueDiv, _, _, Some(x), Some(y)) => Out::Float(x as f64 / y as f64),
        (BinOp::Mul, None, None, Some(x), None) => match scale(x, b, false) { Some(r) => r?, None => return Ok(None) },
        (BinOp::Mul, None, None, None, Some(y)) => match scale(y, a, false) { Some(r) => r?, None => return Ok(None) },
        (BinOp::TrueDiv, None, None, Some(x), None) => match scale(x, b, true) { Some(r) => r?, None => return Ok(None) },
        _ => return Ok(None),
    }))
}

/* a number a span scales by */
enum Num { Int(i128), Float(f64) }

/* the number `v` holds and none for a value that is no number */
fn number<D: Dates>(heap: &HeapPool, v: Val) -> Option<Result<Num, VmErr>> {
    if v.is_float() { return Some(Ok(Num::Float(v.as_float()))); }
    if let Some(i) = as_i128(v, heap) { return Some(Ok(Num::Int(i))); }
    // an int past an i128 takes a span past the range
    heap.is_wide(v).then(|| Err(long::<D>()))
}

/* `span` times or over a number rounded half to even to whole nanoseconds */
fn scaled<D: Dates>(span: i128, n: Num, divide: bool) -> Result<i128, VmErr> {
    let r = match n {
        Num::Int(0) if divide => return Err(VmErr::ZeroDiv),
        Num::Float(f) if divide && f == 0.0 => return Err(VmErr::ZeroDiv),
        Num::Int(i) if divide => rounded(span, i),
        Num::Int(i) => span.checked_mul(i),
        Num::Float(f) if !f.is_finite() => None,
        Num::Float(f) => {
            let (m, e) = split(f);
            if divide { over(span, m, e) } else { times(span, m, e) }
        }
    };
    r.ok_or_else(long::<D>)
}

/* a finite float as a signed odd mantissa and the power of two scaling it */
fn split(f: f64) -> (i128, i32) {
    let bits = f.to_bits();
    let exp = ((bits >> 52) & 0x7ff) as i32;
    let frac = i128::from(bits & ((1 << 52) - 1));
    let (m, e) = if exp == 0 { (frac, -1074) } else { (frac | (1 << 52), exp - 1075) };
    if m == 0 { return (0, 0); }
    let z = m.trailing_zeros();
    let m = m >> z;
    (if bits >> 63 == 1 { -m } else { m }, e + z as i32)
}

/* `span` times `m` times two to the `e` rounded half to even */
fn times(span: i128, m: i128, e: i32) -> Option<i128> {
    let p = span.checked_mul(m)?;
    if p == 0 { return Some(0); }
    if e >= 0 { return p.checked_mul(power(e.unsigned_abs())?); }
    Some(halved(p, e.unsigned_abs()))
}

/* `span` over `m` times two to the `e` rounded half to even */
fn over(span: i128, m: i128, e: i32) -> Option<i128> {
    if span == 0 { return Some(0); }
    if e <= 0 { return rounded(span.checked_mul(power(e.unsigned_abs())?)?, m); }
    // a divisor past an i128 leaves under a nanosecond
    let Some(den) = power(e.unsigned_abs()).and_then(|s| m.checked_mul(s)) else { return Some(0) };
    rounded(span, den)
}

/* two to the `s` while it fits an i128 */
fn power(s: u32) -> Option<i128> { 1i128.checked_shl(s).filter(|&p| p > 0) }

/* `p` over a nonzero `den` rounded half to even */
fn rounded(p: i128, den: i128) -> Option<i128> {
    let (p, den) = if den < 0 { (p.checked_neg()?, den.checked_neg()?) } else { (p, den) };
    if den == 0 { return None; }
    let (q, r) = (p / den, p % den);
    // a remainder of half the divisor goes to the even quotient
    let (twice, whole) = (r.unsigned_abs() * 2, den.unsigned_abs());
    let away = twice > whole || (twice == whole && q % 2 != 0);
    Some(if !away { q } else if p < 0 { q - 1 } else { q + 1 })
}

/* `p` over two to the `s` rounded half to even */
fn halved(p: i128, s: u32) -> i128 {
    if s == 0 { return p; }
    if s >= 128 { return 0; }
    let a = p.unsigned_abs();
    let (q, r, half) = (a >> s, a & ((1u128 << s) - 1), 1u128 << (s - 1));
    let q = (q + u128::from(r > half || (r == half && q & 1 == 1))) as i128;
    if p < 0 { -q } else { q }
}

/* `t` moved by `span` and refused past the years a time reads in */
fn moved<D: Dates>(t: Time, span: Option<i128>) -> Result<Time, VmErr> {
    let t = Time { nanos: span.and_then(|s| t.nanos.checked_add(s)).ok_or_else(far::<D>)?, offset: t.offset };
    if t.valid() { Ok(t) } else { Err(far::<D>()) }
}

/* a time past the years one reads in raised in the runtime's words */
#[cold]
fn far<D: Dates>() -> VmErr { bare::<D>(Fail::TimeRange) }

/* a duration past what one holds raised in the runtime's words */
#[cold]
fn long<D: Dates>() -> VmErr { bare::<D>(Fail::DurationRange) }

fn unop<D: Dates>(heap: &mut HeapPool, op: UnOp, v: Val) -> Result<Option<Val>, VmErr> {
    let Some(&Duration { nanos }) = held::<Duration>(heap, v) else { return Ok(None) };
    let nanos = match op {
        UnOp::Neg => nanos.checked_neg(),
        UnOp::Abs => nanos.checked_abs(),
        // a duration is immutable so plus gives the value itself
        UnOp::Pos => return Ok(Some(v)),
        UnOp::Invert => return Ok(None),
    };
    duration_val::<D>(heap, Duration { nanos: nanos.ok_or_else(long::<D>)? }).map(Some)
}

/* `n` onto `out` as a zigzag varint of seven bits a byte */
fn put(out: &mut Vec<u8>, n: i128) {
    let mut z = ((n << 1) ^ (n >> 127)) as u128;
    loop {
        let byte = (z & 0x7f) as u8;
        z >>= 7;
        if z == 0 { return out.push(byte); }
        out.push(byte | 0x80);
    }
}

/* the zigzag varint at the front of `b` and the bytes after it */
fn take(b: &[u8]) -> Option<(i128, &[u8])> {
    let mut z = 0u128;
    for (i, &byte) in b.iter().enumerate().take(19) {
        z |= u128::from(byte & 0x7f) << (7 * i);
        if byte & 0x80 == 0 { return Some(((z >> 1) as i128 ^ -((z & 1) as i128), b.get(i + 1..)?)); }
    }
    None
}

fn save_time(p: &dyn Any, out: &mut Vec<u8>) {
    if let Some(t) = p.downcast_ref::<Time>() {
        put(out, t.nanos);
        put(out, i128::from(t.offset));
    }
}

/* a saved time checked as a parse checks one */
fn load_time(b: &[u8]) -> Option<Rc<dyn Any>> {
    let (nanos, b) = take(b)?;
    let (offset, b) = take(b)?;
    let t = Time { nanos, offset: i16::try_from(offset).ok()? };
    (b.is_empty() && t.valid()).then(|| Rc::new(t) as Rc<dyn Any>)
}

fn save_duration(p: &dyn Any, out: &mut Vec<u8>) {
    if let Some(d) = p.downcast_ref::<Duration>() { put(out, d.nanos); }
}

fn load_duration(b: &[u8]) -> Option<Rc<dyn Any>> {
    let (nanos, b) = take(b)?;
    b.is_empty().then(|| Rc::new(Duration { nanos }) as Rc<dyn Any>)
}
```

### Kinds the engine asks about

- **The wide kind.** The language's `WIDE` names the kind every int past 48 bits boxes in, made by `lib::num::big::kind::<L>(type_name)`. It is the only kind with `from_i128` and `from_digits`, and its family takes the inline numbers too, so a float and a wide int of one value are equal and share a hash. The engine reads a wide int that fits an `i128` with one compare and no call into the kind.
- **Kinds made on first use.** Lib registers a kind when a native boxes its first value of it. The language's `KINDS` lists those a restore may meet, so it can name them before any value exists, and a host that boxes values of its own names them with `heap.know_kind`.
- **Kinds the engine builds.** The language's `BUILT` names the kinds of the values the engine makes itself, the slice a key of several bounds or a stored slice makes and the one value the ellipsis names, made by `lib::seq::slice::<L>(type_name)` and `lib::types::dots::<L>()`. A read, a delete or a store of `x[a:b:c]` passes its bounds to one op and builds no slice, a store once its code runs in registers, so a slice value exists only where a program keeps one, where an augmented store such as `x[a:b] += v` reads and stores, and where a map takes the slice as its key.
- **Snapshots.** An inline store rides as it is and a shared payload through its kind's codec, and a restore needs a kind of the same name and version. A kind that rejects fails the save with its name while the run still holds a value of it, as [Rust](../03-platforms/04-rust.mdx#snapshots) lists among the results of `save_state`, and the JS host and the CLI sweep a value nothing holds before they save, as `edge::embed::save_swept` does.
- **The plugin wire.** A value crosses to a plugin as the int its kind's `to_i128` gives when its `transfer` is `Copy`, which the wide kind's is. Any other FOREIGN value reaches a plugin as a handle it works on through `edge_op`, as [ABI](../04-reference/06-abi.mdx#op-codes) lists.

### A kind's methods

A kind's methods are natives in the runtime's table, listed under the kind by `edge::natives!` the way methods are listed under an engine kind.

```rust
pub static NATIVES: Natives = edge::natives! {
    language: Mine,
    fns: [IO],
    methods: [Str => [STR]],
    foreign: [POINT => [POINT_METHODS]],
    types: &TYPES,
};
```

`foreign` names each kind by the static `Kind` it registers, so `p.squared()` on a value of `POINT` finds `squared` among `POINT_METHODS` and a value of another kind never does. A read of `p.x` that no method names goes to the kind's `get`. The table keys a kind's methods by the name the kind registers under and each method by its name, so a snapshot names a bound method by both and a table built again finds it by both. A site keeps no foreign method between calls, since the engine kind of every FOREIGN value is the same and only the kind's name tells two tables apart. `tests/names.rs` gives a point kind a method and shows a wide int, a FOREIGN value of another kind, missing it.

## The collector

The collector marks every value a root reaches, then sweeps the slots and the FOREIGN entries nothing reached, with no reference counts, so cycles go too. It runs only at a safe point of the loop, a back-edge or the step of a loop, never while a native's body runs. It runs once the live slots, the allocations since the last sweep or the bytes held pass their thresholds, or once the run holds more than its memory limit, and the first collection waits for 512 live values. [Garbage collection](../05-internals/01-design.mdx#garbage-collection) gives each threshold and every root.

A FOREIGN entry is marked with the slots. The marking walks into the values a `Vals` store holds, and a shared payload's kind names those it keeps in its `trace`. A native that keeps values across a step keeps them in its `Acc` or in a `Cont` that traces them, since nothing else it holds is a root, as [Out and Step](./05-natives.mdx#out-and-step) describes.

## The meter

Every block the allocator hands out carries the meter of the run that paid for it, so a run's memory is counted, not estimated. `Metered<A>` is the global allocator that writes the tag. `edge.wasm` installs it, and a host that runs the crate in its own process installs it too, as [The allocator](./09-embedding.mdx#the-allocator) shows, or a run under a memory limit refuses to start.

- **What a run pays for.** Each heap holds a `Meter`, and while a run runs it is the payer, so its objects, its frames, its caches and its buffers are all charged to it. Freeing a block credits the meter it was charged to, and a block that grows is charged to the payer that grew it. A value a host builds for a run between its steps, an event, an input line or the answer of a call that waited, is charged to that run as well.
- **The limit.** `held` is what the run holds now, garbage since the last sweep included, and `peak` the most it held at once, which the `memory_peak` export reads. A run past its limit collects at its next safe point and raises the runtime's memory error if it still holds more, while a new slot is refused once the run holds twice its limit.
- **The instance.** The programs that share a wasm instance or a thread share one budget too, half the address space by default, which `meter::set_budget` sets. The run whose growth passes it raises while the others go on.
- **Before building.** `room()` is what a result may still take and `reserve(bytes)` refuses a result past it before a byte is built, as [The budget](./05-natives.mdx#the-budget) describes.

The type count of [Tokens or a front end](../01-get-started/04-book/02-tokens.mdx#one-job-both-ways) reads the hour a chunk at a time and keeps only its counts, so it prints its five lines under a limit of 1 MB.

```text
$ edge run --ops 10000000000 --memory 1 types.mini
 64617  PushEvent
 10350  CreateEvent
  3198  PullRequestEvent
  3072  DeleteEvent
  1368  IssueCommentEvent
```

The same count over the hour held whole keeps every chunk, joins them and splits the result, so it holds the 89.4 MB of the hour about three times over.

```edge
import net

HOUR = 'https://data.gharchive.org/2026-10-01-15.json.gz'

// every chunk of the hour kept before a line of it is cut
parts = []
r = net.request('GET', HOUR, nil, nil, 'gzip')
chunk = net.read(r)
while chunk is !nil:
    parts.append(chunk)
    chunk = net.read(r)
body = b''.join(parts)

counts = {}
for line in body.split(b'\n')[:-1]:
    at = line.find(b'"type":"') + 8
    kind = line[at:line.find(b'"', at)].decode()
    counts[kind] = counts.get(kind, 0) + 1
print(len(body), counts['PushEvent'])
```

Under the CLI's default limit of 256 MB the run stops at the split, and a limit of 512 MB lets it finish.

```text
$ edge run --ops 10000000000 whole.mini
error: MemoryError: memory limit
   --> whole.mini:15:1
   |
15 | for line in body.split(b'\n')[:-1]:
   | ^

$ edge run --ops 10000000000 --memory 512 whole.mini
89367842 64617
```
