# Functions

Functions are values. Pass them, return them, store them and compose them.

## def

```edge-python
def add(a, b):
  return a + b

print(add(3, 4))
```

```output
7
```

### Default arguments

```edge-python
def greet(name, greeting="Hello"):
  return f"{greeting}, {name}!"

print(greet("world"))
print(greet("world", "Hi"))
```

```output
Hello, world!
Hi, world!
```

### Keyword arguments

```edge-python
def f(x, y, z):
  return x * 100 + y * 10 + z

print(f(1, 2, 3))
print(f(x=1, z=3, y=2))
print(f(1, z=3, y=2))
```

```output
123
123
123
```

### Variadic parameters

A function without `*args` rejects extra positional arguments with `TypeError`. The two variadic forms collect what the declared parameters do not take.

- `*args` collects extra positional arguments into a tuple.
- `**kwargs` collects extra keyword arguments into a dict.

```edge-python
def total(*nums):
  return sum(nums)

print(total(1, 2, 3))
print(total(*[10, 20, 30]))
```

```output
6
60
```

```edge-python
def opts(**kwargs):
  return sorted(kwargs.items())

print(opts(host="api", port=443))
```

```output
[('host', 'api'), ('port', 443)]
```

### Keyword-only parameters

A bare `*` marks the following parameters as keyword-only. They must be passed by name. A positional argument that would reach them raises `TypeError`.

```edge-python
def connect(host, *, port=80, secure=False):
  return f"{host}:{port} secure={secure}"

print(connect("api"))
print(connect("api", port=443, secure=True))

try:
  connect("api", 443) # positional can't fill a keyword-only param
except TypeError:
  print("rejected")
```

```output
api:80 secure=False
api:443 secure=True
rejected
```

### Argument unpacking at the call site

```edge-python
def f(a, b, c):
  return a + b + c

print(f(*[1, 2, 3]))
print(f(*[1, 2], 3))
print(f(**{"a": 1, "b": 2, "c": 3}))
print(f(1, **{"b": 2, "c": 3}))
```

```output
6
6
6
6
```

## lambda

A lambda is an anonymous function. Its body is a single expression.

```edge-python
double = lambda x: x * 2
print(double(21))

add = lambda a, b: a + b
print(add(3, 4))

# With defaults
greet = lambda name, msg="Hi": f"{msg}, {name}"
print(greet("world"))
```

```output
42
7
Hi, world
```

## Functions as values

A function can sit in a list or a dict, travel as an argument and come back as a result.

```edge-python
ops = [abs, hex, str]
print([f(-3) for f in ops])
```

```output
[3, '-0x3', '-3']
```

A dict of functions replaces a switch statement.

```edge-python
handlers = {
  "add": lambda a, b: a + b,
  "mul": lambda a, b: a * b,
  "max": max,
}

print(handlers["add"](3, 4))
print(handlers["mul"](3, 4))
print(handlers["max"](3, 4))
```

```output
7
12
4
```

A higher-order function takes or returns a function.

```edge-python
def apply(f, x):
  return f(x)

print(apply(lambda n: n * n, 5))
print(apply(abs, -10))

def make_adder(n):
  return lambda x: x + n

add5 = make_adder(5)
add10 = make_adder(10)
print(add5(3))
print(add10(3))
```

```output
25
10
8
13
```

## Closures

An inner function captures the variables of its enclosing scope by reference.

```edge-python
def counter():
  count = 0
  def step():
    nonlocal count
    count += 1
    return count
  return step

tick = counter()
print(tick())
print(tick())
print(tick())
```

```output
1
2
3
```

Capture is by reference. Every lambda made in a loop sees the same loop variable. Bind the current value through a default argument.

```edge-python
def make_adders(n):
  return [lambda x, i=i: x + i for i in range(n)]

add0, add1, add2 = make_adders(3)
print(add0(10), add1(10), add2(10))
```

```output
10 11 12
```

### global and nonlocal

Assignment inside a function creates a local unless declared otherwise.

- `nonlocal name` rebinds the variable of the nearest enclosing function. The `counter` closure above relies on it. A `nonlocal` that no enclosing function binds, or one at module level, fails to compile.
- `global name` rebinds the module-level variable.

```edge-python
total = 0

def bump(n):
  global total
  total += n

bump(3)
bump(4)
print(total)
```

```output
7
```

Reading an outer variable needs no declaration. Only rebinding does.

```edge-python
BASE = 10

def add_base(n):
  return n + BASE

print(add_base(5))
```

```output
15
```

## Recursion

```edge-python
def factorial(n):
  if n < 2:
    return 1
  return n * factorial(n - 1)

print(factorial(10))
```

```output
3628800
```

```edge-python
# Mutual recursion
def is_even(n):
  return True if n == 0 else is_odd(n - 1)

def is_odd(n):
  return False if n == 0 else is_even(n - 1)

print(is_even(10), is_odd(10))
```

```output
True False
```

Recursion has no fixed depth. Its frames may take a share of the memory limit, as [Sandboxed execution](/docs/edge-python/reference/limits-and-errors#sandboxed-execution) describes. A pure function called again with the same immutable positional arguments can return a cached result without running its body. [Design](/docs/edge-python/internals/design#key-mechanisms) lists when the cache applies.

## Generators

A function containing `yield` produces its sequence lazily. Pull values with `next()` or iterate with `for`.

```edge-python
def squares(n):
  for i in range(n):
    yield i * i

for x in squares(5):
  print(x)
```

```output
0
1
4
9
16
```

```edge-python
def gen():
  yield 1
  yield 2

g = gen()
print(next(g))
print(next(g))
```

```output
1
2
```

```edge-python
# Materialize a generator
def naturals(limit):
  n = 1
  while n <= limit:
    yield n
    n += 1

print(list(naturals(5)))
```

```output
[1, 2, 3, 4, 5]
```

### yield from

`yield from` delegates to another generator or any iterable.

```edge-python
def nums():
  yield from range(3)
  yield from [10, 20]

print(list(nums()))
```

```output
[0, 1, 2, 10, 20]
```

`yield from` is also an expression. It evaluates to the return value of the subgenerator. A generator can pass a result back to the one that delegates to it.

```edge-python
def sub():
  yield 1
  yield 2
  return 'done'

def outer():
  result = yield from sub()
  print('returned', result)

print(list(outer()))
```

```output
returned done
[1, 2]
```

> [!NOTE]
> Generators are one-way producers. `gen.send(value)`, `gen.throw(exc)` and `gen.close()` are not exposed. For flow in both directions, use the [cooperative scheduler](/docs/edge-python/language/async) and pass values through arguments and return values.

## Generator expressions

A generator expression is a generator written inline. It computes each value when asked and can be read once.

```edge-python
print(sum(x * x for x in range(5)))
squares = (x * x for x in range(3))
print(next(squares), list(squares), list(squares))
```

```output
30
0 [1, 4] []
```

## Decorators

A decorator wraps another callable. It applies to functions and to [classes](/docs/edge-python/language/classes#class-decorators).

```edge-python
def trace(f):
  def wrapped(*args):
    print(f"calling with {args}")
    return f(*args)
  return wrapped

@trace
def add(a, b):
  return a + b

print(add(3, 4))
```

```output
calling with (3, 4)
7
```

Stacked decorators apply bottom-up.

```edge-python
def double_result(f):
  return lambda *a: f(*a) * 2

def add_one(f):
  return lambda *a: f(*a) + 1

@double_result
@add_one
def base(x):
  return x

# base(5) -> add_one -> 6 -> double_result -> 12
print(base(5))
```

```output
12
```

A parameterized decorator is a factory. The outer function takes the decorator arguments and returns the actual decorator. The wrapped function captures both scopes.

```edge-python
def repeat(n):
  def decorator(fn):
    def wrapped(x):
      for i in range(n):
        fn(x)
    return wrapped
  return decorator

@repeat(3)
def greet(name):
  print(f"hi {name}")

greet("world")
```

```output
hi world
hi world
hi world
```

## Function attributes

Functions carry writable attributes, like any object. Decorators use them for metadata.

- `getattr`, `hasattr`, `setattr` and `delattr` work on them.
- An assigned `__name__` wins over the declared one.

```edge-python
def sma(source, length):
  return sum(source) / length

sma.window = 10
print(sma.window)
print(getattr(sma, "missing", "n/a"))

def tag(fn):
  fn.tagged = True
  return fn

@tag
def step():
  pass
print(step.tagged)
```

```output
10
n/a
True
```
