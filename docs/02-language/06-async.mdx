# Async

`async def` makes a coroutine function. Calling it builds a coroutine and runs none of its body. A coroutine runs only while something drives it, an `await` inside another coroutine or a driver that calls `send`.

- The engine implements the coroutine protocol of Python 3.15, with no scheduler of its own.
- `asyncio` arrives with the standard library, written in Python over this protocol, so the event loop is one more module.
- Until then a small driver runs coroutines. This one steps each coroutine in turn until all of them return.

```edge-python
class Tick:
  def __await__(self):
    yield "tick"

async def worker(name, n):
  for i in range(n):
    await Tick()
    print(name, i)
  return name

def run(*coros):
  results = [None] * len(coros)
  ready = list(enumerate(coros))
  while ready:
    i, coro = ready.pop(0)
    try:
      coro.send(None)
      ready.append((i, coro))
    except StopIteration as e:
      results[i] = e.value
  return results

print(run(worker("a", 2), worker("b", 2)))
```

```output
a 0
b 0
a 1
b 1
['a', 'b']
```

## await

`await x` runs `x` in place and gives what it returns, the way `yield from` runs a generator.

- `x` is a coroutine, or an object whose `__await__` returns an iterator.
- What the innermost awaitable yields passes up to the driver of the outermost coroutine, and what the driver sends comes back down to it.
- An error raised inside reaches the `await` as if the call had raised it.
- `await` belongs only in an `async def`. Anywhere else, the top of a module included, it is a `SyntaxError`.

```edge-python
async def square(n):
  return n * n

async def total():
  return await square(3) + await square(4)

coro = total()
print(type(coro).__name__)
try:
  coro.send(None)
except StopIteration as e:
  print(e.value)
```

```output
coroutine
25
```

## send, throw and close

A coroutine answers the methods a generator does. Each one reaches the awaitable the coroutine waits on first, so a `throw` at the outer coroutine raises at the innermost `await`.

- `send(value)` resumes the coroutine, `send(None)` starts it.
- `throw(exc)` raises `exc` where it waits, and `close()` raises `GeneratorExit` there.
- `StopIteration` carries the value the coroutine returned.
- `cr_await` is the awaitable it waits on, with `cr_running`, `cr_suspended` and `cr_code` beside it.
- A coroutine runs once. Driving one that ended raises `RuntimeError: cannot reuse already awaited coroutine`.

```edge-python
class Wait:
  def __await__(self):
    return (yield "waiting")

async def inner():
  try:
    return await Wait()
  except KeyError:
    return "recovered"

async def outer():
  return "outer got " + await inner()

c = outer()
print(c.send(None))
print(type(c.cr_await).__name__)
try:
  c.throw(KeyError)
except StopIteration as e:
  print(e.value)
```

```output
waiting
coroutine
outer got recovered
```

A cancellation is a `throw` of the exception the loop chose. The coroutine may catch it, run its `finally` blocks and go on. [Functions](/docs/edge-python/language/functions#send-throw-and-close) covers the same methods on generators.

## Async generators

An `async def` that yields is an async generator. It may `await` between its yields.

- `async for` steps it, and so does a comprehension such as `[x async for x in gen()]`.
- `anext(g[, default])` and `g.asend(value)` give an awaitable of the next item, `g.athrow(exc)` raises inside it and `g.aclose()` closes it.
- `aiter(x)` gives the async iterator of `x`. A class takes part by defining `__aiter__` and an `async def __anext__` that raises `StopAsyncIteration` at its end.
- `async for` takes an `else` block, which runs when the loop ends without `break`.

```edge-python
async def countdown(n):
  while n > 0:
    yield n
    n -= 1

async def main():
  async for x in countdown(3):
    print(x)
  print([x async for x in countdown(2)])
  g = countdown(5)
  print(await anext(g), await g.asend(None))
  await g.aclose()
  print(await anext(g, "closed"))

try:
  main().send(None)
except StopIteration:
  pass
```

```output
3
2
1
[2, 1]
5 4
closed
```

## async with

`async with` awaits `__aenter__` on entry and `__aexit__` on every exit. A truthy result of `__aexit__` swallows the exception, as with `with`.

```edge-python
class Session:
  async def __aenter__(self):
    print("open")
    return self
  async def __aexit__(self, kind, exc, tb):
    print("close", kind.__name__ if kind else None)
    return True

async def main():
  async with Session():
    raise ValueError("swallowed")
  return "done"

try:
  main().send(None)
except StopIteration as e:
  print(e.value)
```

```output
open
close ValueError
done
```

## Host waits

The module body runs as a coroutine the host drives, which is how a run suspends to the host and resumes later.

- `receive()` and a host call that waits, at the top of the module or in a plain function it calls, suspend the whole run until the host answers.
- A generator a `for` loop steps may wait too, the loop parks with it.
- A generator or a coroutine stepped by `next` or `send` cannot suspend to the host. A wait inside one raises `RuntimeError`.

## receive

`receive()` pops the oldest message of the event queue of the host. When the queue is empty it suspends the run until the host pushes one. Messages are strings.

- [JavaScript](/docs/edge-python/platforms/javascript) shows how a page or a worker pushes them.
- A suspended `receive()` is a natural pause point for [snapshots](/docs/edge-python/language/snapshots).
- Inside an [actor pool](/docs/edge-python/platforms/actors) its counterpart `send(group, body)` hands a string to another group.

```python
while True:
  msg = receive() # suspends until the host pushes an event
  print(f"got {msg}")
```

[Rust](/docs/edge-python/platforms/rust) shows the loop that resumes a run for a host of your own.

## asyncio

`asyncio` comes with the standard library, compiled from its Python source.

- `asyncio.run`, `asyncio.gather`, `asyncio.sleep`, `asyncio.wait_for` and `Task.cancel` run over the protocol above, unchanged.
- A `CancelledError` is an ordinary exception the task may catch.
- A host call that waits inside a task is the part the engine still has to carry through `send`.

> [!CARDS]
> - `camera` [Snapshots](/docs/edge-python/language/snapshots) Freeze a paused run to a blob and resume it later.
> - `users` [Actors](/docs/edge-python/platforms/actors) Run many programs side by side as message-passing tasks.
