# Rust

A Rust program links the engine and a runtime as crates and runs programs in its own process, with no `.wasm` in between. The examples on this page embed Lox through the `lox` crate. A runtime of your own exposes the same `RUNTIME` and `FRONT`, as [Build a runtime](./02-runtime.mdx) shows.

```toml
[dependencies]
edge = { git = "https://github.com/dylan-sutton-chavez/edge-lang", branch = "main" }
lox = { git = "https://github.com/dylan-sutton-chavez/edge-lang", branch = "main" }
```

## Run a program

`edge::code::compile` parses a source through a runtime's front and gives the chunk with every diagnostic. `VM::with_runtime` boots a machine over it, and `run` runs it to the end.

```rust standalone_crate
use edge::embed::{Limits, VM};

// the memory limit counts what this allocator hands out
edge::allocator!();

fn main() {
    let src = "fun square(n) {\n    return n * n;\n}\n\nfor (var n = 0; n < 4; n = n + 1) print square(n);\n";
    let (chunk, errors) = edge::code::compile(&lox::FRONT, src);
    assert!(errors.is_empty(), "{}", edge::code::Diagnostic::render_all(&errors, src, Some("main.lox")));
    let mut vm = VM::with_runtime(&lox::RUNTIME, &chunk, Limits::sandbox());
    vm.run().expect("the program runs");
    assert_eq!(vm.output_text(), "0\n1\n4\n9\n");
}
```

The binary installs `edge::allocator!()` once, since a VM whose limits cap memory refuses to run without the meter. A VM keeps what the program prints as lines in `output`, and `output_text()` joins them. Set `vm.print_hook = Some(f)` with a `fn(&str)` to take each text as it is written instead.

| Call | Does |
|---|---|
| `VM::with_runtime(&RUNTIME, &chunk, limits)` | Boots a machine. The chunk outlives it |
| `run()` | Runs the program, or carries a parked run on |
| `push_event(text)` | Hands an event to a run waiting in `receive()`, or queues it |
| `inject_host_result_by_id(id, value)` | Answers a host call the run waits on |
| `call_export(name, args)` | Calls a function the program defined, after `run` |
| `set_preempt_interval(n)` | Stops the run every `n` loop back-edges, never at 0 |
| `reset_budget(ops)` | Gives the run a fresh op budget |
| `set_input(lines)` | The lines `input()` reads |
| `error_text(&e)`, `report_error(&e, src, path)` | An error as one line, or as the whole report with its source line |
| `display(v)`, `repr(v)` | A value as the runtime prints it |
| `memory()`, `memory_peak()` | What the run holds now, and the most it held |

## Events

A run that calls `receive()` with nothing queued parks, and `run` returns `VmErr::HostYield(SchedulerStatus::PendingEvent)`. The host pushes an event and calls `run` again, and the run goes on from where it stopped.

```rust standalone_crate
use edge::embed::{Limits, SchedulerStatus, VM};
use edge::value::VmErr;

edge::allocator!();

fn main() {
    let src = "var words = \"\";\nvar m = receive();\nwhile (m != \"stop\") {\n    words = words + m;\n    m = receive();\n}\nprint \"got \" + words;\n";
    let (chunk, _) = edge::code::compile(&lox::FRONT, src);
    let mut vm = VM::with_runtime(&lox::RUNTIME, &chunk, Limits::sandbox());
    let mut events = ["ab", "cd", "stop"].into_iter();
    loop {
        match vm.run() {
            Ok(_) => break,
            Err(VmErr::HostYield(SchedulerStatus::PendingEvent)) => vm.push_event(events.next().unwrap()).unwrap(),
            Err(e) => panic!("{}", vm.report_error(&e, src, Some("main.lox"))),
        }
    }
    assert_eq!(vm.output_text(), "got abcd\n");
}
```

## Host functions

An import, `import("name")` in Lox, is answered by a `Resolver`. Answering with `Resolved::Code` serves a module's source, and `Resolved::Native` serves Rust functions. A function that returns `VmErr::HostCallDeferred` parks the run with `PendingHostCall`, and the host answers it later by id, counting from 0 in the order the run made the calls.

```rust standalone_crate
use edge::embed::{Limits, NativeBinding, Resolved, Resolver, SchedulerStatus, VM};
use edge::targets::native::Script;
use edge::value::{HeapPool, Val, VmErr};

edge::allocator!();

// a Lox number is a double
fn double(_: &mut HeapPool, args: &[Val], _kw: Option<Val>) -> Result<Val, VmErr> {
    Ok(Val::float(args[0].as_float() * 2.0))
}

// answered later, the way a host waits on a network reply
fn fetch(_: &mut HeapPool, _args: &[Val], _kw: Option<Val>) -> Result<Val, VmErr> {
    Err(VmErr::HostCallDeferred)
}

struct Host;

impl Resolver for Host {
    fn resolve(&mut self, spec: &str) -> Result<Resolved, String> {
        match spec {
            "host" => Ok(Resolved::Native {
                bindings: vec![NativeBinding::from_fn("double", double), NativeBinding::from_fn("fetch", fetch)],
                classes: vec![],
                consts: vec![],
                canonical: "host".into(),
            }),
            "util" => Ok(Resolved::Code { src: "fun greet(n) {\n    return \"hi \" + n;\n}\n".into(), canonical: "util".into() }),
            _ => Err(format!("no module '{spec}'")),
        }
    }
}

fn main() {
    let src = "var host = import(\"host\");\nvar util = import(\"util\");\nprint text(host.double(21)) + \" \" + util.greet(\"ana\");\nprint host.fetch() + 1;\n";
    let script = Script::compile(&lox::FRONT, "main.lox", src.into(), Box::new(Host)).unwrap();
    let mut vm = VM::with_runtime(&lox::RUNTIME, &script.chunk, Limits::sandbox());
    assert!(matches!(vm.run(), Err(VmErr::HostYield(SchedulerStatus::PendingHostCall))));
    assert!(vm.inject_host_result_by_id(0, Val::float(41.0)));
    vm.run().unwrap();
    assert_eq!(vm.output_text(), "42 hi ana\n42\n");
}
```

## Exported functions

Once `run` has bound the program's names, `call_export` calls one of its functions with values the host built.

```rust standalone_crate
use edge::embed::{Limits, VM};
use edge::value::Val;

edge::allocator!();

fn main() {
    let (chunk, _) = edge::code::compile(&lox::FRONT, "fun area(w, h) {\n    return w * h;\n}\n");
    let mut vm = VM::with_runtime(&lox::RUNTIME, &chunk, Limits::sandbox());
    vm.run().unwrap();
    let got = vm.call_export("area", &[Val::float(6.0), Val::float(7.0)]).unwrap();
    assert_eq!(vm.display(got), "42");
}
```

## Snapshots

A parked run freezes to a blob with `edge::embed::save` and thaws on a fresh VM booted from the same program with `edge::embed::restore`, on this host or another. The blob holds the heap, every frame and the input not yet read.

```rust standalone_crate
use edge::embed::{self, Limits, SchedulerStatus, VM};
use edge::value::VmErr;

edge::allocator!();

fn main() {
    let src = "var seen = \"\";\nvar m = receive();\nwhile (m != \"stop\") {\n    seen = seen + m;\n    m = receive();\n}\nprint seen;\n";
    let (chunk, _) = edge::code::compile(&lox::FRONT, src);
    let mut vm = VM::with_runtime(&lox::RUNTIME, &chunk, Limits::sandbox());
    assert!(matches!(vm.run(), Err(VmErr::HostYield(SchedulerStatus::PendingEvent))));
    vm.push_event("a").unwrap();
    assert!(matches!(vm.run(), Err(VmErr::HostYield(SchedulerStatus::PendingEvent))));
    let blob = embed::save(&vm, src, "main.lox").unwrap();
    drop(vm);

    // a new machine over the same program picks up where the first one parked
    let mut later = VM::with_runtime(&lox::RUNTIME, &chunk, embed::limits_of(&blob).unwrap());
    embed::restore(&mut later, &blob).unwrap();
    later.push_event("b").unwrap();
    later.push_event("stop").unwrap();
    later.run().unwrap();
    assert_eq!(later.output_text(), "ab\n");
}
```

`set_preempt_interval(n)` parks a run that never waits with `SchedulerStatus::Preempted`, so a long loop can be saved too. `embed::entry_of(&blob)` gives back the script name the blob was saved under.

## A native binary

`edge::targets::native` holds a whole host: `Script::read` compiles a file and reads its relative imports beside it, `boot` gives a VM that prints to stdout and reads stdin, and `main` puts them together. This is the whole `main.rs` of the `lox` binary the book's suite runs on.

```rust no_run standalone_crate
use edge::embed::Limits;
use std::process::ExitCode;

edge::allocator!();

// runs the Lox file its first argument names
fn main() -> ExitCode {
    edge::targets::native::main(&lox::RUNTIME, &lox::FRONT, Limits::sandbox())
}
```

`main` exits with the statuses the runtime's `Descriptor` gives in `statuses`, and words compile errors through its `diagnosed` when it sets one, so `lox` reports as the book's interpreters do. On a file holding `var x = = 2;` it writes this to stderr and exits with 65:

```text
[line 1] Error at '=': Expect expression.
```

A native script loads no URL and no plugin. The `edge` CLI and the JS host serve both.
