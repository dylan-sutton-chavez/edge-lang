# Build a runtime

A runtime is a crate that gives the engine four pieces.

| Piece | Type | Says |
|---|---|---|
| Token table | `interpreter::lexer::Syntax` through `Spelling` | How a program is written |
| Natives | `interpreter::lang::Natives` from `interpreter::natives!` | The functions a program can call |
| Language | `interpreter::lang::Language` | The rules, the names of types and errors, and how values print |
| Runtime | `interpreter::lang::Runtime::of::<L>()` | The one value every host boots, checked when the crate builds |

The parser has one grammar and the token table only spells it. `!` and `not` can both be the `Not` token, and a block can open with `{`, with a colon and an indent, or with a word such as `do`. Every spelling of a construct compiles to the same bytecode.

## Example

`tally` uses braces for blocks, `let` for a first store and two natives of `interpreter::lib`.

```rust standalone_crate
use interpreter::embed::{Limits, VM};
use interpreter::lang::{Cx, Descriptor, Front, Language, Mode, Names, Native, Natives, Overflow, Policy, Runtime};
use interpreter::lexer::TokenType as T;
use interpreter::lexer::{index, operators, Binding, Blocks, Comments, Continuation, Ends, Escapes, Keywords, Numbers, Quote, Shapes, Spelling, Strings, Suffix, Syntax, TokenType, Unicode, Unknown, Zeros};
use interpreter::value::{Val, VmErr};

// every run meters what it allocates so its memory limit holds
interpreter::allocator!();

pub struct Tally;

const WORDS: &[(&str, TokenType)] = &[
    ("let", T::Let), ("fn", T::Fn), ("return", T::Return), ("if", T::If), ("else", T::Else),
    ("for", T::For), ("in", T::In), ("true", T::True), ("false", T::False), ("nil", T::Nil),
];
const SYMBOLS: &[(&str, TokenType)] = &[
    ("(", T::ParenOpen), (")", T::ParenClose), ("[", T::BracketOpen), ("]", T::BracketClose),
    ("{", T::BraceOpen), ("}", T::BraceClose), ("{", T::BlockOpen), ("}", T::BlockClose),
    (",", T::Comma), ("==", T::EqualEqual), ("<", T::Less),
    ("=", T::Equal), ("+", T::Plus), ("-", T::Minus), ("*", T::Star),
];
static OPERATORS: [[TokenType; 4]; 128] = operators(SYMBOLS);
static KEYWORDS: Keywords = index(WORDS);
// each operator's left and right power, a zero left power marks a prefix
const LADDER: &[(TokenType, u8, u8)] = &[
    (T::EqualEqual, 1, 2), (T::Less, 1, 2), (T::Plus, 3, 4), (T::Minus, 3, 4), (T::Star, 5, 6), (T::Minus, 0, 7),
];

impl Spelling for Tally {
    const SYNTAX: Syntax = Syntax {
        name: "tally", extension: "tly", words: WORDS, symbols: SYMBOLS, operators: &OPERATORS, keywords: &KEYWORDS,
        precedence: LADDER, chained: false, blocks: Blocks::Braces, ends: Ends::Newline,
        comments: Comments { line: &["#"], block: None, nested: false },
        strings: Strings {
            quotes: &[Quote { byte: b'"', multiline: false, triple: false }],
            prefixes: &[], any_case: false, hashes: false, adjacent: false, newlines: false,
            escapes: Escapes { simple: &[(b'n', '\n')], hex: false, unicode: Unicode::Fixed, octal: false, line_join: false, unknown: Unknown::Refuse, refused: &[] },
        },
        interp: None,
        numbers: Numbers { radixes: &[], separator: None, zeros: Zeros::Refused, leading_dot: false, trailing_dot: false, exponent: false, suffix: Suffix::Refused },
        continuation: Continuation { join: None, operator: true },
        shapes: Shapes { binding: Binding::Required, ..Shapes::CORE },
        soft: &[],
        bom: false,
    };
    const NATIVES: &'static Natives = &NATIVES;
}

// two kernels of lib under the names a program calls
const TABLE: &[Native] = &interpreter::lib::table![Tally; "print" => interpreter::lib::io::print, "len" => interpreter::lib::seq::len];

static NATIVES: Natives = interpreter::natives! { language: Tally, fns: [TABLE], methods: [], types: &[] };

// lib words failures and renders values with its defaults
static TREE: interpreter::lib::lang::Tree = interpreter::lib::lang::Tree::of::<Tally>();
impl interpreter::lib::Lang for Tally {
    const TREE: &'static interpreter::lib::lang::Tree = &TREE;
}
impl interpreter::lib::fmt::render::Style for Tally {}

impl Language for Tally {
    const VERSION: u32 = 1;
    // the engine's rules, but an int too wide to box raises instead of growing
    const POLICY: Policy = Policy { int_overflow: Overflow::Error, ..Policy::ENGINE };
    const NATIVES: &'static Natives = &NATIVES;
    const NAMES: &'static Names = &Names::PLAIN;
    const FRONT: Front = FRONT;
    const DESCRIPTOR: &'static Descriptor = &DESCRIPTOR;
    type Ops = ();

    fn show(cx: &mut Cx<'_, '_>, v: Val, mode: Mode) -> Result<String, VmErr> {
        interpreter::lib::fmt::render::hook::<Tally>(cx, v, mode)
    }
}

pub const FRONT: Front = Front::spelled::<Tally>();
pub const DESCRIPTOR: Descriptor = Descriptor { language: "tally", extension: "tly", entries: &["main.tly"], ..Descriptor::NONE };
pub static RUNTIME: Runtime = Runtime::of::<Tally>();

// the exports of tally.wasm and of its native library, built only for the exports feature
#[cfg(feature = "exports")]
interpreter::web_exports!(RUNTIME);

fn main() {
    let src = "let total = 0\nfor n in [1, 2, 3] {\n    total = total + n * n\n}\nprint(\"squares\", len([1, 2, 3]), total)\n";
    let (chunk, errors) = interpreter::code::compile(&FRONT, src);
    assert!(errors.is_empty(), "{}", interpreter::code::Diagnostic::render_all(&errors, src, Some("main.tly")));
    let mut vm = VM::with_runtime(&RUNTIME, &chunk, Limits::sandbox());
    vm.run().expect("the program runs");
    assert_eq!(vm.output_text(), "squares 3 14\n");
}
```

Its `Cargo.toml` turns on only the two modules it names.

```toml
[dependencies]
interpreter = { version = "1", default-features = false, features = ["std", "io", "seq"] }
```

## Token table

| Field | Sets |
|---|---|
| `words`, `symbols` | Each reserved word and symbol and its token. A space joins a phrase, as in `("else if", T::ElseIf)`. A braces table lists `{` as both `BraceOpen` and `BlockOpen` |
| `operators`, `keywords` | Lookups built when the crate compiles, with `operators(SYMBOLS)` and `index(WORDS)` |
| `precedence`, `chained` | Binding powers, and whether `a < b < c` chains |
| `blocks`, `ends` | `Indent`, `Braces` or `Words { implicit }`, and whether a statement ends at a line end, a semicolon or either |
| `comments`, `strings`, `interp`, `numbers` | Comments, quotes and escapes, interpolated strings and number literals |
| `shapes` | Optional pieces such as lambdas, comprehensions, slices, decorators, `match` arms, ranges, `let` and a [grammar](./03-grammar.mdx). `Shapes::CORE` turns on all of them but `let`, arms, ranges and a grammar |

A language the parser cannot read implements `interpreter::lang::Front` itself and writes the same bytecode through `interpreter::code::Builder`. Lox in `examples/lox` does this.

## Natives

`interpreter::lib` holds ready natives, one module per feature.

| Module | Holds |
|---|---|
| `io` | `print`, `input`, `send`, `receive`, `exit` |
| `text`, `bytes`, `spec` | Text and bytes methods, codecs and format specs |
| `num` | Ints of any size, floats, rounding and hashing |
| `seq`, `iter`, `map`, `set` | Lists, iterators, folds, sorting, maps and sets |
| `data` | JSON, CSV and line reading |
| `date` | Times and durations |
| `reflect`, `types` | Attributes, `isinstance`, `type` and which errors a handler catches |

`interpreter::lib::table!` gives each native the name a program calls it by, as in `"json" => interpreter::lib::data::json::read`. In `interpreter::natives!`, `methods` adds methods by kind, such as `text.upper`, and `types` names the types a program can test against. A native that `interpreter::lib` lacks is an `interpreter::lang::Native` you write, a function of a `Cx` and its arguments that returns a value.

## Language

| Item | Default | Sets |
|---|---|---|
| `POLICY` | `Policy::ENGINE` | Integer overflow and division, what is false, negative indexes, iteration and the recursion limit. Ints that grow without bound also need `WIDE`, which `interpreter::lib::num::big::kind` gives |
| `NAMES` | `Names::PLAIN` | The names of the engine's types and error classes in your language |
| `show`, `format` | none | How a value prints, usually `interpreter::lib::fmt::render::hook` and `interpreter::lib::fmt::spec::hook` |
| `handles` | none | Which errors a handler catches, usually `interpreter::lib::types::match_exc` |
| `DESCRIPTOR` | `Descriptor::NONE` | What tools read, such as the file extension, the entry files and the test suffix |

`Runtime::of::<L>()` runs in a `static`, so a policy that does not hold together fails the build.

## The .wasm of a runtime

The same crate builds the module the JS host and the CLI load, and the native library the CLI loads in its place. `interpreter::web_exports!(RUNTIME)`, as in the example, writes its exports behind a feature of its own, here `exports`.

```toml
[features]
exports = ["interpreter/runtime", "interpreter/perms"]
```

```bash
cargo rustc --release --target wasm32-unknown-unknown --lib --crate-type cdylib --no-default-features --features exports
```

The native library takes the same exports with a context of its own for each run, so actors run it in parallel with no lock between them. It needs `std` and a profile where a panic unwinds, so the CLI catches one as an error of the run.

```toml
[profile.native]
inherits = "release"
panic = "unwind"
```

```bash
cargo rustc --profile native --lib --crate-type cdylib --features exports
```

The CLI runs it outside the sandbox, as [wasm or native](./06-cli.mdx#wasm-or-native) says.

## Lox

`examples/lox` is a whole runtime and the one `interpreter.wasm` is built from. Its token table scans through the engine's lexer, and its own front parses and resolves a program as the book's compiler does, with the book's error messages. Every number is a double, only `nil` and `false` are false, and fields live on instances only. A native binary exits with 65 after a compile error and 70 after a run error, as the book's does. `cargo test -p interpreter-lox` runs the book's suite on it.
