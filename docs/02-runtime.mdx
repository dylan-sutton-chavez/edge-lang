# Build a runtime

This page builds a runtime, from its token table to its `.wasm`. A runtime is a crate that gives the engine four pieces.

| Piece | Type | Says |
|---|---|---|
| Token table | `interpreter::lexer::Syntax` through `Spelling` | How a program is written |
| Natives | `interpreter::lang::Natives` from `interpreter::natives!` | The functions a program can call |
| Language | `interpreter::lang::Language` | The rules, the names of types and errors, and how values print |
| Runtime | `interpreter::lang::Runtime::of::<L>()` | The one value every host boots, checked when the crate builds |

The parser has one grammar and the token table only spells it. `!` and `not` can both be the `Not` token, and a block can open with `{`, a colon and an indent, or a word such as `do`. Every spelling compiles to the same bytecode.

## Example

`tally` uses braces for blocks, `let` for a first store and two natives of `interpreter::lib`.

```rust standalone_crate
use interpreter::{Limits, VM};
use interpreter::lang::{Descriptor, Front, Language, Names, Native, Natives, Overflow, Policy, Runtime};
use interpreter::lexer::TokenType as T;
use interpreter::lexer::{Binding, Blocks, Comments, Continuation, Ends, Escapes, Keywords, Numbers, Quote, Shapes, Spelling, Strings, Suffix, Syntax, TokenType, Unicode, Unknown, Zeros, index, operators};

// every run meters what it allocates so its memory limit holds
interpreter::allocator!();

pub struct Tally;

const WORDS: &[(&str, TokenType)] = &[
    ("let", T::Let), ("fn", T::Fn), ("return", T::Return), ("if", T::If), ("else", T::Else),
    ("for", T::For), ("in", T::In), ("true", T::True), ("false", T::False), ("nil", T::Nil),
];
const SYMBOLS: &[(&str, TokenType)] = &[
    ("(", T::ParenOpen), (")", T::ParenClose), ("[", T::BracketOpen), ("]", T::BracketClose),
    ("{", T::BraceOpen), ("}", T::BraceClose), ("{", T::BlockOpen), ("}", T::BlockClose),
    (",", T::Comma), ("==", T::EqualEqual), ("<", T::Less),
    ("=", T::Equal), ("+", T::Plus), ("-", T::Minus), ("*", T::Star),
];
static OPERATORS: [[TokenType; 4]; 128] = operators(SYMBOLS);
static KEYWORDS: Keywords = index(WORDS);
// each operator's left and right power, a zero left power marks a prefix
const LADDER: &[(TokenType, u8, u8)] = &[
    (T::EqualEqual, 1, 2), (T::Less, 1, 2), (T::Plus, 3, 4), (T::Minus, 3, 4), (T::Star, 5, 6), (T::Minus, 0, 7),
];

impl Spelling for Tally {
    const SYNTAX: Syntax = Syntax::PLAIN
        .name("tally")
        .extension("tly")
        .words(WORDS)
        .symbols(SYMBOLS)
        .operators(&OPERATORS)
        .keywords(&KEYWORDS)
        .precedence(LADDER)
        .ends(Ends::Newline)
        .comments(Comments::PLAIN.line(&["#"]))
        .strings(Strings::PLAIN
        .quotes(&[Quote::PLAIN])
        .escapes(Escapes::PLAIN.simple(&[(b'n', '\n')]).unicode(Unicode::Fixed).unknown(Unknown::Refuse)))
        .numbers(Numbers::PLAIN.zeros(Zeros::Refused).suffix(Suffix::Refused))
        .continuation(Continuation::PLAIN.operator(true))
        .shapes(Shapes::PLAIN.binding(Binding::Required));
    const NATIVES: &'static Natives = &NATIVES;
}

// two kernels of lib under the names a program calls
const TABLE: &[Native] = &interpreter::lib::table![Tally; "print" => interpreter::lib::io::print, "len" => interpreter::lib::seq::len];

static NATIVES: Natives = interpreter::natives! { language: Tally, fns: [TABLE], methods: [], types: &[] };

// lib words failures and renders values with its defaults
impl interpreter::lib::Lang for Tally {}

impl Language for Tally {
    const VERSION: u32 = 1;
    // the engine's rules, but an int too wide to box raises instead of growing
    const POLICY: Policy = Policy::PLAIN.int_overflow(Overflow::Error);
    const NATIVES: &'static Natives = &NATIVES;
    const NAMES: &'static Names = &Names::PLAIN;
    const FRONT: Front = FRONT;
    const DESCRIPTOR: &'static Descriptor = &DESCRIPTOR;
    type Ops = ();

    // values print as lib renders them
    interpreter::lib::hooks!(Tally; show);
}

pub const FRONT: Front = Front::spelled::<Tally>();
pub const DESCRIPTOR: Descriptor = Descriptor::PLAIN.language("tally").entries(&["main.tly"]);
pub static RUNTIME: Runtime = Runtime::of::<Tally>();

// the exports of tally.wasm and of its native library built only for the web feature
#[cfg(feature = "web")]
interpreter::exports!(RUNTIME);

fn main() {
    let src = "let total = 0\nfor n in [1, 2, 3] {\n    total = total + n * n\n}\nprint(\"squares\", len([1, 2, 3]), total)\n";
    let chunk = FRONT.compile(src).unwrap_or_else(|errors| panic!("{}", interpreter::Diagnostic::render_all(&errors, src, Some("main.tly"))));
    let mut vm = VM::with_runtime(&RUNTIME, &chunk, Limits::sandbox());
    vm.run().expect("the program runs");
    assert_eq!(vm.output_text(), "squares 3 14\n");
}
```

Its `Cargo.toml` turns on only the two modules it names.

```toml
[dependencies]
interpreter = { version = "1", default-features = false, features = ["std", "io", "seq"] }
```

## Token table

| Field | Sets |
|---|---|
| `words`, `symbols` | Each reserved word and symbol and its token. A space joins a phrase, as in `("else if", T::ElseIf)`. A braces table lists `{` as both `BraceOpen` and `BlockOpen` |
| `operators`, `keywords` | Lookups built when the crate compiles, with `operators(SYMBOLS)` and `index(WORDS)` |
| `precedence`, `chained` | Binding powers, and whether `a < b < c` chains |
| `blocks`, `ends` | `Indent`, `Braces` or `Words { implicit }`, and whether a statement ends at a line end, a semicolon or either |
| `comments`, `strings`, `interp`, `numbers` | Comments, quotes and escapes, interpolated strings and number literals |
| `shapes` | Optional pieces such as lambdas, comprehensions, slices, decorators, `match` arms, ranges, `let` and a [grammar](./03-grammar.mdx). `Shapes::PLAIN` turns on all of them but `let`, arms, ranges and a grammar |

A language the parser cannot read builds its own `Front` with `Front::new(parse, imports, syntax, policy)`. Its parse function writes the same bytecode through `interpreter::code::build` and its `Builder`, and the front takes its file extension from the `Syntax` it gets. [Lox](#lox) does this.

## Natives

`interpreter::lib` holds ready natives, one module per feature.

| Module | Holds |
|---|---|
| `io` | `print`, `read_line`, `send`, `receive`, `exit` |
| `text`, `bytes`, `spec` | Text and bytes methods, codecs and format specs |
| `num` | Ints of any size, floats, rounding and hashing |
| `seq`, `iter`, `map`, `set` | Lists, iterators, folds, sorting, maps and sets |
| `data` | JSON, CSV and line reading |
| `date` | Times and durations |
| `types` | Attributes through `lib::reflect`, `is_a` and `type_of`. Which errors a handler catches is `types::handles`, which `lib` alone gives |

Each is a kernel, a native with no name until `interpreter::lib::table!` gives it the one a program calls, as in `"json" => interpreter::lib::data::json::read`. In `interpreter::natives!`, `methods` adds methods by kind, such as `text.upper`, and `types` names the types a program can test against. A native `interpreter::lib` lacks is an `interpreter::lang::Native` you write, a function of a `Cx` and its arguments that returns a value.

## Language

| Item | Start from | Sets |
|---|---|---|
| `POLICY` | `Policy::PLAIN` | Integer overflow and division, what is false, negative indexes, iteration and the recursion limit. Ints that grow without bound also need `WIDE`, which `interpreter::lib::num::int_kind` gives |
| `NAMES` | `Names::PLAIN` | The names of the engine's types and error classes in your language. `.kinds` and `.errors` take pairs such as `(ErrKind::Type, "TypeError")`, and a kind or class left out keeps its plain name |
| `VERSION`, `NATIVES`, `FRONT`, `Ops` | Required | The runtime's version, its natives, its front and its own opcodes, `()` for none |
| `show` | An error | How a value prints, usually `interpreter::lib::fmt::show` |
| `format` | `show` for an empty spec and an error for any other | How a value prints under a format spec, usually `interpreter::lib::fmt::format` |
| `handles` | An error | Which errors a handler catches, usually `interpreter::lib::types::handles` |
| `DESCRIPTOR` | `Descriptor::PLAIN` | What tools read, such as the entry files and the test suffix. `Runtime::of` adds the file extension from `FRONT` and the type, value, runtime and permission error classes from `NAMES` |

`interpreter::lib::hooks!(L)` inside `impl Language for L` writes `show`, `format` and `handles` over those three helpers, and `hooks!(L; show)` writes only the ones it names. `hooks!(L)` and any list with `format` need the `spec` feature. `L` implements `interpreter::lib::Lang`, and an empty `impl`, as in the example, keeps lib's renders and words. Each is a provided item of `Lang` a runtime may override.

`Names::error(kind)` and `Names::kind(kind)` read the class a runtime gives an `ErrKind` and the type it gives a `KindId`, also in a `const`. `Runtime::of::<L>()` runs in a `static`, so a policy that does not hold together fails the build.

## The .wasm of a runtime

The same crate builds the module the JS host and the CLI load, and the native library the CLI loads in its place. `interpreter::exports!(RUNTIME)` writes the exports behind a feature of the runtime's own, `web` here and in Lox, which turns on the crate's `exports` feature.

```toml
[features]
web = ["interpreter/exports"]
```

```bash
cargo rustc --release --target wasm32-unknown-unknown --lib --crate-type cdylib --no-default-features --features web
```

The native library has the same exports with a context for each run, so actors run it in parallel with no lock. It needs `std` and a profile where a panic unwinds, so the CLI reports one as an error of the run.

```toml
[profile.native]
inherits = "release"
panic = "unwind"
```

```bash
cargo rustc --profile native --lib --crate-type cdylib --features web
```

The CLI runs it outside the sandbox, as [wasm or native](./06-cli.mdx#wasm-or-native) says.

## Lox

[Lox](./01-overview.mdx#lox) scans through the engine's lexer with a token table of its own, and its own front parses and resolves a program as the book's compiler does, with the book's error messages. Every number is a double, only `nil` and `false` are false, and fields live on instances only. Its native binary exits with 65 after a compile error and 70 after a run error, as the book's does. `cargo test -p interpreter-lox` runs the book's suite on it.
