# System

A program reaches outside its sandbox only through the host modules its host wires in. The CLI and the JS host both serve `net`, for requests and sockets, and the CLI also serves `files`, which reads local files. A host module needs no `imports` entry, and a package can import it only when the root `edge.json` grants it.

A call that fails raises a class of the runtime that runs it, named in its descriptor. An argument the rules refuse raises the runtime's value error, `ValueError` in mini. A host or path outside the grant raises its `denied_error`, `PermissionError` in mini, and a call that reached out and failed raises its `failed_error`, `OSError` in mini. Uptime raises `BadData`, `Denied` and `Unreachable` for the same three, and the rest of this page names mini's.

```edge-manifest
{ "permissions": { "main": ["net:api.github.com"] } }
```

```edge
import net

r = net.request("GET", "https://api.github.com/zen")
print("granted", r > 0)
try:
    net.request("GET", "https://evil.example/")
except PermissionError as e:
    print(e)
```

```output
granted True
'main' has no net:evil.example, edge.json grants it net:api.github.com
```

## Permissions

The root `edge.json` grants each package it imports. Each package passes grants on to the ones it imports. A `permissions` section maps each holder to a list of entries, each written `module:scope`.

```json
{
  "imports": { "analytics": "1.2.0" },
  "permissions": {
    "main": ["net:api.example.com"],
    "analytics": ["net:api.telemetry.com/v1"]
  }
}
```

| Holder | Who holds its entries |
|---|---|
| `main` | The code of the package itself. For the root, every module under the root `edge.json` |
| `all` | `main` and every package it imports |
| An import key | The package that key imports |
| `eval` | Nobody. It caps what a bundle may grant in an [eval group](../03-platforms/03-actors.mdx#untrusted-code) |

| Entry | Allows |
|---|---|
| `net:<host>` | `request` and `connect` to that exact host, on any port and path |
| `net:<host>/<prefix>` | The same host, but only at `<prefix>` and the paths under it |
| `net` | Importing the module and reaching nothing |

A host is a lowercase name or an IPv4 written as `a.b.c.d`, with no scheme and no port. IPv6 is not supported, since the policy of a browser frame cannot name one. A module the host does not serve, or a scope its module does not take, stops the run before anything compiles.

### Path prefixes

`net:api.example.com/v2` reaches `/v2` and `/v2/items` and no other path. A path counts as under the prefix only if it stays there however a server reads it.

- It may be decoded once or twice.
- A backslash may be taken for a slash.
- A `;` parameter may be dropped.

Under that grant `/v2/..%2fadmin` and `/v2/..;/admin` are refused. `/v2/group%2Fproject` reaches.

### Who holds what

A package is what an import key brings in, the nearest `edge.json` above its files.

- A package holds what its importer writes under its key, joined with what the importer writes for `all`.
- An importer other than the root passes on only what it holds itself.
- The `name` a manifest gives itself never counts. No package can pose as another.
- Code reached by a relative import belongs to the package that imports it, even under an `edge.json` of its own, unless an import key brings that package in or it sits in a package around the importer.
- Two importers holding different grants that reach one such package by relative imports stop the run before anything compiles with `'shared/' is reached by relative imports from 'pay/' and 'shop/' which hold different grants, import it under a key of each edge.json instead`.
- A grant under the import key of a local module with no `edge.json` of its own reaches nothing, since that code runs as part of its importer, so the run stops before anything compiles with `permissions for 'util' reach nothing, its import './util/main.mini' has no edge.json of its own so it runs as part of this package`.
- A package two importers share loads once for each. Each copy holds only what its own importer passes it.
- Code outside any package holds nothing.

### What a dependency asks for and passes on

A dependency writes in its own `edge.json` what its code needs under `main`. It writes what each package it imports needs under that import key. It passes on only what it holds, and its importer has to give it everything it lists.

A generic client such as `http` asks for `"net"` alone. The package that imports it passes the hosts.

```json
{ "name": "analytics", "imports": { "http": "0.2.0" }, "permissions": { "main": ["net:api.telemetry.com"], "http": ["net:api.telemetry.com"] } }
```

The CLI holds the tree to these asks at every step.

- `edge add` prints what each new package asks for.
- `edge lock` walks the whole tree, each package through its own `edge.lock`. It writes nothing until the root gives each package it imports everything that package lists, and it names each one that misses something.
- A package that passes an import less than it asks fails the lock the same way.
- `edge run` and `edge test` run the same check before anything compiles, on the nearest `edge.json` above the script or the tested path, and `edge build` on the project's own. An edit after the last lock cannot slip past it.

```text
error: edge.json does not grant what these packages ask for
  analytics 1.2.0   net:api.telemetry.com
help: grant them under "permissions" in edge.json
```

No import may be named `all`, `main` or `eval`. The package it brings in would answer to that holder. The CLI refuses a package named any of them.

### Where a grant is checked

Importing a host module the package holds no entry for fails at compile time.

```text
'analytics' imports net, which edge.json does not grant it
```

Every call checks its scope again, since a url is only known once the program runs. A call outside the grant raises `PermissionError` in the coroutine that made it, before any byte leaves.

A host module, and every request or socket it opens, answers only code of the package that imported it. Another package that reaches the object, as `analytics.net` or a function passed along, gets `PermissionError` and imports the module itself to use its own grants.

## net

| Call | Returns |
|---|---|
| `request(method, url, headers, body, inflate, timeout)` | An id at once. The request goes out in the background |
| `response(id)` | `[status, headers]` once the head arrived |
| `read(id)` | The next chunk of the body or the next message of a socket. `nil` once it ended, and on every read after |
| `connect(url)` | A socket id once the WebSocket is open |
| `send(id, data)` | Sends `bytes` or a `str` on a socket |
| `close(id)` | Aborts a request or closes a socket |

`headers` is a list of `[name, value]` pairs or a dict. `body` is `bytes`, a `str` or `nil`. With `inflate` set to `"gzip"`, `read` hands back the bytes a gzip body holds. A body arrives one chunk per `read`, so a large one never sits in memory whole. `timeout` bounds the head and each body read to that many seconds, 30 by default and at most 86400, and a read counts it only while it waits. A server silent past it fails the call waiting on it with `OSError`, and every later `read` of that request fails the same way. Every argument after `url` may be left out.

A package holds at most 128 requests and sockets open at once, and one more fails with `OSError` until it closes one. A socket keeps at most 1024 messages and 16 MB nobody has read. Past them it closes, and a read past the messages it kept fails with `OSError`.

```edge-manifest
{ "permissions": { "main": ["net:api.github.com"] } }
```

```edge
import net

r = net.request("GET", "https://api.github.com/zen", [["accept", "application/vnd.github+json"]], nil)
status, headers = net.response(r)
body = b""
chunk = net.read(r)
while chunk is !nil:
    body += chunk
    chunk = net.read(r)
print(status, body.decode())
```

```output
200 Responsive is better than fast.
```

GitHub answers one line of its zen, another on each request, and that one came on 25 October 2026.

A call fails with one of three errors.

| Raises | When |
|---|---|
| `ValueError` | An argument the rules refuse, before anything is sent |
| `PermissionError` | A host or path outside the grant, before anything is sent |
| `OSError` | A connection, a read or a redirect that failed, from the call that meets it |

### URL rules

The check and the request always read the same host and exactly one path. The path is resolved before the check and sent as resolved.

| Part | Rule |
|---|---|
| Host | It comes right after the scheme, with no user before it. Anything else raises `ValueError` |
| Characters | No backslash, space or control character anywhere, or `ValueError`. An `@` later in the path stays, as in `https://example.com/@dylan` |
| Non-ASCII host | Raises `ValueError`. Only its punycode form reads the same everywhere |
| Numeric host | A host ending in a number raises `ValueError` unless it is written `a.b.c.d`. A browser reads `0x7f.1` or `2130706433` as an IPv4 |
| Dot segments | A `.` or `..` segment is applied however it is spelled. `/v2/%2e%2e/admin` is `/admin`, and a path prefix cannot be climbed out of |
| Other text | Text outside the unreserved set crosses as its escaped UTF-8 bytes. `/Español` is sent as `/Espa%C3%B1ol` |
| Fragment | Dropped. It never leaves the host |
| Redirects | No host follows one. A 301, 302, 303, 307 or 308 raises `OSError`, and the new address goes through its own `request` and its own check |
| Headers | One that fetch keeps for the host raises `ValueError`, such as `Host`, `Cookie`, `Origin` or any `Sec-` or `Proxy-` header |
| Sockets | `connect` takes `ws` and `wss`, and an `http` or `https` url opens its socket twin |

In a browser the request is a `fetch` from the Web Worker, and CORS applies on top of the grant.

### Two implementations

The browser and the CLI each run `net` as a module of their own, one in TypeScript over `fetch` and `WebSocket`, one in Rust over `ureq` and `tungstenite`. Both follow the rules above, and one suite of cases runs every program on both, granted and denied. A program answers the same with and without `--web`.

```rust file=examples/net/net.rs
use cli::host::{Calls, Fault, Held, HostModule, Reply, Serve, WireValue};
use flate2::bufread::GzDecoder;
use std::collections::{HashMap, VecDeque};
use std::io::{BufRead, BufReader, Read};
use std::net::TcpStream;
use std::sync::atomic::{AtomicI64, Ordering};
use std::sync::mpsc::{channel, Receiver, Sender, TryRecvError};
use std::sync::{Arc, Condvar, Mutex, MutexGuard};
use std::time::{Duration, Instant};
use tungstenite::stream::MaybeTlsStream;
use tungstenite::Message;
use ureq::unversioned::resolver::DefaultResolver;
use ureq::unversioned::transport::{Buffers, ConnectionDetails, Connector, DefaultConnector, NextTimeout, Transport};

/* requests and sockets to the hosts a package holds as `net:<host>` or `net:<host>/<prefix>` */
pub struct Net;

const CALLS: [&str; 6] = ["request", "response", "read", "close", "connect", "send"];

impl HostModule for Net {
    fn name(&self) -> &str {
        "net"
    }

    fn scope(&self, scope: &str) -> bool {
        let (host, prefix) = scope.split_at(scope.find('/').unwrap_or(scope.len()));
        let plain = |segment: &str| !segment.is_empty() && segment != "." && segment != ".." && segment.chars().all(|c| c.is_ascii_alphanumeric() || "-._~!$&'()*+,=:@".contains(c));
        // one trailing slash stays a whole host and every segment before it is plain
        let body = prefix.strip_suffix('/').unwrap_or(prefix);
        is_host(host) && plain_host(host) && body.split('/').skip(1).all(plain)
    }

    // a request or a socket reaches the host and the resolved path of its url
    fn reaches(&self, call: &str, args: &[WireValue]) -> Result<Option<String>, Fault> {
        let url = match call {
            "request" => args.get(1),
            "connect" => args.first(),
            _ => return Ok(None),
        };
        let place = plain(text(url.unwrap_or(&WireValue::None), "a url")?)?;
        Ok(Some(format!("{}{}", place.host, place.path)))
    }

    // a scope reaches its whole host or the paths under its prefix in every reading
    fn covers(&self, scope: &str, reached: &str) -> bool {
        let (host, path) = reached.split_at(reached.find('/').unwrap_or(reached.len()));
        if scope.split('/').next() != Some(host) {
            return false;
        }
        let prefix = &scope[host.len()..];
        let prefix = prefix.strip_suffix('/').unwrap_or(prefix);
        prefix.is_empty() || readings(path).iter().all(|read| read == prefix || read.strip_prefix(prefix).is_some_and(|rest| rest.starts_with('/')))
    }

    // the path shows only once the host is held so a refused host reads alone
    fn asked(&self, held: &[String], reached: &str) -> String {
        let host = reached.split('/').next().unwrap_or(reached);
        match held.iter().any(|scope| scope.split('/').next() == Some(host)) {
            true => reached.to_string(),
            false => host.to_string(),
        }
    }

    // the kit checks every url against the grant before a call arrives here
    fn open(&self, inst: &mut dyn Serve, spec: &str, _pkg: &str, _held: Held) -> Result<(), String> {
        inst.serve(spec, self.name(), &CALLS, Box::new(Opened { streams: HashMap::new() }))
    }
}

// one counter for every package so an id never names two streams
static NEXT: AtomicI64 = AtomicI64::new(1);

// requests and sockets one package may hold open at once
const OPEN: usize = 128;

// the seconds a request waits for its answer to begin by default and at most
const TIMEOUT: f64 = 30.0;
const TIMEOUT_MAX: f64 = 86400.0;

// messages and their bytes a socket keeps unread before it closes rather than hold more
const QUEUED: usize = 1024;
const QUEUED_BYTES: usize = 16 << 20;

/* the calls of one package and the requests and sockets it opened */
struct Opened {
    streams: HashMap<i64, Stream>,
}

enum Stream {
    Request(Arc<Exchange>),
    Socket(Socket),
}

impl Calls for Opened {
    fn call(&mut self, index: usize, args: Vec<WireValue>, reply: Reply) {
        let arg = |at: usize| args.get(at).unwrap_or(&WireValue::None);
        match CALLS[index] {
            "request" => reply.answer(self.request(arg(0), arg(1), arg(2), arg(3), arg(4), arg(5))),
            "response" => self.response(arg(0), reply),
            "read" => self.read(arg(0), reply),
            "close" => reply.answer(self.close_one(arg(0))),
            "connect" => self.connect(arg(0), reply),
            _ => reply.answer(self.send(arg(0), arg(1))),
        }
    }

    fn close(&mut self) {
        for (_, stream) in self.streams.drain() {
            stream.abort();
        }
    }
}

impl Opened {
    /* the id at once while the head and the body arrive through `response` and `read` */
    fn request(&mut self, method: &WireValue, url: &WireValue, headers: &WireValue, body: &WireValue, inflate: &WireValue, timeout: &WireValue) -> Result<WireValue, Fault> {
        let place = plain(text(url, "a url")?)?;
        let method = match method {
            WireValue::None => "GET",
            method => text(method, "a method")?,
        };
        let headers = pairs(headers)?;
        let body = content(body)?;
        let inflate = match inflate {
            WireValue::None => false,
            WireValue::Bytes(b) if b == b"gzip" => true,
            _ => return Err(Fault::invalid("inflate must be None or 'gzip'")),
        };
        let timeout = seconds(timeout)?;
        self.room()?;
        let id = NEXT.fetch_add(1, Ordering::Relaxed);
        let exchange = Arc::new(Exchange::new(&place.target));
        let (asked, at) = (Asked { method: method.to_string(), headers, body, inflate, timeout }, exchange.clone());
        std::thread::spawn(move || fetch(asked, &place.target, &at));
        self.streams.insert(id, Stream::Request(exchange));
        Ok(WireValue::Int(id as i128))
    }

    /* the status and headers of a request once they arrive */
    fn response(&mut self, id: &WireValue, reply: Reply) {
        match self.stream(id) {
            Ok(Stream::Request(exchange)) => exchange.head(reply),
            Ok(Stream::Socket(_)) => reply.fail(Fault::invalid("response takes a request from net.request")),
            Err(fault) => reply.fail(fault),
        }
    }

    /* the next body chunk or socket message or None once it ended */
    fn read(&mut self, id: &WireValue, reply: Reply) {
        match self.stream(id) {
            Ok(Stream::Request(exchange)) => exchange.read(reply),
            Ok(Stream::Socket(socket)) => socket.read(reply),
            Err(fault) => reply.fail(fault),
        }
    }

    /* the socket id once it opens while its messages arrive through `read` */
    fn connect(&mut self, url: &WireValue, reply: Reply) {
        let place = match text(url, "a url").and_then(plain) {
            Ok(place) => place,
            Err(fault) => return reply.fail(fault),
        };
        if let Err(fault) = self.room() {
            return reply.fail(fault);
        }
        let id = NEXT.fetch_add(1, Ordering::Relaxed);
        let (flow, (outgoing, queued)) = (Arc::new(Mutex::new(Flow::default())), channel());
        let (at, target) = (flow.clone(), place.target.clone());
        std::thread::spawn(move || serve(&place.target, id, reply, &at, &queued));
        self.streams.insert(id, Stream::Socket(Socket { flow, outgoing, target }));
    }

    fn send(&mut self, id: &WireValue, data: &WireValue) -> Result<WireValue, Fault> {
        let Stream::Socket(socket) = self.stream(id)? else { return Err(Fault::invalid("send takes a socket from net.connect")) };
        if !lock(&socket.flow).open {
            return Err(Fault::failed("the socket is not open"));
        }
        let message = match content(data)? {
            Some((text, true)) => Message::text(String::from_utf8_lossy(&text).into_owned()),
            Some((bytes, false)) => Message::binary(bytes),
            None => Message::binary(Vec::new()),
        };
        socket.outgoing.send(Outgoing::Message(message)).map_err(|_| Fault::failed("the socket is not open"))?;
        Ok(WireValue::None)
    }

    /* aborts a request or closes a socket */
    fn close_one(&mut self, id: &WireValue) -> Result<WireValue, Fault> {
        self.stream(id)?;
        if let Some(stream) = id_of(id).and_then(|id| self.streams.remove(&id)) {
            stream.abort();
        }
        Ok(WireValue::None)
    }

    /* refuses another request or socket while the package holds `OPEN` of them */
    fn room(&self) -> Result<(), Fault> {
        match self.streams.len() < OPEN {
            true => Ok(()),
            false => Err(Fault::failed(format!("net holds {OPEN} open requests and sockets for this package, close one first"))),
        }
    }

    /* what an id names among the streams this package opened */
    fn stream(&self, id: &WireValue) -> Result<&Stream, Fault> {
        let Some(id) = id_of(id) else { return Err(Fault::invalid("an id is an int from net.request or net.connect")) };
        match self.streams.get(&id) {
            Some(Stream::Socket(socket)) if lock(&socket.flow).gone => None,
            found => found,
        }
        .ok_or_else(|| Fault::invalid(format!("no open request or socket {id}")))
    }
}

impl Stream {
    fn abort(self) {
        match self {
            Stream::Request(exchange) => exchange.close(),
            Stream::Socket(socket) => drop(socket.outgoing.send(Outgoing::Close)),
        }
    }
}

// a whole number a page holds exactly names an id
fn id_of(value: &WireValue) -> Option<i64> {
    const SAFE: i64 = (1 << 53) - 1;
    match value {
        WireValue::Int(id) => i64::try_from(*id).ok().filter(|id| id.abs() <= SAFE),
        WireValue::Float(f) if f.fract() == 0.0 && f.abs() <= SAFE as f64 => Some(*f as i64),
        _ => None,
    }
}

/* the seconds a request waits for its answer where none gives the default */
fn seconds(value: &WireValue) -> Result<f64, Fault> {
    let seconds = match value {
        WireValue::None => return Ok(TIMEOUT),
        WireValue::Int(n) => *n as f64,
        WireValue::Float(f) => *f,
        _ => f64::NAN,
    };
    match seconds > 0.0 && seconds <= TIMEOUT_MAX {
        true => Ok(seconds),
        false => Err(Fault::invalid("timeout must be a number of seconds above 0 and up to 86400")),
    }
}

fn text<'a>(value: &'a WireValue, what: &str) -> Result<&'a str, Fault> {
    match value {
        WireValue::Bytes(b) => std::str::from_utf8(b).map_err(|_| Fault::invalid(format!("{what} must be a str"))),
        _ => Err(Fault::invalid(format!("{what} must be a str"))),
    }
}

/* a body as its bytes and whether it was text or none when absent */
fn content(value: &WireValue) -> Result<Option<(Vec<u8>, bool)>, Fault> {
    match value {
        WireValue::None => Ok(None),
        WireValue::Bytes(b) => Ok(Some((b.clone(), true))),
        WireValue::Raw(b) => Ok(Some((b.clone(), false))),
        _ => Err(Fault::invalid("a body must be bytes, a str or None")),
    }
}

// headers fetch keeps for the host are refused not dropped so both hosts answer alike
const FORBIDDEN: [&str; 21] = [
    "accept-charset", "accept-encoding", "access-control-request-headers", "access-control-request-method", "connection", "content-length",
    "cookie", "cookie2", "date", "dnt", "expect", "host", "keep-alive", "origin", "referer", "set-cookie", "te", "trailer",
    "transfer-encoding", "upgrade", "via",
];

/* the headers a program sends as pairs each checked in order */
fn pairs(value: &WireValue) -> Result<Vec<(String, String)>, Fault> {
    let shape = || Fault::invalid("headers are [name, value] pairs or a dict");
    let entries: Vec<Option<(&WireValue, &WireValue)>> = match value {
        WireValue::None => return Ok(Vec::new()),
        WireValue::List(items) => items.iter().map(|pair| match pair {
            WireValue::List(pair) if pair.len() == 2 => Some((&pair[0], &pair[1])),
            _ => None,
        }).collect(),
        WireValue::Dict(pairs) => pairs.iter().map(|(name, value)| Some((name, value))).collect(),
        _ => return Err(shape()),
    };
    let mut out = Vec::with_capacity(entries.len());
    for entry in entries {
        let (name, value) = entry.ok_or_else(shape)?;
        let name = text(name, "a header name")?;
        let lower = name.to_ascii_lowercase();
        if FORBIDDEN.contains(&lower.as_str()) || lower.starts_with("proxy-") || lower.starts_with("sec-") {
            return Err(Fault::invalid(format!("the header '{name}' belongs to the host, a program cannot set it")));
        }
        out.push((name.to_string(), text(value, "a header value")?.to_string()));
    }
    Ok(out)
}

/* a url as its lowercase host and the escaped resolved path both hosts send */
struct Place {
    host: String,
    path: String,
    target: String,
}

// a dotted lowercase host as a scope names it and a url reaches it
fn is_host(host: &str) -> bool {
    !host.is_empty() && host.bytes().all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'.' || b == b'-')
}

/* whether a host reads alike everywhere since browsers take a numeric ending as an ip4 */
fn plain_host(host: &str) -> bool {
    let last = host.split('.').rfind(|label| !label.is_empty()).unwrap_or_default();
    let hex = last.get(..2).is_some_and(|x| x.eq_ignore_ascii_case("0x")) && last[2..].bytes().all(|b| b.is_ascii_hexdigit());
    let numeric = hex || (!last.is_empty() && last.bytes().all(|b| b.is_ascii_digit()));
    !numeric || (host.split('.').count() == 4 && host.split('.').all(|octet| octet.parse::<u8>().is_ok() && (octet == "0" || !octet.starts_with('0'))))
}

/* the parts of a url every parser reads alike or the refusal naming it */
fn plain(url: &str) -> Result<Place, Fault> {
    let refused = || Fault::invalid(format!("'{url}' is not a plain url, net takes scheme://host/path with no user, backslash or space"));
    // these characters can move a host or end the match early
    if !url.chars().all(|c| c > ' ' && c != '\\' && c != '\x7f' && c != '\u{2028}' && c != '\u{2029}') {
        return Err(refused());
    }
    let (scheme, rest) = url.split_once("://").ok_or_else(refused)?;
    let scheme = scheme.to_ascii_lowercase();
    if !matches!(scheme.as_str(), "http" | "https" | "ws" | "wss") {
        return Err(refused());
    }
    let named = rest.bytes().take_while(|b| b.is_ascii_alphanumeric() || *b == b'.' || *b == b'-').count();
    let (name, rest) = rest.split_at(named);
    let digits = rest.strip_prefix(':').map(|after| after.bytes().take_while(u8::is_ascii_digit).count());
    let (port, rest) = match digits {
        Some(1..=5) => rest.split_at(1 + digits.unwrap_or(0)),
        Some(_) => return Err(refused()),
        None => ("", rest),
    };
    let host = name.to_ascii_lowercase();
    if host.is_empty() || !(rest.is_empty() || rest.starts_with(['/', '?', '#'])) || !plain_host(&host) {
        return Err(refused());
    }
    // a fragment never leaves the host so a grant never reaches it
    let addressed = rest.split('#').next().unwrap_or_default();
    let (path, query) = addressed.split_at(addressed.find('?').unwrap_or(addressed.len()));
    let path: String = resolve(path).chars().map(escape).collect();
    Ok(Place { target: format!("{scheme}://{host}{port}{path}{query}"), host, path })
}

// what a path may carry as written while the rest crosses as escaped UTF-8 bytes
fn escape(c: char) -> String {
    if c.is_ascii_alphanumeric() || "-._~!$&'()*+,;=:@/%".contains(c) {
        return c.to_string();
    }
    c.to_string().bytes().map(|b| format!("%{b:02X}")).collect()
}

// a segment of `count` dots each spelled plainly or escaped
fn dots(segment: &str, count: usize) -> bool {
    let (mut rest, mut seen) = (segment, 0);
    while !rest.is_empty() {
        rest = match rest.strip_prefix('.') {
            Some(after) => after,
            None if rest.get(..3).is_some_and(|x| x.eq_ignore_ascii_case("%2e")) => &rest[3..],
            None => return false,
        };
        seen += 1;
    }
    seen == count
}

/* applies dot segments however they are spelled and never climbs above the root */
fn resolve(path: &str) -> String {
    let segments: Vec<&str> = path.strip_prefix('/').unwrap_or(path).split('/').collect();
    let mut out: Vec<&str> = Vec::new();
    for (at, segment) in segments.iter().enumerate() {
        let above = dots(segment, 2);
        if above {
            out.pop();
        }
        if !above && !dots(segment, 1) {
            out.push(segment);
        } else if at == segments.len() - 1 {
            out.push("");
        }
    }
    format!("/{}", out.join("/"))
}

// an escape a server may undo before routing where every server decodes the unreserved ones
fn decode(text: &str, unreserved_only: bool) -> String {
    let (mut out, mut rest) = (String::with_capacity(text.len()), text);
    while let Some(c) = rest.chars().next() {
        let hex = rest.strip_prefix('%').and_then(|after| after.get(..2)).filter(|hex| hex.bytes().all(|b| b.is_ascii_hexdigit()));
        match hex.and_then(|hex| u8::from_str_radix(hex, 16).ok()) {
            Some(b) if !unreserved_only || b.is_ascii_alphanumeric() || b"-._~".contains(&b) => {
                out.push(char::from(b));
                rest = &rest[3..];
            }
            _ => {
                out.push(c);
                rest = &rest[c.len_utf8()..];
            }
        }
    }
    out
}

/* every path a server might route `path` to decoded up to twice */
fn readings(path: &str) -> [String; 3] {
    let all = decode(path, false);
    [decode(path, true), decode(&all, false), all].map(|read| {
        let mut plain = String::with_capacity(read.len());
        let mut parameter = false;
        for c in read.chars().map(|c| if c == '\\' { '/' } else { c }) {
            parameter = c == ';' || (parameter && c != '/');
            if !parameter {
                plain.push(c);
            }
        }
        resolve(&plain)
    })
}

/* refuses unless the grant is unbounded or a scope reaches the host within its prefix */
#[cfg(test)]
fn reach(held: &Held, place: &Place) -> Result<(), Fault> {
    held.reach(&Net, &format!("{}{}", place.host, place.path))
}

// statuses that hand a request elsewhere which only a new request may follow
const REDIRECTS: [u16; 5] = [301, 302, 303, 307, 308];

// how much of a body one read hands over
const CHUNK: usize = 64 << 10;

fn lock<T>(at: &Mutex<T>) -> MutexGuard<'_, T> {
    at.lock().unwrap_or_else(|e| e.into_inner())
}

/* what a request asked for carried to the thread that sends it */
struct Asked {
    method: String,
    headers: Vec<(String, String)>,
    body: Option<(Vec<u8>, bool)>,
    inflate: bool,
    // the seconds the request waits for its answer to begin
    timeout: f64,
}

/* one request between the package and the thread reading its body a chunk per ask */
struct Exchange {
    state: Mutex<Exchanged>,
    asked: Condvar,
    target: String,
}

#[derive(Default)]
struct Exchanged {
    head: Option<Result<WireValue, Fault>>,
    heads: Vec<Reply>,
    // each read waiting with the moment the program asked for it
    reads: VecDeque<(Reply, Instant)>,
    // how the body stopped once it did
    ended: Option<Result<(), Fault>>,
    closed: bool,
}

impl Exchange {
    fn new(target: &str) -> Exchange {
        Exchange { state: Mutex::new(Exchanged::default()), asked: Condvar::new(), target: target.to_string() }
    }

    // a known head still parks the run as the page host does
    fn head(&self, reply: Reply) {
        let mut state = lock(&self.state);
        match &state.head {
            Some(head) => reply.later(head.clone()),
            None => state.heads.push(reply),
        }
    }

    fn read(&self, reply: Reply) {
        let mut state = lock(&self.state);
        match &state.ended {
            Some(Ok(())) => reply.later(Ok(WireValue::None)),
            Some(Err(fault)) => reply.later(Err(fault.clone())),
            None => {
                state.reads.push_back((reply, Instant::now()));
                self.asked.notify_one();
            }
        }
    }

    /* the head arrived or failed and every call waiting on it hears so */
    fn arrived(&self, head: Result<WireValue, Fault>) {
        let mut state = lock(&self.state);
        for reply in state.heads.drain(..) {
            reply.later(head.clone());
        }
        if let Err(fault) = &head {
            Exchanged::end(&mut state, Err(fault.clone()));
        }
        state.head = Some(head);
    }

    /* the next read asked and when or none once the program closed the request */
    fn next(&self) -> Option<(Reply, Instant)> {
        let mut state = lock(&self.state);
        loop {
            if state.closed || state.ended.is_some() {
                return None;
            }
            if let Some(read) = state.reads.pop_front() {
                return Some(read);
            }
            state = self.asked.wait(state).unwrap_or_else(|e| e.into_inner());
        }
    }

    fn end(&self, how: Result<(), Fault>) {
        Exchanged::end(&mut lock(&self.state), how);
    }

    fn close(&self) {
        let mut state = lock(&self.state);
        state.closed = true;
        let fault = Fault::failed(format!("net.request to {} failed, the request was closed", self.target));
        for reply in state.heads.drain(..) {
            reply.later(Err(fault.clone()));
        }
        Exchanged::end(&mut state, Err(fault));
        self.asked.notify_one();
    }
}

impl Exchanged {
    // the first end of a body stands and every read waiting on it hears it
    fn end(&mut self, how: Result<(), Fault>) {
        let how = self.ended.get_or_insert(how).clone();
        for (reply, _) in self.reads.drain(..) {
            reply.later(how.clone().map(|()| WireValue::None));
        }
    }
}

/* sends one request and hands its body over a chunk per read asked */
fn fetch(asked: Asked, target: &str, exchange: &Exchange) {
    let seconds = asked.timeout;
    let mut body = match start(asked, target) {
        Ok((head, body)) => {
            exchange.arrived(Ok(head));
            body
        }
        Err(fault) => return exchange.arrived(Err(fault)),
    };
    while let Some((reply, at)) = exchange.next() {
        match body.chunk(at) {
            Ok(Some(chunk)) => reply.later(Ok(WireValue::Raw(chunk))),
            Ok(None) => {
                reply.later(Ok(WireValue::None));
                return exchange.end(Ok(()));
            }
            Err(why) => {
                let fault = match stalled(&why) {
                    true => Fault::failed(format!("reading the response failed, nothing arrived within {seconds} s")),
                    false => Fault::failed(format!("reading the response failed, {why}")),
                };
                reply.later(Err(fault.clone()));
                return exchange.end(Err(fault));
            }
        }
    }
}

/* the head and body reader of a request or why they never arrived */
fn start(asked: Asked, target: &str) -> Result<(WireValue, Body), Fault> {
    let failed = |why: String| Fault::failed(format!("net.request to {target} failed, {why}"));
    let method = method(&asked.method).map_err(failed)?;
    if asked.body.is_some() && matches!(method.as_str(), "GET" | "HEAD") {
        return Err(failed(format!("a {method} request carries no body")));
    }
    // each step up to the head and each body read gets the timeout
    let wait = Duration::from_secs_f64(asked.timeout);
    let config = ureq::Agent::config_builder().http_status_as_error(false).max_redirects(0);
    let config = config.timeout_resolve(Some(wait)).timeout_connect(Some(wait)).timeout_send_request(Some(wait)).timeout_send_body(Some(wait)).timeout_recv_response(Some(wait));
    let by: Deadline = Arc::new(Mutex::new(None));
    // a redirect comes back as it is so the program requests the new address itself
    let agent = ureq::Agent::with_parts(config.build(), DefaultConnector::new().chain(Paced(by.clone())), DefaultResolver::default());
    let mut request = ureq::http::Request::builder().method(method.as_str()).uri(wire(target));
    let typed = asked.headers.iter().any(|(name, _)| name.eq_ignore_ascii_case("content-type"));
    for (name, value) in asked.headers {
        request = request.header(name, value);
    }
    let (bytes, text) = asked.body.unwrap_or_default();
    // text goes out as fetch sends a string body when the program names no type
    if text && !typed {
        request = request.header("content-type", "text/plain;charset=UTF-8");
    }
    let timeout = asked.timeout;
    let response = match request.body(bytes) {
        Ok(request) => agent.run(request).map_err(|e| match e {
            ureq::Error::Timeout(_) => late(target, timeout),
            e => failed(e.to_string()),
        })?,
        Err(e) => return Err(failed(e.to_string())),
    };
    let status = response.status().as_u16();
    if REDIRECTS.contains(&status) {
        return Err(Fault::failed(format!("net.request to {target} was redirected, request the new address with its own net.request")));
    }
    let head = WireValue::List(vec![WireValue::Int(status.into()), received(response.headers())]);
    let reader = response.into_body().into_reader();
    let reader = match asked.inflate {
        true => Reader::Gzip(Box::new(GzDecoder::new(BufReader::new(reader)))),
        false => Reader::Plain(reader),
    };
    Ok((head, Body { reader, by, wait }))
}

// fetch normalizes these six and refuses the three that tunnel or echo
fn method(method: &str) -> Result<String, String> {
    let token = |b: u8| b.is_ascii_alphanumeric() || b"!#$%&'*+-.^_`|~".contains(&b);
    if method.is_empty() || !method.bytes().all(token) {
        return Err(format!("'{method}' is not a valid method"));
    }
    let upper = method.to_ascii_uppercase();
    match upper.as_str() {
        "CONNECT" | "TRACE" | "TRACK" => Err(format!("the method '{method}' is forbidden")),
        "DELETE" | "GET" | "HEAD" | "OPTIONS" | "POST" | "PUT" => Ok(upper),
        _ => Ok(method.to_string()),
    }
}

// the query crosses escaped as a page sends it while the path was escaped already
fn wire(target: &str) -> String {
    let (head, query) = target.split_at(target.find('?').unwrap_or(target.len()));
    let escaped: String = query.chars().map(|c| match c {
        '"' | '<' | '>' | '\'' => format!("%{:02X}", c as u32),
        c if !c.is_ascii() => c.to_string().bytes().map(|b| format!("%{b:02X}")).collect(),
        c => c.to_string(),
    }).collect();
    format!("{head}{escaped}")
}

/* the response headers as fetch lists them sorted and joined with no cookie */
fn received(headers: &ureq::http::HeaderMap) -> WireValue {
    let mut named: Vec<(String, String)> = Vec::new();
    for (name, value) in headers {
        let name = name.as_str();
        if name == "set-cookie" || name == "set-cookie2" {
            continue;
        }
        // header bytes read one character each as a page reads them
        let value: String = value.as_bytes().iter().map(|&b| char::from(b)).collect();
        match named.iter_mut().find(|(seen, _)| seen == name) {
            Some((_, joined)) => {
                joined.push_str(", ");
                joined.push_str(&value);
            }
            None => named.push((name.to_string(), value)),
        }
    }
    named.sort_by(|a, b| a.0.cmp(&b.0));
    WireValue::List(named.into_iter().map(|(name, value)| WireValue::List(vec![WireValue::Bytes(name.into_bytes()), WireValue::Bytes(value.into_bytes())])).collect())
}

enum Reader {
    Plain(ureq::BodyReader<'static>),
    Gzip(Box<GzDecoder<BufReader<ureq::BodyReader<'static>>>>),
}

/* a body reader and the deadline its connection holds the read in progress to */
struct Body {
    reader: Reader,
    by: Deadline,
    wait: Duration,
}

impl Body {
    /* the next chunk inflated when asked or none at the end */
    fn chunk(&mut self, at: Instant) -> std::io::Result<Option<Vec<u8>>> {
        // the timeout counts from the moment the program asked and only while it waits
        *lock(&self.by) = Some(at + self.wait);
        let mut buf = vec![0u8; CHUNK];
        let n = match &mut self.reader {
            Reader::Plain(reader) => reader.read(&mut buf),
            Reader::Gzip(reader) => reader.read(&mut buf),
        }?;
        if n > 0 {
            buf.truncate(n);
            return Ok(Some(buf));
        }
        // bytes after the gzip stream fail the body as a page decoder does
        if let Reader::Gzip(reader) = &mut self.reader
            && !reader.get_mut().fill_buf()?.is_empty()
        {
            return Err(std::io::Error::other("junk found after the end of the gzip stream"));
        }
        Ok(None)
    }
}

/* the moment the body read in progress gives up and none before the first read */
type Deadline = Arc<Mutex<Option<Instant>>>;

/* wraps each connection of a request so a body read waits only until its deadline */
#[derive(Debug)]
struct Paced(Deadline);

impl<In: Transport> Connector<In> for Paced {
    type Out = PacedTransport<In>;

    fn connect(&self, _: &ConnectionDetails, chained: Option<In>) -> Result<Option<Self::Out>, ureq::Error> {
        Ok(chained.map(|inner| PacedTransport { inner, by: self.0.clone() }))
    }
}

/* a connection whose waits for bytes stop at the deadline of the read that asked */
#[derive(Debug)]
struct PacedTransport<T> {
    inner: T,
    by: Deadline,
}

impl<T: Transport> Transport for PacedTransport<T> {
    fn buffers(&mut self) -> &mut dyn Buffers {
        self.inner.buffers()
    }

    fn transmit_output(&mut self, amount: usize, timeout: NextTimeout) -> Result<(), ureq::Error> {
        self.inner.transmit_output(amount, timeout)
    }

    fn await_input(&mut self, timeout: NextTimeout) -> Result<bool, ureq::Error> {
        let Some(by) = *lock(&self.by) else { return self.inner.await_input(timeout) };
        let left = by.saturating_duration_since(Instant::now());
        // a socket never waits for no time so a spent read fails here
        if left.is_zero() {
            return Err(ureq::Error::Timeout(ureq::Timeout::RecvBody));
        }
        let left = ureq::unversioned::transport::time::Duration::Exact(left);
        match left < timeout.after {
            true => self.inner.await_input(NextTimeout { after: left, reason: ureq::Timeout::RecvBody }),
            false => self.inner.await_input(timeout),
        }
    }

    fn is_open(&mut self) -> bool {
        self.inner.is_open()
    }

    fn is_tls(&self) -> bool {
        self.inner.is_tls()
    }
}

/* whether a body read failed since nothing arrived before its deadline */
fn stalled(why: &std::io::Error) -> bool {
    why.get_ref().and_then(|inner| inner.downcast_ref::<ureq::Error>()).is_some_and(|e| matches!(e, ureq::Error::Timeout(_)))
}

/* a request whose answer did not begin within the seconds it was given */
fn late(target: &str, seconds: f64) -> Fault {
    Fault::failed(format!("net.request to {target} failed, no answer within {seconds} s"))
}

enum Outgoing {
    Message(Message),
    Close,
}

/* a socket the package opened with the messages it was sent */
struct Socket {
    flow: Arc<Mutex<Flow>>,
    outgoing: Sender<Outgoing>,
    target: String,
}

#[derive(Default)]
struct Flow {
    messages: VecDeque<WireValue>,
    reads: VecDeque<Reply>,
    open: bool,
    ended: bool,
    // a socket that never opened names no stream
    gone: bool,
    // the bytes the queued messages hold and whether the queue filled so the socket closed
    bytes: usize,
    flooded: bool,
}

impl Socket {
    fn read(&self, reply: Reply) {
        let mut flow = lock(&self.flow);
        match flow.messages.pop_front() {
            Some(message) => {
                flow.bytes -= size(&message);
                reply.ok(message)
            }
            None if flow.flooded => reply.fail(Fault::failed(format!("the socket to {} closed once the messages nobody read filled its queue", self.target))),
            None if flow.ended => reply.ok(WireValue::None),
            None => flow.reads.push_back(reply),
        }
    }
}

impl Flow {
    /* hands a message to a waiting read or queues it and is false once full */
    fn deliver(&mut self, message: WireValue) -> bool {
        match self.reads.pop_front() {
            Some(reply) => reply.later(Ok(message)),
            None if self.messages.len() >= QUEUED || self.bytes + size(&message) > QUEUED_BYTES => {
                self.flooded = true;
                self.end();
                return false;
            }
            None => {
                self.bytes += size(&message);
                self.messages.push_back(message);
            }
        }
        true
    }

    // every later read answers None so a closed socket never hangs a reader
    fn end(&mut self) {
        self.open = false;
        self.ended = true;
        for reply in self.reads.drain(..) {
            reply.later(Ok(WireValue::None));
        }
    }
}

/* the bytes a socket message holds as both hosts count them */
fn size(message: &WireValue) -> usize {
    match message {
        WireValue::Bytes(bytes) | WireValue::Raw(bytes) => bytes.len(),
        _ => 0,
    }
}

// how long a socket waits on a message before it looks for one to send
const SOCKET_POLL: Duration = Duration::from_millis(20);

/* keeps one socket open sending what the program queues and handing on what arrives */
fn serve(target: &str, id: i64, opened: Reply, flow: &Mutex<Flow>, queued: &Receiver<Outgoing>) {
    // an http url opens its ws twin as a page socket does
    let url = target.strip_prefix("http").map_or_else(|| target.to_string(), |rest| format!("ws{rest}"));
    // redirects fail the socket as in a browser since the check read only this url
    let mut socket = match tungstenite::client::connect_with_config(wire(&url).as_str(), None, 0) {
        Ok((socket, _)) => socket,
        Err(_) => {
            let mut flow = lock(flow);
            flow.gone = true;
            flow.end();
            return opened.later(Err(Fault::failed(format!("the socket to {target} failed"))));
        }
    };
    let tcp: Option<&TcpStream> = match socket.get_ref() {
        MaybeTlsStream::Plain(tcp) => Some(tcp),
        MaybeTlsStream::Rustls(tls) => Some(tls.get_ref()),
        _ => None,
    };
    if let Some(tcp) = tcp {
        let _ = tcp.set_read_timeout(Some(SOCKET_POLL));
    }
    lock(flow).open = true;
    opened.later(Ok(WireValue::Int(id.into())));
    loop {
        loop {
            let sent = match queued.try_recv() {
                Ok(Outgoing::Message(message)) => socket.send(message),
                Ok(Outgoing::Close) | Err(TryRecvError::Disconnected) => {
                    let _ = socket.close(None);
                    let _ = socket.flush();
                    return lock(flow).end();
                }
                Err(TryRecvError::Empty) => break,
            };
            if sent.is_err() {
                return lock(flow).end();
            }
        }
        let delivered = match socket.read() {
            Ok(Message::Text(text)) => lock(flow).deliver(WireValue::Bytes(text.as_bytes().to_vec())),
            Ok(Message::Binary(bytes)) => lock(flow).deliver(WireValue::Raw(bytes.to_vec())),
            Ok(Message::Close(_)) => return lock(flow).end(),
            Ok(_) => true,
            Err(tungstenite::Error::Io(e)) if matches!(e.kind(), std::io::ErrorKind::WouldBlock | std::io::ErrorKind::TimedOut) => true,
            Err(_) => return lock(flow).end(),
        };
        // a program that reads nothing while messages pile up gets the socket closed
        if !delivered {
            let _ = socket.close(None);
            let _ = socket.flush();
            return;
        }
    }
}
```

```ts file=examples/net/net.ts
// a dotted lowercase host as a scope names it and a url reaches it
const HOST = /[a-z0-9.-]+/;

// an ip4 in the one spelling every parser reads alike with no leading zeros
const OCTET = '(?:25[0-5]|2[0-4]\\d|1\\d\\d|[1-9]?\\d)';
const IP4 = new RegExp(`^${OCTET}(?:\\.${OCTET}){3}$`);

    const last = host.split('.').filter(Boolean).pop() ?? '';
    return !/^(?:\d+|0x[0-9a-f]*)$/i.test(last) || IP4.test(host);
}

// a whole scope as one lowercase host and the path prefix bounding its reach
const SCOPE = new RegExp(`^(${HOST.source})((?:/[A-Za-z0-9\\-._~!$&'()*+,=:@]+)*/?)$`);

/* whether a grant may give net a scope with no dot segment in its prefix */
function scope(asked: string): boolean {
    const [, host, prefix] = SCOPE.exec(asked) ?? [];
    return host !== undefined && plainHost(host) && prefix!.split('/').every((segment) => segment !== '.' && segment !== '..');

// a url every parser reads alike with the host right after the scheme
const PLAIN = new RegExp(`^((?:https?|wss?)://)(${HOST.source})((?::\\d{1,5})?)([/?#].*)?$`, 'i');

// what a path may carry as written while the rest crosses as escaped UTF-8 bytes
const KEPT = /^[a-z0-9\-._~!$&'()*+,;=:@/%]$/i;

// spaces and control characters and backslashes can move hosts and lone surrogates have no bytes
const sendable = (c: string) => c > ' ' && c !== '\\' && c !== '\x7f' && (c.length > 1 || c < '\ud800' || c > '\udfff');

// a segment for this directory or the one above it spelled plainly or escaped
const HERE = /^(?:\.|%2e)$/i;
const ABOVE = /^(?:\.|%2e){2}$/i;

/* applies dot segments however they are spelled and never climbs above the root */
function resolve(path: string): string {
    const out: string[] = [];
    const segments = path.replace(/^\//, '').split('/');
    for (const [i, segment] of segments.entries()) {
        const above = ABOVE.test(segment);
        if (above) out.pop();
        if (!above && !HERE.test(segment)) out.push(segment);
        else if (i === segments.length - 1) out.push('');
    }
    return `/${out.join('/')}`;
}

/* a url as its lowercase host and the escaped resolved path both hosts send */
function plain(url: string): { host: string, path: string, target: string } {
    const [, scheme, name, port, rest = '/'] = ([...url].every(sendable) ? PLAIN.exec(url) : null) ?? [];
    const host = name?.toLowerCase();
    if (host === undefined || !plainHost(host)) throw invalid(`'${url}' is not a plain url, net takes scheme://host/path with no user, backslash or space`);
    // a fragment never leaves the host so a grant never reaches it
    const [addressed] = rest.split('#') as [string];
    const at = addressed.indexOf('?');
    const path = [...resolve(at === -1 ? addressed : addressed.slice(0, at))].map((c) => (KEPT.test(c) ? c : encodeURIComponent(c))).join('');
    return { host, path, target: `${scheme!.toLowerCase()}${host}${port}${path}${at === -1 ? '' : addressed.slice(at)}` };

// an escape a server may undo before routing where every server decodes the unreserved ones
const ESCAPE = /%([0-9a-f]{2})/gi;
const UNRESERVED = /[A-Za-z0-9\-._~]/;
const byte = (hex: string) => String.fromCharCode(parseInt(hex, 16));

/* a scope reaches its whole host or the paths under its prefix in every reading */

/* the seconds a request waits for its answer to begin where none gives the default */

    if (value === null) return TIMEOUT;
    const n = typeof value === 'number' ? value : typeof value === 'bigint' ? Number(value) : NaN;
    if (!(n > 0 && n <= TIMEOUT_MAX)) throw invalid('timeout must be a number of seconds above 0 and up to 86400');
    return n;

const failure = (what: string, e: unknown) => failed(`${what} failed, ${e instanceof Error ? e.message : String(e)}`);

// statuses that hand a request elsewhere which only a new request may follow
const REDIRECTS = [301, 302, 303, 307, 308];

/* the next chunk where a read waiting past the timeout fails every later one too */
async function chunk(request: InFlight): Promise<Message> {
    await request.head;
    const reader = await request.body;
    if (!reader) return null;
    if (request.stalled) throw request.stalled;
    // the timeout counts from the moment the program asked and only while it waits
    const timer = setTimeout(() => {
        request.stalled = failed(`reading the response failed, nothing arrived within ${request.wait} s`);
        reader.cancel().catch(() => {});
        request.abort();
    }, request.wait * 1000);
    try {
        const { done, value } = await reader.read();
        if (request.stalled) throw request.stalled;
        return done ? null : value;
    } catch (e) {
        throw request.stalled ?? failure('reading the response', e);
    } finally {
        clearTimeout(timer);
    }
}

/* the calls and ids of a package whose urls the host checks against its grant */
function open(_pkg: string, _held: Held) {
    const streams = new Map<number, Stream>();

    // a whole number a page holds exactly names an id
    const stream = (id: EdgeValue | undefined): Stream => {
        if (typeof id !== 'number' || !Number.isSafeInteger(id)) throw invalid('an id is an int from net.request or net.connect');
        const found = streams.get(id);
        if (!found) throw invalid(`no open request or socket ${id}`);
        return found;
    };

    /* refuses another request or socket while the package holds `OPEN` of them */
    const room = () => {
        if (streams.size >= OPEN) throw failed(`net holds ${OPEN} open requests and sockets for this package, close one first`);
    };

    /* returns the request id at once while head and body arrive through `response` and `read` */
    function request(method: EdgeValue = null, url: EdgeValue = null, headers: EdgeValue = null, body: EdgeValue = null, inflate: EdgeValue = null, timeout: EdgeValue = null): number {
        const place = plain(text(url, 'a url'));
        const init = { method: text(method ?? 'GET', 'a method'), headers: pairs(headers), body: content(body) };
        if (inflate !== null && inflate !== 'gzip') throw invalid("inflate must be None or 'gzip'");
        const wait = seconds(timeout);
        room();
        const controller = new AbortController();
        // an answer that has not begun within the timeout aborts the request
        let late = false;
        const timer = setTimeout(() => { late = true; controller.abort(); }, wait * 1000);
        const answer = fetch(place.target, { ...init, signal: controller.signal, redirect: 'manual' }).finally(() => clearTimeout(timer));
        const head = answer.then((res): [number, [string, string][]] => {
            // redirects stay unfollowed since a browser hides the target that a new request checks
            if (res.type === 'opaqueredirect' || REDIRECTS.includes(res.status)) {
                throw failed(`net.request to ${place.target} was redirected, request the new address with its own net.request`);
            }
            const received: [string, string][] = [];
            res.headers.forEach((value, name) => received.push([name, value]));
            return [res.status, received];
        }, (e) => { throw late ? failed(`net.request to ${place.target} failed, no answer within ${wait} s`) : failure(`net.request to ${place.target}`, e); });
        // a request nobody reads still settles so its failure never surfaces as unhandled
        head.catch(() => {});
        const reader = (res: Response) => (inflate ? res.body?.pipeThrough(new DecompressionStream('gzip')) : res.body)?.getReader() ?? null;
        const id = next++;
        streams.set(id, { kind: 'request', abort: () => controller.abort(), head, body: answer.then(reader, () => null), wait, stalled: null });
        return id;
    }

    /* the status and headers of a request once they arrive */
    function response(id: EdgeValue = null): Promise<[number, [string, string][]]> {
        const found = stream(id);
        if (found.kind !== 'request') throw invalid('response takes a request from net.request');
        return found.head;
    }

    /* the next body chunk or socket message or None once it ended */
    function read(id: EdgeValue = null): Message | Promise<Message> {
        const found = stream(id);
        if (found.kind === 'request') return chunk(found);
        if (found.messages.length > 0) {
            const message = found.messages.shift()!;
            found.bytes -= size(message);
            return message;
        }
        if (found.flooded) throw failed(`the socket to ${found.target} closed once the messages nobody read filled its queue`);
        if (found.ended) return null;
        return new Promise((resolve) => found.waiting.push(resolve));
    }

    /* aborts a request or closes a socket */
    function close(id: EdgeValue = null): null {
        stream(id).abort();
        streams.delete(id as number);
        return null;
    }

    /* resolves the socket id once open while its messages arrive through `read` */
    function connect(url: EdgeValue = null): Promise<number> {
        const place = plain(text(url, 'a url'));
        room();
        // an http url opens its ws twin as every page socket now does
        const socket = new WebSocket(place.target.replace(/^http/, 'ws'));
        socket.binaryType = 'arraybuffer';
        const found: Stream = { kind: 'socket', abort: () => socket.close(), socket, messages: [], waiting: [], ended: false, bytes: 0, flooded: false, target: place.target };
        socket.onmessage = (e) => {
            if (found.flooded) return;
            const message = typeof e.data === 'string' ? e.data : new Uint8Array(e.data as ArrayBuffer);
            const waiter = found.waiting.shift();
            if (waiter) waiter(message);
            // a program that reads nothing while messages pile up gets the socket closed
            else if (found.messages.length >= QUEUED || found.bytes + size(message) > QUEUED_BYTES) {
                found.flooded = true;
                socket.close();
            } else {
                found.bytes += size(message);
                found.messages.push(message);
            }
        };
        // every later read answers None so a closed socket never hangs a reader
        socket.onclose = () => {
            found.ended = true;
            for (const waiter of found.waiting.splice(0)) waiter(null);
        };
        const id = next++;
        streams.set(id, found);
        return new Promise((resolve, reject) => {
            let opened = false;
            socket.onopen = () => {
                opened = true;
                resolve(id);
            };
            // a socket that never opened names no stream
            socket.onerror = () => {
                if (opened) return;
                streams.delete(id);
                reject(failed(`the socket to ${place.target} failed`));
            };
        });
    }

    function send(id: EdgeValue = null, data: EdgeValue = null): null {
        const found = stream(id);
        if (found.kind !== 'socket') throw invalid('send takes a socket from net.connect');
        if (found.socket.readyState !== WebSocket.OPEN) throw failed('the socket is not open');
        found.socket.send(content(data) ?? new Uint8Array(0));
        return null;
    }

    /* aborts what a finished run left open */
    function closeAll(): void {
        for (const found of streams.values()) found.abort();
        streams.clear();
    }

    return { calls: { request, response, read, close, connect, send }, close: closeAll };
}

const idOf = (value: unknown) => (typeof value === 'number' ? value : typeof value === 'bigint' ? Number(value) : undefined);

/* host and path only since the query or fragment may carry a key */
function place(url: unknown): string {
    try {
        const parsed = new URL(String(url));
        return `${parsed.host}${parsed.pathname}`;
    } catch {
        return '';
    }
}

/* what a call reached for a trace and never its body headers or query */
function show(call: string, args: EdgeValue[], value: unknown): Shown {
    if (call === 'request') return { scope: `${String(args[0])} ${place(args[1])}`, id: idOf(value) };
    if (call === 'connect') return { scope: place(args[0]), id: idOf(value) };
    const id = idOf(args[0]);
    if (call === 'response' && Array.isArray(value)) return { id, status: Number(value[0]) };
    if (call === 'read') return { id, bytes: value == null ? 0 : (value as { length: number }).length };
    return { id };
}

/* a room reaches the whole host of a scope since a policy names no path */
const origins = (asked: string): string[] => ['https', 'http', 'wss', 'ws'].map((scheme) => `${scheme}://${asked.split('/')[0]}:*`);

/* requests and sockets to the hosts a package holds as `net:<host>` or `net:<host>/<prefix>` */
export default { name: 'net', scope, reaches, covers, asked, open, origins, show } satisfies HostModule;
```

## files

The CLI serves `files`, which reads the files a grant names below the directory of the package's `edge.json`. The JS host serves no files.

| Call | Returns |
|---|---|
| `open(path, inflate)` | An id once a grant reaches the path and the file opens |
| `read(id)` | The next chunk of the file, or `nil` once it ended |
| `close(id)` | Nothing, and the file is dropped |

A path is names joined by slashes below the package, with no `.` or `..` segment, no leading slash and no backslash. A grant names one file, as `files:events.jsonl` does, or a directory with a trailing slash, as `files:data/` does, which reaches every file below it. With `inflate` set to `"gzip"`, `read` hands back the bytes the file holds inflated, and a file with bytes after its gzip stream fails as such a body fails through `net`.

| Raises | When |
|---|---|
| `ValueError` | A path the rules refuse, before anything opens |
| `PermissionError` | A path no grant of the package reaches |
| `OSError` | A file that is missing or fails to read |

An untrusted run in an actor pool reads only below the pool's `edge.json`, within what the pool grants `eval`. A package other than the root writes a file channel only below its own directory, where its `files` grant reaches, and the root writes one without a grant. A tiny flow whose `from` names a path reads it through this module, as [Tiny](../01-get-started/03-use-cases/03-tiny.mdx#sources-and-sinks) shows.

```rust file=cli/src/files.rs
    }

    }

        let dir = match (inst.project().untrusted, &inst.project().pool) {

        };

    }

/* the calls of one package and the files it opened */
struct Opened {
    held: Held,
    dir: String,
    open: HashMap<i64, Reader>,

    Plain(File),
    Gzip(Box<GzDecoder<BufReader<File>>>),
}

impl Calls for Opened {
    fn call(&mut self, index: usize, args: Vec<WireValue>, reply: Reply) {
        let arg = |at: usize| args.get(at).unwrap_or(&WireValue::None);
        reply.answer(match CALLS[index] {
            "open" => self.open(arg(0), arg(1)),
            "read" => self.read(arg(0)),
            _ => self.close_one(arg(0)),
        });
    }

    fn close(&mut self) {
        self.open.clear();
    }
}

impl Opened {
    /* the id of the file at `path` under the package once its grant reaches it */
    fn open(&mut self, path: &WireValue, inflate: &WireValue) -> Result<WireValue, Fault> {
        let path = path_of(path)?;
        let inflate = match inflate {
            WireValue::None => false,
            WireValue::Bytes(b) if b == b"gzip" => true,
            _ => return Err(Fault::invalid("inflate must be None or 'gzip'")),
        };
        let (real, resolved) = self.resolve(path)?;
        // a link the name runs through must land where the grant reaches too
        if resolved != path {
            self.held.reach(&Files, &resolved)?;
        }
        let file = File::open(&real).map_err(|e| Fault::failed(format!("cannot open {path}, {}", why(&e))))?;
        let reader = match inflate {
            true => Reader::Gzip(Box::new(GzDecoder::new(BufReader::new(file)))),
            false => Reader::Plain(file),
        };
        let id = NEXT.fetch_add(1, Ordering::Relaxed);
        self.open.insert(id, reader);
        Ok(WireValue::Int(id.into()))
    }

    /* the real file `path` names with every link resolved and its path below the package */
    fn resolve(&self, path: &str) -> Result<(PathBuf, String), Fault> {
        let base = Path::new(if self.dir.is_empty() { "." } else { &self.dir });
        let opened = |e: std::io::Error| Fault::failed(format!("cannot open {path}, {}", why(&e)));
        let (root, real) = (base.canonicalize().map_err(opened)?, base.join(path).canonicalize().map_err(opened)?);
        let parts = real.strip_prefix(&root).ok().and_then(|rest| rest.iter().map(|part| part.to_str()).collect::<Option<Vec<_>>>());
        match parts.filter(|parts| !parts.is_empty()).map(|parts| parts.join("/")) {
            Some(below) => Ok((real, below)),
            None => Err(Fault::denied(format!("'{path}' is a link out of the package, files reads only below it"))),
        }
    }

    /* the next chunk of a file inflated when asked or None at its end */
    fn read(&mut self, id: &WireValue) -> Result<WireValue, Fault> {
        let reader = self.open.get_mut(&id_of(id)?).ok_or_else(|| Fault::invalid(format!("no open file {}", shown(id))))?;
        let mut buf = vec![0u8; CHUNK];
        let read = match reader {
            Reader::Plain(file) => file.read(&mut buf),
            Reader::Gzip(file) => file.read(&mut buf),
        };
        let n = read.map_err(|e| Fault::failed(format!("reading the file failed, {}", why(&e))))?;
        if n > 0 {
            buf.truncate(n);
            return Ok(WireValue::Raw(buf));
        }
        // bytes after the gzip stream fail the file as net fails a body
        if let Reader::Gzip(file) = reader
            && !file.get_mut().fill_buf().map_err(|e| Fault::failed(format!("reading the file failed, {}", why(&e))))?.is_empty()
        {
            return Err(Fault::failed("reading the file failed, junk found after the end of the gzip stream"));
        }
        Ok(WireValue::None)
    }

    fn close_one(&mut self, id: &WireValue) -> Result<WireValue, Fault> {
        self.open.remove(&id_of(id)?).ok_or_else(|| Fault::invalid(format!("no open file {}", shown(id))))?;
        Ok(WireValue::None)
    }
}

/* a path a call names checked to stay below the package */
fn path_of(path: &WireValue) -> Result<&str, Fault> {
    let WireValue::Bytes(raw) = path else { return Err(Fault::invalid("a path must be a str")) };
    let path = std::str::from_utf8(raw).map_err(|_| Fault::invalid("a path must be a str"))?;
    if !plain(path) {
        return Err(Fault::invalid(format!("'{path}' is not a plain path, files takes names joined by slashes below the package")));
    }
    Ok(path)
}

/* an id as the int `open` gave */
fn id_of(id: &WireValue) -> Result<i64, Fault> {
    match id {
        WireValue::Int(n) => i64::try_from(*n).map_err(|_| Fault::invalid("an id is an int from files.open")),
        _ => Err(Fault::invalid("an id is an int from files.open")),
    }
}

fn shown(id: &WireValue) -> String {
    match id {
        WireValue::Int(n) => n.to_string(),
        _ => String::from("?"),
    }
}

/* the words of an io failure without its os code */
fn why(e: &std::io::Error) -> String {
    match e.kind() {
        std::io::ErrorKind::NotFound => String::from("no such file"),
        std::io::ErrorKind::PermissionDenied => String::from("the system refused it"),
        _ => e.to_string(),
    }
}
```
